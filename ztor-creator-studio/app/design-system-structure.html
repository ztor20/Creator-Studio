From Figma 856:27798 (visualised in design-layers.html): L0 canvas solid → L1 card solid → L2 translucent film that brightens whatever it sits on, and can stack → L3 stops filling and keeps only a hairline.

Brighter (stacked on top)往亮（疊上去的一層） --nest-surface + --nest-line. Consumers消費者: .nest, .card--muted, .bd-sec. Light mode has both layers white, so the hairline is what separates them.亮色兩層同為白，靠線框才分得出來。
Darker (a well cut into the surface)往暗（挖出來的凹槽） --muted. Consumers消費者: .segmented track軌道, media wells (image placeholders)媒體井（圖片佔位格）, progress bar troughs進度條底. Not in scope of the flip.不在翻向範圍。
Controls (buttons on a surface)控件（浮在表面上的按鈕） --control-raise (dark深色 rgba(222,223,233,.04) / light亮色 var(--card)). Consumer消費者: .btn--outline. Never an absolute surface colour — hardcoding --card made the same button read brighter on canvas, identical inside a card, and darker inside an L2 block (Q67).不要用絕對表面色——寫死 --card 時，同一顆按鈕在畫布上比底亮、在卡裡同色、在 L2 分組面裡反而更暗（Q67）。
Clickable cards (hover)可點卡片（hover） --clickable-card-lift (-4px) + --clickable-card-hover-bg (aliases別名 --control-raise-hover: dark深色 rgba(222,223,233,.12) / light亮色 var(--accent)). Declared in both theme blocks of _tokens.css so the alias resolves the dark value. Consumers and exceptions: see §5.3 · Clickable card hover.亮暗兩個主題區塊都宣告，別名才吃得到暗色值。消費者與例外見 §5.3「可點卡片 hover」。
Rule of thumb判斷句 Is this a layer stacked on the container, or a well cut into it? Former brightens, latter darkens.這塊東西是「疊在容器上的一層」還是「容器上挖出來的一個凹槽」？前者往亮，後者往暗。

4.202 Archived gate

🟢 atom

Purpose

用途

Makes an archived detail page read-only at the event level (spec §7.14 “Archived · No delete”, D284 / D288). Each detail page already hides or disables its edit entry points; this module is the second line — while the page root carries data-archived, every data-changing control (inputs, switches, segmented buttons, radio lists, chip ✕, the film picker’s add / remove, upload tiles, the private-link reset) is intercepted in the capture phase before any page handler runs. Navigation and viewing stay untouched: links, tabs, section nav, disclosure handles, the confirm dialog and whatever the page allows explicitly (the Unarchive button — since 2026-09-22 / D298 the archived page's only action, which returns the item to Unlisted). Nothing is drawn — the visible read-only cues are the existing info banner, locked listing controls and hidden actions.

把已封存的細節頁在事件層收成唯讀（規格 §7.14「封存與不可刪除」，D284／D288）。每個細節頁本來就會藏掉或停用編輯入口；本模組是第二道——頁面根節點帶 data-archived 時，所有會改資料的控件（輸入格、開關、分段按鈕、單選清單、chip 的 ✕、選片器的加入／移除、上傳格、非公開連結的重置）在 capture 階段就被攔下、到不了頁面的 handler。導覽與查看不受影響：連結、分頁、章節導覽、展開把手、確認彈窗，以及頁面明確放行的（「解除封存」鈕——2026-09-22 · D298 起已封存頁唯一的動作，按下回到已下架）。它不畫任何東西——看得見的唯讀提示仍是既有的 info banner、鎖定的 listing controls 與收起的動作。

Rendered preview (live — the wrapper carries data-archived; toggle it to see the gate open and close)

視覺展示 （真的由模組守著：外框帶 data-archived，切換看閘門開關）

Archived — read-only. Unarchiving returns it to Unlisted; settings are kept.已封存：整頁唯讀，解除封存後回到已下架、設定照舊保留。
Show in shop顯示於商店

For developers — API · code給工程師 — API · 程式碼

No CSS of its own, draws nothing.無自帶 CSS、不畫任何東西。 window.ZtorArchivedGate.install(rootEl, { block?: string, allow?: string }) → { isActive() }。The check is live — the gate reads rootEl.hasAttribute('data-archived') on every event, so archiving and relisting need no re-install. block extends the default blocked selectors, allow extends the default pass-through ones; allow wins. Also honours [data-archived-allow] on any element.判斷是即時的——每個事件都重讀 rootEl.hasAttribute('data-archived')，封存／解除封存不必重裝。block 追加要擋的選擇器、allow 追加放行的；放行優先。任何元素標 [data-archived-allow] 也放行。

Default block: 預設擋：input, textarea, select, [contenteditable], .switch, .segmented__btn, .radio-list__item, .radio-card, .zcheck, .chip__remove, [data-fp-add], [data-fp-remove], .tag-input__entry, .upload-tile, [data-upload], [data-linkf-reset]。Default allow: 預設放行：a, summary, [role=tab], .tabs__item, .section-nav__item, [data-tab-jump], [data-rowdis], .leave-dialog, [data-archived-allow]。Events: click · keydown (Enter / Space) · beforeinput · input · change, all capture-phase, stopImmediatePropagation + preventDefault.事件：click・keydown（Enter／Space）・beforeinput・input・change，一律 capture，stopImmediatePropagation＋preventDefault。
