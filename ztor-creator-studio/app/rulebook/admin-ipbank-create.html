建立 IP Entry

Admin 在同一頁填完一部影片的一個 IP、它的權利人與分潤比例，建立一筆 IP 權利分配。存好後回到 Admin IP Bank 的清單。

概述

  • 一頁填完，不分步驟；權利人可以選既有的 Ztor 帳號，也可以填 email 邀請還沒註冊的人
  • 存檔時才檢查必填、權利人與這部影片的分潤比例合計；沒通過時已填的資料保留，畫面指出要改哪裡
  • 存好的這一筆會出現在 Admin IP Bank 的清單，並算進 IP Bank Reporting 的分潤數字

操作流程

這一頁從 Admin IP Bank 按「建立 IP Entry」開始，到存檔回到清單為止。

1從 Admin IP Bank 進入按「建立 IP Entry」
2填 IP 資料影片、IP 名稱、IP 類型
3權利人是誰？
選定這個帳號存檔後為已連結
當成邀請對象存檔後為已邀請
不能建立權利人改查詢內容
4填分潤比例先看已配置與剩餘比例
5存檔：合計超過 100% 嗎？
建立這一筆回到 Admin IP Bank 清單
擋下指出超出多少，已填資料保留

流程圖：由左往右走，權利人的三種情形各一列，最下面一列被擋下、要改查詢內容才能往下；圓圈數字對應下方步驟清單的編號。

  1. 從 Admin IP Bank 按「建立 IP Entry（Add IP entry）」進入；不用先選定創作者
  2. 填 IP 資料：見IP 資料
  3. 權利人是誰？
    • 既有帳號：從查詢結果選定，存檔後為已連結
    • 未註冊的有效 email：這個 email 就是邀請對象，存檔後為已邀請，同時建立邀請
    • 都不是：不能建立權利人，改查詢內容
  4. 填分潤比例：先看這部影片的已配置與剩餘比例，見分潤配置
  5. 存檔：合計超過 100% 嗎？
    • 沒超過：建立這一筆，回到 Admin IP Bank 清單
    • 超過：擋下，畫面指出超出多少，已填的資料保留

依據：5.1.0.1.1 §1、§2、§3、§4、§6；D130、D131、D132。

功能與欄位

這一頁依序是三組：IP 資料、權利人連結、分潤配置；存檔按鈕在最後一組。

IP 資料

第一組，決定這一筆屬於哪部影片、是哪個 IP。

功能或欄位出現條件與必填規則
影片（Film）必填選這一筆分潤屬於哪部影片
選定後，分潤配置的已配置與剩餘比例跟著這部影片算
IP 名稱（IP title）必填寫這一筆分配對應的 IP
IP 類型（IP type）必填，單選選項：
Original Story / Screenplay
Character / Likeness
Music & Score
Footage / Clip
Brand / Trademark
Other

權利人連結

第二組，用同一個查詢框找既有帳號或填 email 邀請。連結狀態的意思見 Admin IP Bank 的權利人的連結狀態。

功能或欄位出現條件與必填規則
權利人（Owner）查詢框必填輸入 Ztor 使用者的 username 或 email 查詢，打部分字串也能查
查詢結果輸入後出現每一筆顯示：
顯示名稱
@username
email
選定一筆就是這一筆的權利人，存檔後為已連結
邀請對象查不到既有帳號、輸入的是有效 email 時這個 email 就是邀請對象，存檔通過後這一筆為已邀請，同時建立邀請
邀請在這一筆存檔成功之後才建立並寄出
同一個 email 已經有一筆還在邀請中時，不能再建一次
只能用 email 邀請，不能用電話
查無結果查不到既有帳號、輸入的也不是有效 email 時不能建立權利人，存檔時擋下
連結狀態—不能手動選，由選了既有帳號或發出邀請自動決定；受邀的人接受邀請後自動轉為已連結

分潤配置

第三組，先看這部影片已經分出去多少，再填這位權利人的比例。合計上限與平台剩餘的規則見 Admin IP Bank 的分潤比例怎麼檢查。

功能或欄位出現條件與必填規則
已配置比例（Allocated share）—這部影片已經分給權利人的比例合計，只能看
剩餘比例（Remaining share）—這部影片還能分配的比例，只能看；沒分出去的歸平台
分潤比例（Share）必填0 到 100，最小單位 0.01
儲存 IP Entry—檢查三件事，全部通過才建立這一筆並回到 Admin IP Bank 清單：
必填都填了
權利人是既有帳號，或是沒有重複的有效邀請 email
加上這一筆後，這部影片的分潤比例合計沒超過 100%
沒通過時已填的資料保留，畫面指出要改哪裡；合計超過時指出超出多少

依據：5.1.0.1.1 §4 F1、F2、F3、§8；主規格 §8.15；D131、D132。
