設定

創作者在項目詳情的設定分頁，維護這個項目是什麼、怎麼賺錢、誰參與，以及粉絲端看到的公開資訊。頁首與編輯規則見項目詳情。

概述

  • 欄位沿用建立項目時的設定，見建立項目；這裡只寫建立之後能改什麼、有什麼限制
  • 營利設定只有直接發佈；方案與門檻在方案分頁

操作流程

創作者在設定分頁一次改一個區段，不必重走建立流程。

1找到要改的區段
2修改改到承諾或金流先確認
3儲存變更

流程圖：由左往右走，綠框是結束的地方。圓圈數字對應下方步驟清單的編號。

  1. 進設定分頁，找到要改的區段
  2. 修改；改到已對外的承諾或金流時先確認，見各狀態能編輯什麼；公開資訊預設是檢視狀態，要先進入編輯，見檢視與編輯兩段式
  3. 儲存變更

依據：5.1.2.2 §1、§2.2；D155。

功能與欄位

設定分頁有七個區段，依序是：

  • 關於項目
  • 展示內容
  • 營利設定
  • 發布狀態
  • 合作者
  • IP Rental
  • 公開資訊

關於項目

關於項目說明這個項目是什麼。

功能或欄位出現條件與必填規則
項目名稱—可以改；和作品上架的標題是同一份資料，任一處改了就同步
內容類型—可以改
項目描述—可以改；和公開資訊的簡介、作品上架的說明是同一份資料
類型相關欄位依內容類型可以改
發行模式—直接發佈、共創、預購；建立時鎖定，發布後不能改

依據：5.1.2.2 §2.2.1、§2.2.8；D041、D182。

展示內容

展示內容是粉絲端看到的主視覺、圖庫、影片與故事。

功能或欄位出現條件與必填規則
主視覺、圖庫—每一格可以放圖片或影片
單一直式 750×1125px（2:3）；影片為 MP4、MOV 或 WEBM，單檔 1.8GB
方形版位由直式原始素材置中裁切，不另收方形素材，也不提供裁切工具
完整標準見展示素材與年齡分級
影片——
故事——
更換主要素材已發布的項目提示這次更換對粉絲端呈現的影響
內容項目依內容類型綁定本項目的內容：影集是 Episodes、專輯是 Tracks、商品是 Items
可以排序、看上傳狀態與替換
和主視覺、圖庫是不同的東西

依據：5.1.2.2 §2.2.2；主規格 §7.10；D156、D164、D259。

營利設定

營利設定決定直接發佈的項目怎麼賺錢；共創與預購沒有這一區。能改哪些看作品家族。

功能或欄位出現條件與必填規則
存取模式只有非影片家族已售出後要調整，先確認並保守處理
價格只有非影片家族已售出後要調整，先確認並保守處理
影片家族的定價在作品資料改，改了要重新送審，見哪些變更要重新送審
發布時間只有非影片家族影片家族改由上映日期承擔，見設定與修改上映日期
廣告——
品牌合作——
預期收益結構——
  • 平台費與支付費照平台規定，創作者不能改，見財務術語與收入事件
  • 已取消的項目，營利設定凍結，也不接受新的收入事件

依據：5.1.2.2 §2.0、§2.2.3；5.1.2.1 §5.1；D182、D192。

發布狀態

發布狀態管理項目在各狀態之間的轉換；狀態的定義與轉換順序見項目規則，這裡不自創狀態。

功能或欄位出現條件與必填規則
狀態操作—發布、排程、暫停或下架、取消
影響金流或對粉絲承諾的轉換要先確認
影片家族轉入已上線只能經由作品上線，不在這裡手動切換，見審核與上線
直接發佈的非影片家族，發布或排定的時間到就上線
終止原因（Termination reason）轉入已取消時必帶未達標或創作者取消，見項目規則的項目的取消

取消之後哪些凍結，見已取消的凍結範圍。

依據：5.1.2.2 §2.2.4；主規格 §7.2；D151、D154、D192。

IP Rental

IP Rental 揭露本項目用到的租入 IP 或授權紀錄，不是營利模式。

功能或欄位出現條件與必填規則
連結或更新授權—連到 IP 資產庫（IP Bank）
到期提示與續租綁定的租入 IP 距到期 30 天以內詳情頁顯示到期提示與續租入口，連到 IP Bank
7 天以內在內容區再提示一次

依據：5.1.2.2 §2.2.7；5.1.2.1 §3.6；主規格 §7.7。

公開資訊

公開資訊是粉絲端看得到的介紹資料，和營利設定分開。

功能或欄位出現條件與必填規則
簡介（Synopsis）必填和項目描述、作品上架的說明是同一份資料，任一處改了就同步
用預設語言單語填寫，顯示預設語言那一份
其他語系的自動翻譯，在發布前預覽確認畫面檢視與修改，見語言與在地化
演職（Cast／Crew）——
常見問答（FAQ）——
製作名單（Credits）——
相關連結（Related Links）——
標籤（Tags）——
年齡分級（Age rating）—六級單選，值見展示素材與年齡分級
和建立項目的年齡分級、作品上架的年齡限制是同一份資料
里程碑（Timeline Milestones）—見頁尾尚待確認

依據：5.1.2.2 §2.2.8；主規格 §7.4、§7.11；D182、D220、D223。
