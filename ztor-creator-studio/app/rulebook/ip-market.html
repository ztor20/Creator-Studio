IP 市場

創作者在 IP 市場瀏覽、比較並挑選其他創作者上架出租的 IP，替自己的項目、商品或活動找到可用的權利來源。

概述

  • 只列擁有者已上架的 IP，見市場上架開關
  • 點一張卡片進 IP 詳情，在那裡看完整條件並送出租用申請或出價

操作流程

創作者用搜尋與篩選收斂清單，比較卡片後進 IP 詳情決定要不要租。

1進 IP 市場
2搜尋與篩選類型、版稅、地區、狀態
3比較卡片價格、版稅、可用名額
4進 IP 詳情，用哪種方式取得？
送出租用申請等擁有者核准
出價

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 進 IP 市場
  2. 用搜尋與篩選縮小清單，見搜尋與篩選
  3. 比較卡片上的價格、版稅、可用名額與素材包完整度，見卡片
  4. 點卡片進 IP 詳情，依這筆 IP 的取得方式：
    • 直接租用：送出租用申請，見 IP 詳情的租用
    • 競標中：出價，見 IP 詳情的競標
  • 從建立項目流程找他人 IP 時也會來到這裡，見建立項目

依據：5.1.3 F1–F4、情境；5.1.3.1 §3、§4；D232。

可授權 IP 清單

清單呈現符合條件的 IP，讓創作者一眼比較價格、版稅與可用性。怎麼找，見搜尋與篩選；每張卡片顯示什麼，見卡片；清單沒有東西時，見沒有資料時。

搜尋框—比對 IP 名稱、權利人、關鍵字或內容描述

卡片

一張卡片是一筆可授權的 IP，點卡片進 IP 詳情。

欄位內容
IP 名稱與權利人標題是 IP 名稱，下方是權利人與可用名額，例如「5 名額剩 3」
起始價格固定租金的 IP 顯示「起 $420」；競標中的 IP 顯示「出價 $2,140 起」（數字為假設）
版稅比例例如「版稅 12%」
授權狀態Available（可租用）、Bidding（競標中）、Exclusive（獨家）
素材包完整度這筆 IP 目前的完整度，不是某一筆授權凍結的值，見素材包

沒有資料時

市場沒貨與帳號還沒開始用是兩種不同的情況，畫面分開。

情況畫面
整個市場可授權的 IP 太少（市場冷啟動）不顯示空的卡片格，改引導創作者「成為第一個上架者」
帳號還沒探索或租用過任何 IP（含第一次進來）清單退位，改以探索引導為主，說明可以在這裡瀏覽與租用其他創作者的 IP
搜尋與篩選不搶第一眼
清單載入中、載入失敗照全站共用的載入與錯誤狀態規則顯示

依據：5.1.3 F1、F2、F3、F4、頁面狀態；主規格 §6.1–§6.4、§7.1、§7.7「素材包」；D080、D150、D169。
