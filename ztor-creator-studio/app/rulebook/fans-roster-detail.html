粉絲詳情

創作者在粉絲詳情看一位粉絲的檔案、忠誠點數、行為、消費與參與紀錄，並從這裡發訊息給這位粉絲。

概述

  • 這一頁只彙整電子商店、活動、項目的紀錄，不重算
  • 金額和收入管理是同一個口徑
  • 分級、忠誠點數與狀態只顯示結果，怎麼算見粉絲分級與粉絲狀態
  • 行為、消費、活動與項目、標籤四類紀錄各有一區，見功能與欄位

操作流程

創作者從粉絲總覽點進一位粉絲，先看概況，再依需要查紀錄或聯絡這位粉絲。分級設定不從這一頁進，要調整分級規則回到粉絲總覽。

1從排行榜進來按某一列的「詳情」
2看概況粉絲檔案、忠誠點數與升級進度
3要做什麼？
行為、消費、活動與項目、標籤各看一區
群發訊息收件對象帶入這位粉絲
粉絲總覽保留原本的篩選、分級與搜尋

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 在粉絲總覽的排行榜按某一列的「詳情」進來
  2. 看粉絲檔案與忠誠點數與升級進度，掌握概況
  3. 要做什麼？
    • 查紀錄：看行為時間線、消費紀錄、活動與項目紀錄或標籤與長期貢獻
    • 聯絡這位粉絲：按「發訊息」，開啟群發訊息
    • 回到清單：點麵包屑回到粉絲總覽

依據：5.1.7.7 §2.1、§2.2、§4。

功能與欄位

各小節依序是：

  • 粉絲檔案：這位粉絲是誰，以及頁首的操作
  • 忠誠點數與升級進度：點數與離下一個分級還差多少
  • 行為時間線：做過哪些事
  • 消費紀錄：花了多少錢
  • 活動與項目紀錄：參與過哪些活動與項目
  • 標籤與長期貢獻：怎麼分類、怎麼記住長期支持
  • 沒有資料時：沒有紀錄時顯示什麼

粉絲檔案

粉絲檔案讓創作者認出這位粉絲是誰、目前在哪個分級、狀態如何。

  • 頁首顯示：
    • 頭像與姓名
    • Email、所在地與加入時間
    • 分級，名稱見四個分級
    • 狀態：活躍、流失風險或已挽回，條件見粉絲狀態
    • 標籤摘要，完整標籤見標籤與長期貢獻
功能或欄位出現條件與必填規則
麵包屑與返回—顯示來源路徑，例如「Fans / Wei Yu-han」
回到粉絲總覽時，保留原本的篩選、分級與搜尋
發訊息（Message）—開啟群發訊息，收件對象帶入這位粉絲
調整點數（Adjust points）只在 Admin 代管創作者時出現新增一筆調整，標題固定為「System Adjust」，不能自訂
加點或扣點，點數與原因必填
每次記成帳本的一筆，規則見Admin 手動調整點數
修改點數（每一筆的 ⋮）只在 Admin 代管創作者時出現修改這一筆的點數，必填原因
記成一筆校正分錄，連回原筆，不覆寫原值
不能刪除任何一筆
規則見Admin 手動調整點數
調整紀錄只在 Admin 代管創作者時出現列出每次新增與修改，欄位見下表

調整紀錄的欄位：

欄位新增一筆調整修改既有的一筆
調整內容「System Adjust」加原因原行為名稱加原因
修改前「—」原本的點數
修改後新的點數修改後的點數
修改額加減的點數，例如 +N前後差額，正負都可能
日期與時間、操作者每一筆都寫

每一筆調整紀錄也出現在行為時間線的「調整」分類。

忠誠點數與升級進度

這一區顯示這位粉絲的點數，以及離下一個分級還差多少。

指標內容
忠誠點數目前點數，附近 7 天入帳的點數，例如「近 7 天入帳 +38」（數字為假設）
天數預設 7 天，由 Admin 在平台忠誠點數設定調整
累積消費（Spent）累積消費金額，附訂單數
下一分級進度進度百分比與「還差 X 分」，算法見下方升級進度怎麼算
已是核心圈（Inner Circle）時改顯示「已達最高級」，副標「以維繫為重」，不顯示百分比
最近活躍距離最近一次互動多久，附互動內容
線下掃碼領點也會更新最近活躍

升級進度怎麼算

升級進度拿目前點數和下一級的門檻分數 D 比；門檻分數 D 會隨情況變：

情況門檻分數 D
目前點數低於最低忠誠點數門檻（預設 500）D＝500
目前點數達到 500D＝下一級目前最低分那位粉絲的分數；會隨其他粉絲的分數浮動
下一級目前沒有人視為已達該級，顯示 100%
已是核心圈沒有下一級，顯示「已達最高級」
  • 進度＝目前點數 ÷ D，最多 100%
  • 還差 X 分＝D − 目前點數
  • 從不到 500 達到 500 只是取得排名資格，名次要進前 % 名才真正升級，見兩道門檻
例：假設一般粉絲有 620 分，上榜粉絲目前最低分是 700 分，D＝700，進度 88.6%，還差 80 分。
  • 這一區要提示：點數即時入帳、達標即時升級；降級先倒數緩衝天數，到期後下一次每週重算仍未達標才降，見點數入帳與升降級的時機
  • 主要應援對象只能看到是或否，見主要應援對象的規則；這一欄要不要正式顯示，見頁尾尚待確認

行為時間線

行為時間線依時間列出這位粉絲在電子商店、活動、項目做過哪些事。

  • 依時間分組，列出電子商店、活動、項目與互動（例如留言、推薦好友）的行為
  • 每一筆寫出：
    • 行為
    • 來源
    • 時間
    • 金額
  • 純互動沒有金額
  • 每一筆寫出當時入帳的點數；Admin 新增的減分那一筆是負數
  • Admin 新增的調整，創作者也看得到：分類寫「調整」、標題寫「System Adjust」；原因與操作者只在 Admin 的調整紀錄
  • 附「點數從哪來」說明卡，概覽點數來自哪些行為，卡上的百分比是示意，不能編輯；各類行為怎麼給分見點數從哪來

每一筆的狀態如下。

狀態什麼時候畫面
一般照規則入帳的行為狀態欄空白，點數照入帳的寫
已人工修改Admin 改過這一筆的點數，記成一筆校正分錄，不覆寫原值狀態欄標「已人工修改」，點數寫修改後的合計淨值
已達上限這類行為在最近 90 天已達上限，這次入帳 0 點，上限見誠信規則照樣列出，狀態欄標「已達上限」，點數寫 0
已達上限後被改分Admin 把已達上限的那一筆改成大於 0改標「已人工修改」，不再標「已達上限」

掃碼領點的點數明細列

粉絲掃商家的 QR 領點成功一次，就在活動報到分類多一列；這一列取代原本活動報到分類沒有資料的空缺，不另開分類。

功能或欄位出現條件與必填規則
分類—活動報到
來源模組—標示「掃碼領點」
行為—場次名稱（掃碼領點類型的取貨場次）
副說明—QR 名稱
日期時間—領取時間
金額—無消費金額，顯示「—」
點數—+該 QR 設定的每次領取點數；不乘份量、不吃賽季加倍、不衰減，見發點規則
狀態—不會有「已達上限」，因為不受 90 天滾動上限
Admin 修改過這一筆就標「已人工修改」
修改點數（每一筆的 ⋮）只在 Admin 代管創作者時出現用來校正，會新增一筆校正分錄，不改原筆，規則見Admin 手動調整點數

消費紀錄

消費紀錄顯示這位粉絲花了多少錢、買了哪些商品、票券或項目。

指標內容
累積消費與上方 Spent 同一個數字，涵蓋商店、票券、項目
平均訂單金額累積消費 ÷ 訂單數
近 90 天消費附與前 90 天的比較
  • 消費明細逐筆列出：
    • 品項
    • 來源
    • 日期
    • 金額

活動與項目紀錄

這一區彙整這位粉絲參與活動、支持項目的紀錄，讓創作者了解參與深度。

  • 活動：名稱、狀態（例如已出席 Attended、已報名 RSVP'd）與日期
  • 項目：名稱、所選支持方案或追蹤中（Following）、日期
  • 項目有支持才有金額
  • 正式紀錄與管理操作仍在活動與項目各自的頁面

標籤與長期貢獻

標籤用來分類粉絲、方便在清單篩選；長期貢獻摘要記住長期支持的粉絲。

  • 標籤例如 VIP、High spender、Event attendee、Early backer
  • 長期貢獻摘要：
    • 成為粉絲多久
    • 累積消費
    • 名人堂的最高分級與達成年份，見名人堂
功能或欄位出現條件與必填規則
新增標籤—替這位粉絲加上一個標籤
可用的標籤由誰定義，見頁尾尚待確認

沒有資料時

  • 行為時間線、消費紀錄沒有資料時，各自顯示空狀態，不放假資料
  • 活動與項目紀錄的兩份清單各自顯示空狀態
