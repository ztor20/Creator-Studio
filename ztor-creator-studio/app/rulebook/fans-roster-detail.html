粉絲詳情

創作者在粉絲詳情看一位粉絲的檔案、忠誠點數、行為、消費與參與紀錄，並從這裡發訊息給這位粉絲。

概述

  • 這一頁只彙整電子商店、活動、項目的紀錄，不重算
  • 金額和收入管理是同一個口徑
  • 分級、忠誠點數與狀態只顯示結果，怎麼算見粉絲分級與粉絲狀態

操作流程

創作者從粉絲總覽點進一位粉絲，先看概況，再依需要查紀錄或聯絡這位粉絲。分級設定不從這一頁進，要調整分級規則回到粉絲總覽。

1從排行榜進來按某一列的「詳情」
2看概況粉絲檔案、忠誠點數與升級進度
3要做什麼？
行為、消費、活動與項目、標籤各看一區
群發訊息收件對象帶入這位粉絲
粉絲總覽保留原本的篩選、分級與搜尋

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 在粉絲總覽的排行榜按某一列的「詳情」進來
  2. 看粉絲檔案與忠誠點數與升級進度，掌握概況
  3. 要做什麼？
    • 查紀錄：看行為時間線、消費紀錄、活動與項目紀錄或標籤與長期貢獻
    • 聯絡這位粉絲：按「發訊息」，開啟群發訊息
    • 回到清單：點麵包屑回到粉絲總覽

依據：5.1.7.7 §2.1、§2.2、§4。

功能與欄位

各小節依序是：

  • 粉絲檔案：這位粉絲是誰，以及頁首的操作
  • 忠誠點數與升級進度：點數與離下一個分級還差多少
  • 行為時間線：做過哪些事
  • 消費紀錄：花了多少錢
  • 活動與項目紀錄：參與過哪些活動與項目
  • 標籤與長期貢獻：怎麼分類、怎麼記住長期支持
  • 沒有資料時：沒有紀錄時顯示什麼

    • Email、所在地與加入時間
    • 分級，名稱見四個分級
    • 狀態：活躍、流失風險或已挽回，條件見粉絲狀態
    • 標籤摘要，完整標籤見標籤與長期貢獻
功能或欄位出現條件與必填規則
麵包屑與返回—顯示來源路徑，例如「Fans / Wei Yu-han」
回到粉絲總覽時，保留原本的篩選、分級與搜尋
發訊息（Message）—開啟群發訊息，收件對象帶入這位粉絲
調整點數（Adjust points）Admin只在 Admin 代管創作者時出現新增一筆調整，標題固定為「System Adjust」、不能自訂
加點或減點，點數與原因必填，沒填原因不能送出，規則見Admin 手動調整點數

欄位新增一筆調整修改既有的一筆

修改前「—」原本的點數
修改後新的點數修改後的點數

這一區顯示這位粉絲的點數，以及離下一個分級還差多少。

指標內容
忠誠點數目前點數，附近 7 天入帳的點數，例如「近 7 天入帳 +38」（數字為假設）
天數預設 7 天，由 Admin 在平台忠誠點數設定設定
累積消費（Spent）累積消費金額，附訂單數
下一分級進度進度百分比與「還差 X 分」，算法見下方升級進度怎麼算

最近活躍距離最近一次互動多久，附互動內容
線下掃碼領點也會更新最近活躍

升級進度怎麼算

升級進度拿目前點數和下一級的門檻分數（簡稱 D）比；D 會隨情況變：

情況下一級的門檻分數（D）
目前點數低於最低忠誠點數門檻（預設 500）D＝500
目前點數達到 500D＝下一級目前最低分那位粉絲的分數；會隨其他粉絲的分數浮動
下一級目前沒有人視為已達該級，顯示 100%（規格另並列「已達最高級」，用哪一種見頁尾尚待確認）
已是核心圈沒有下一級，顯示「已達最高級」
  • 進度＝目前點數 ÷ D，最多 100%
  • 還差 X 分＝D − 目前點數
  • 從不到 500 達到 500 只是取得排名資格，名次要進前 % 名才真正升級，見兩道門檻
例：假設一般粉絲有 620 分，上榜粉絲目前最低分是 700 分，D＝700，進度 88.6%，還差 80 分。
  • 這一區要提示：點數即時入帳、達標即時升級、降級另有時機，見點數入帳與升降級的時機
  • 主要應援對象只能看到是或否，見主要應援對象的規則；這一欄要不要正式顯示，見頁尾尚待確認

行為時間線

行為時間線依時間列出這位粉絲在電子商店、活動、項目做過哪些事。

  • 依時間分組，列出電子商店、活動、項目與互動（例如留言、推薦好友）的行為
  • 每一筆寫出：
    • 行為
    • 來源
    • 時間
    • 金額
  • 純互動沒有金額
  • 每一筆寫出當時入帳的點數；調整點數新增的減分那一筆是負數
  • 調整點數新增的調整，創作者也看得到：分類寫「調整」、標題寫「System Adjust」；原因與操作者只在調整紀錄
  • 附「點數從哪來」說明卡，概覽點數來自哪些行為，卡上的百分比是示意，不能編輯；各類行為怎麼給分見點數從哪來

每一筆的狀態如下。

狀態什麼時候畫面
一般照規則入帳的行為狀態欄空白，點數照入帳的寫
已人工修改這一筆被修改過點數，記成一筆校正分錄，不覆寫原值狀態欄標「已人工修改」，點數寫修改後的合計淨值
已達上限這類行為在最近 90 天已達上限，這次入帳 0 點，上限見誠信規則照樣列出，狀態欄標「已達上限」，點數寫 0
已達上限後被改分已達上限的那一筆被改成大於 0改標「已人工修改」，不再標「已達上限」

活動與項目紀錄

這一區彙整這位粉絲參與活動、支持項目的紀錄，讓創作者了解參與深度。

  • 活動：名稱、狀態（例如已出席 Attended、已報名 RSVP'd）與日期
  • 項目：名稱、所選支持方案或追蹤中（Following）、日期
  • 項目有支持才有金額
  • 正式紀錄與管理操作仍在活動與項目各自的頁面

標籤與長期貢獻

標籤用來分類粉絲、方便在清單篩選；長期貢獻摘要記住長期支持的粉絲。

  • 標籤例如 VIP、High spender、Event attendee、Early backer
  • 長期貢獻摘要：
    • 成為粉絲多久
    • 累積消費
    • 名人堂的最高分級與達成年份，見名人堂
功能或欄位出現條件與必填規則
新增標籤—替這位粉絲加上一個標籤
可用的標籤由誰定義，見頁尾尚待確認

尚待確認

  • 頭像是否支援真實大頭照，以及預設樣式
  • 粉絲的正式識別依據用帳號 ID 還是 Email
  • Email、所在地、加入時間能顯示到什麼範圍、能不能複製或匯出
  • 哪些行為算「互動」、記錄到多細；從來沒有互動時，最近活躍顯示什麼
  • 近 7 天入帳是 0 或負數時，忠誠點數旁的小字顯示什麼
  • 平均訂單金額在沒有訂單時顯示什麼；近 90 天消費比前 90 天多、少、相同或前 90 天沒有資料時各顯示什麼
  • 粉絲還沒有標籤時，以及從來沒有進過名人堂時，這一區顯示什麼
  • 行為時間線有沒有分類切換、展開或載入更多的操作
  • 時間線的分組界線、更早紀錄怎麼載入、資料保留多久
  • 消費明細能不能點進對應的訂單詳情
  • 粉絲標籤由創作者自訂，還是由平台統一定義
  • 粉絲詳情要不要正式顯示「是否以你為主要應援對象」欄；全站活動的點數來源長條目前保留顯示
  • 下一級目前沒有人時，升級進度顯示 100% 還是「已達最高級」
  • 行為時間線、消費紀錄、活動與項目紀錄、標籤與長期貢獻四區，是否用切換的方式共用同一塊畫面（規格標為呈現參考）
