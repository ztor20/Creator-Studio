粉絲詳情

創作者在粉絲詳情看一位粉絲的檔案、忠誠點數、行為、消費與參與紀錄，並從這裡發訊息給這位粉絲。

概述

  • 這一頁只彙整電子商店、活動、項目的紀錄，不重算
  • 金額和收入管理是同一個口徑
  • 分級、忠誠點數與狀態只顯示結果，怎麼算見粉絲分級與粉絲狀態
  • 行為、消費、活動與項目、標籤四類紀錄各有一區，見功能與欄位

操作流程

創作者從粉絲總覽點進一位粉絲，先看概況，再依需要查紀錄、聯絡這位粉絲或調整分級規則。

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 在粉絲總覽的排行榜按某一列的「詳情」進來
  2. 看粉絲檔案與忠誠點數與升級進度，掌握概況
  3. 要做什麼？
    • 查紀錄：看行為時間線、消費紀錄、活動與項目紀錄或標籤與長期貢獻
    • 聯絡這位粉絲：按「發訊息」，開啟群發訊息

    • 回到清單：點麵包屑回到粉絲總覽

依據：5.1.7.7 §2.1、§2.2、§4。

功能與欄位

各小節依序是：

  • 粉絲檔案：這位粉絲是誰，以及頁首的操作
  • 忠誠點數與升級進度：點數與離下一個分級還差多少
  • 行為時間線：做過哪些事
  • 消費紀錄：花了多少錢
  • 活動與項目紀錄：參與過哪些活動與項目
  • 標籤與長期貢獻：怎麼分類、怎麼記住長期支持
  • 沒有資料時：沒有紀錄時顯示什麼

粉絲檔案

粉絲檔案讓創作者認出這位粉絲是誰、目前在哪個分級、狀態如何。

  • 頁首顯示：
    • 頭像與姓名
    • Email、所在地與加入時間
    • 分級，名稱見四個分級
    • 狀態：活躍、流失風險或已挽回，條件見粉絲狀態
    • 標籤摘要，完整標籤見標籤與長期貢獻
功能或欄位出現條件與必填規則
麵包屑與返回—顯示來源路徑，例如「Fans / Wei Yu-han」
回到粉絲總覽時，保留原本的篩選、分級與搜尋
發訊息（Message）—開啟群發訊息，收件對象帶入這位粉絲
分級設定（Tier settings）—前往分級設定，調整分級門檻與計分設定
系統說明（Fans Guide）—前往粉絲系統說明，看忠誠點數與分級的用詞
調整點數（Adjust points）只在 Admin 代管創作者時出現加點或扣點，必填原因
每次記成帳本的一筆，規則見Admin 手動調整點數
修改點數、刪除（每一筆的 ⋮）只在 Admin 代管創作者時出現修改這一筆的點數或刪除這一筆，必填原因，規則見Admin 手動調整點數
調整紀錄只在 Admin 代管創作者時出現列出每次新增、修改、刪除：調整內容與原因、修改前、修改後、修改額、時間與操作者

忠誠點數與升級進度

這一區顯示這位粉絲的點數，以及離下一個分級還差多少。

指標內容
忠誠點數目前點數，附近 7 天入帳的點數，例如「近 7 天入帳 +38」（數字為假設）
累積消費（Spent）累積消費金額，附訂單數
下一分級進度離下一分級的兩道門檻還差多少，門檻見兩道門檻
已是核心圈（Inner Circle）時改顯示「已達最高分級」，聚焦留存
最近活躍距離最近一次互動多久，附互動內容
  • 這一區要提示：點數即時入帳、達標即時升級；降級先倒數緩衝天數，到期後下一次每週重算仍未達標才降，見點數入帳與升降級的時機
  • 主要應援對象只能看到是或否，見主要應援對象的規則；這一欄要不要正式顯示，見頁尾尚待確認

行為時間線

行為時間線依時間列出這位粉絲在電子商店、活動、項目做過哪些事。

  • 依時間分組，列出電子商店、活動、項目與互動（例如留言、推薦好友）的行為
  • 每一筆寫出：
    • 行為
    • 來源
    • 時間
    • 金額
  • 純互動沒有金額
  • 每一筆寫出當時入帳的點數；Admin 新增的減分那一筆是負數
  • Admin 新增的調整，創作者也看得到：分類寫「調整」、標題寫「點數調整」；原因與操作者只在 Admin 的調整紀錄
  • 附「點數從哪來」說明卡，概覽點數來自哪些行為，卡上的百分比是示意，不能編輯；各類行為怎麼給分見點數從哪來

每一筆的狀態如下。

狀態什麼時候畫面
一般照規則入帳的行為狀態欄空白，點數照入帳的寫
已人工修改Admin 改過這一筆的點數狀態欄標「已人工修改」，點數寫修改後的
已達上限這類行為在最近 90 天已達上限，這次入帳 0 點，上限見誠信規則照樣列出，狀態欄標「已達上限」，點數寫 0
已達上限後被改分Admin 把已達上限的那一筆改成大於 0改標「已人工修改」，不再標「已達上限」
已刪除Admin 刪除這一筆從清單消失，只留在調整紀錄

消費紀錄

消費紀錄顯示這位粉絲花了多少錢、買了哪些商品、票券或項目。

指標內容
累積消費與上方 Spent 同一個數字，涵蓋商店、票券、項目
平均訂單金額累積消費 ÷ 訂單數
近 90 天消費附與前 90 天的比較
  • 消費明細逐筆列出：
    • 品項
    • 來源
    • 日期
    • 金額

活動與項目紀錄

這一區彙整這位粉絲參與活動、支持項目的紀錄，讓創作者了解參與深度。

  • 活動：名稱、狀態（例如已出席 Attended、已報名 RSVP'd）與日期
  • 項目：名稱、所選支持方案或追蹤中（Following）、日期
  • 項目有支持才有金額
  • 正式紀錄與管理操作仍在活動與項目各自的頁面

標籤與長期貢獻

標籤用來分類粉絲、方便在清單篩選；長期貢獻摘要記住長期支持的粉絲。

  • 標籤例如 VIP、High spender、Event attendee、Early backer
  • 長期貢獻摘要：
    • 成為粉絲多久
    • 累積消費
    • 名人堂的最高分級與達成年份，見名人堂
功能或欄位出現條件與必填規則
新增標籤—替這位粉絲加上一個標籤
可用的標籤由誰定義，見頁尾尚待確認

沒有資料時

  • 行為時間線、消費紀錄沒有資料時，各自顯示空狀態，不放假資料
  • 活動與項目紀錄的兩份清單各自顯示空狀態

依據：5.1.7.7 §2.1～§2.7、§3、§5；5.1.7 F7、F9～F12；主規格 §7.5；D169、D347、D348、D494、D495。

來源

尚待確認

  • 頭像是否支援真實大頭照，以及預設樣式
  • 粉絲的正式識別依據用帳號 ID 還是 Email
  • Email、所在地、加入時間能顯示到什麼範圍、能不能複製或匯出
  • 哪些行為算「互動」、記錄到多細
  • 時間線的分組界線、更早紀錄怎麼載入、資料保留多久
  • 消費明細能不能點進對應的訂單詳情
  • 粉絲標籤由創作者自訂，還是由平台統一定義
  • 粉絲詳情要不要正式顯示「是否以你為主要應援對象」欄；全站活動的點數來源長條目前保留顯示
  • 行為時間線、消費紀錄、活動與項目紀錄、標籤與長期貢獻四區，是否用切換的方式共用同一塊畫面（規格標為呈現參考）
