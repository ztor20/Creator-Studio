IP 詳情

創作者在 IP 詳情確認一筆 IP 能不能用、條件與價格如何，再決定送出租用申請或出價；從我的 IP 進來時，同一頁也顯示這筆 IP 的權利、授權與到期資訊。

概述

  • 入口有四個，離開時回到原本的頁面與脈絡：
    • IP 市場的卡片
    • 我的 IP的清單
    • 建立項目流程裡的 IP 租借
    • 管理 IP的「以承租方視角檢視」
  • 可以直接租用的 IP 顯示租用，要競標的顯示競標，兩者擇一
  • 擁有者調整定價、出租與設定在管理 IP，這頁是承租方評估的角度

操作流程

創作者進來後先看能不能用與條件，再依這筆 IP 的取得方式送出租用申請或出價；兩條路都要等擁有者或競標結果，送出當下還不是正式授權。

  • 從建立項目流程進來時，租用、申請或選好 IP 後回到原本的建立流程

功能與欄位

畫面由上到下依序是：

  • 導覽與返回
  • 可用狀態
  • IP 摘要
  • 條款與使用範圍
  • 租用或競標，依這筆 IP 的取得方式二選一
  • IP 資產管理資訊，只在從我的 IP 進來時出現
  • 素材或資料還沒好時，見沒有資料時

導覽與返回

功能或欄位出現條件與必填規則
來源路徑—例如「Artist IP Bank > IP 名稱」或「IP 資產 > IP 名稱」
返回—回到 IP 市場或我的 IP，保留原本的搜尋、篩選、分頁或分組

可用狀態

  • 顯示這筆 IP 目前能不能租用
  • 顯示可用名額與總名額，例如「3 of 5 slots」
  • 不能租用時寫明原因，例如：
    • 名額已滿
    • 授權暫停
    • 競標已結束
    • 權利資料待確認

IP 摘要

  • IP 名稱
  • IP 類型，見IP 類型
  • 權利人或授權方
  • 主要視覺或封面；素材還沒上傳時顯示佔位，不影響判讀授權條件

條款與使用範圍

  • 授權條款（Terms & Conditions）
  • 允許用途（Permitted Usage），例如：
    • 影片內容創作
    • 音樂影片
    • 短片
    • 社群內容
  • 版稅比例，例如「12% of revenue」
  • 有禁止用途、地區、期限或排他限制時，在這一區或租用區清楚標示
  • 揭露平台紀錄不等於正式合約，見平台紀錄與正式合約

租用

這筆 IP 可以直接租用時出現。價格的組成、請洽詢與尚未定價的顯示，見授權的定價。

功能或欄位出現條件與必填規則
一次性授權費（One-off licence fee）—只顯示；付一次就能使用，不依租期分段
分潤比例（Royalty on revenue）—只顯示
獨家授權擁有者有提供獨家授權時顯示獨立的一筆獨家授權費，不是在一次性授權費上加成
沒提供時不顯示，或標明不提供獨家
選獨家授權的影響見頁尾尚待確認
費用摘要—依序列出：
一次性授權費（已定價時）
分潤比例（已定價時）
幣別
任一項請洽詢時寫明待洽詢，不推算金額
有平台費、稅費或其他費用時分開列出
預估的費用不能顯示成已確認的收入
送出租用申請—送出前畫面要列出已知的費用與主要條件

這筆 IP 要透過競標取得授權時出現。

  • 沒得標或被超越時，保留重新出價或查看結果的入口
  • 實際付款與收入結算在收入管理，見收入總覽
