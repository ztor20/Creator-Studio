預覽與發布

創作者在建立項目的最後一步用粉絲視角看完整的項目頁，補譯文與各幣別價格，通過發布前檢核後發布項目或送出審核。四條路徑的全貌見建立項目。

概述

  • 這一步就是發布前的預覽確認畫面，預覽本身就是摘要，不另外列一份摘要
  • 直接發佈影片家族的這一步叫「預覽與送審（Preview & submit）」，主要操作是送出審核
  • 共創與預購的項目頁含交付時程，在這一步填或調整

操作流程

這一步從上一步按下一步開始，到發布或送出審核為止。

1看粉絲視角的項目頁可點區塊的編輯回對應步驟
2檢視語言與幣別
3發布前檢核都通過嗎？
4按發布項目影片路徑按送出審核
發布或送審
主要操作不能按點檢核項回對應的步驟或欄位

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 看粉絲視角的完整項目頁；要改就點該區塊的編輯，回到對應步驟
  2. 在側欄檢視四種語言的譯文與各幣別的價格
  3. 發布前檢核都通過嗎？
    • 通過：主要操作可以按
    • 沒通過：未通過的項目標紅，點它回對應的步驟或欄位
  4. 按「發布項目」，影片路徑按「送出審核」；按下即發布或送審，不再彈第二層確認

依據：5.1.2.1 §3.1、§4.3；主規格 §7.4；D310、D322。

功能與欄位

這一步是一個全頁畫面，分主區的項目頁預覽與右側的側欄。

項目頁預覽

主區顯示粉絲會看到的完整項目頁，依側欄選的語言與幣別呈現。

功能或欄位出現條件與必填規則
項目頁預覽—依選的語言與幣別呈現
可翻譯的文案可以在預覽裡直接改
區塊的編輯（Edit）每個區塊回到對應的步驟修改
預期交付（Expected delivery）只有共創與預購
必填		粉絲可以預期的交付日期
預購已在預購設定填過，這裡顯示並可調整同一筆；共創在這裡第一次填
里程碑（Milestones）只有共創與預購
選填		新增交付前的里程碑（＋ Add milestone），例如「Campaign funded」「Pre-production complete」「Shooting wraps」「Post-production」「Delivery to backers」
顯示已完成、進行中、未開始三種狀態

側欄

側欄由上而下分語言、幣別、發布前檢核三段，最下方是主要操作。

功能或欄位出現條件與必填規則
語言（Language）—四種語言的列表，其他三種由預設語言自動翻譯，可以檢視與修改，見語言與在地化
幣別（Currency）—基準幣別與四個換算幣別的列表
可以逐幣別覆寫價格，見定價幣別
發布前檢核（Pre-publish checks）—逐項標示通過或未通過，未通過的標紅，點它回對應的步驟或欄位，見發布前檢核
附上按下之後會發生什麼，見按下之後會發生什麼
發布項目（Publish project）影片路徑以外發布前檢核全部通過才能按，沒通過時是灰色
按下即發布，不再彈第二層確認
送出審核（Submit for review）只在直接發佈影片家族發布前檢核全部通過才能按
按下即送審，不再彈第二層確認

儲存草稿、返回與關閉見每一步都能用的操作。

依據：5.1.2.1 §4.3「預覽與側欄」、F10、發布操作；主規格 §7.4、§7.15；D306、D310、D322。

發布前檢核

下列檢核全部通過，發布項目或送出審核才能按；不適用這條路徑的項目不列。

#檢核項適用路徑通過條件
1關於項目全部項目名稱、內容類型、項目描述都已填
名稱與描述在預設語言那一份有值；其他語言在側欄的語言段處理，不列在這裡
2展示內容全部必要的展示素材已上傳
故事滿 100 字
3中段步驟全部依路徑完成營利設定、作品檔案與詳情定價、共創設定或預購設定的必填
4方案共創、預購共創至少 3 個方案
預購至少 1 個方案，且每個方案的含作品份數至少 1
5預購可售份數夠成立預購所有方案都設販售數量上限時，可售作品份數合計不少於最少預購數；任一方案不限量則跳過，見最少預購數怎麼數
6費用與時間清楚全部直接發佈非影片家族：平台費與發布時間清楚
直接發佈影片家族：平台費與上映日期清楚
共創、預購：交付時程清楚
7IP 租借全部關於項目提到用了他人 IP 時，已連結 IP 租借
8作品就緒直接發佈影片家族影片已上傳並處理完成
原始語音、封面圖、多語言標題與說明、片長、分類、年齡限制都有值；上映日期可以留白
付費時每個啟用的畫質，四個數值都是正數
每一份字幕都標了語言，同一語言沒有重複
封面圖與劇照符合展示素材的規格
和作品上架的檢核合成同一份，不各跑一次

依據：5.1.2.1 §4.3 F12；5.1.2.2.1 §8；D167、D192、D223。

按下之後會發生什麼

側欄的發布前檢核附上這一段，依路徑說明按下之後的結果；階段怎麼走見項目的階段。

路徑按下之後

粉絲觀看，或付費觀看、解鎖付費內容
收入來自觀看、單次付費與廣告

達標後分期撥款給創作者，沒達標退款
平台費只在達標時收

交付時程

共創與預購的項目頁會向粉絲揭露預期交付日期與進度里程碑，讓粉絲判斷要不要支持或預購；欄位見項目頁預覽。

  • 預購的預期交付和預購設定的預期交付是同一筆，兩處都能改
  • 直接發佈沒有交付時程

依據：5.1.2.1 §4.3 F10、§5.3.1 F27。
