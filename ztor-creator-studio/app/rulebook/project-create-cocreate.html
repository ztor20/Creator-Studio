共創設定

共創項目的創作者在第 3 步設共創目標、周期、資金分配與預算分配，作為粉絲支持的動機與平台計費的基準。四條路徑的全貌見建立項目。

概述

  • 只有共創走這一步，下一步是方案，方案價格用到這一步算出的單位成本
  • 共創目標決定項目算不算成功，見項目的階段

這一步從展示內容按下一步開始，到進入方案為止。

依據：5.1.2.1 §5.2.1 F19～F23。

功能與欄位

這一步有五塊：頂部的退款承諾、共創目標與周期、資金分配、預算分配與欄位的各種狀態。

退款承諾

這一步最上方的綠色提示框，告訴創作者支持者零風險。

功能或欄位出現條件與必填規則
退款提示—文案「Your backers take zero risk. If goal not met, every backer refunded.」
未達標一律全額退款

共創目標與周期

決定共創要募多少、開放多久。

功能或欄位出現條件與必填規則
共創目標（Co-create goal）必填金額，提示「10000」
最低 $500，下方提示「Minimum $500」
決定項目算不算成功與交付時程
共創周期（Co-create length）必填天數，7～90，預設 30，下方提示「7-90 days」
天數從哪裡起算，見項目的時間

資金分配

標題是「Distribution settings」，設資金池百分比與支持者位數，算出單位成本。

功能或欄位出現條件與必填規則
資金池百分比（Pool %）必填數字，例如 10
百分比代表誰得到多少，說明跟範例對不起來，見頁尾尚待確認
支持者位數（Supporter slots）必填數字，例如 100，整個共創最多幾個支持者名額
單位成本（Per slot）自動算出，唯讀共創目標 ÷ 支持者位數，例如「$10」
也是方案價格裡每個名額的單價，見方案價格怎麼算
分配提示—說明最終淨額怎麼分，提示文案例如「If $200k net, each slot = $200」
平台費提示—「5% platform fee (only if goal met) + 3% Stripe. No fees if goal not met.」
平台費只在達標時收，口徑見項目的類型

預算分配

標題是「Budget allocation」，設總共創金額的分配比例，用分色的堆疊長條顯示。

功能或欄位出現條件與必填規則
堆疊長條圖—用顏色顯示總共創金額的分配比例，唯讀
項目名稱每一列一項文字，例如 Production、Marketing、Talent、Operations
百分比每一列一項數字（%）
移除（×）每一列移除這一項
新增項目（＋ Add category）—加一列
總和檢查—合計必須是 100%，達到時顯示勾號
未達 100% 不能進下一步

欄位的各種狀態

狀態什麼時候畫面
共創目標
達到最低金額共創目標至少 $500下方提示「Minimum $500」
低於最低金額共創目標低於 $500尚待確認
共創周期
預設沒改過30 天，下方提示「7-90 days」

依據：5.1.2.1 §5.2.1 F19～F23。

達標後的募得款撥付

共創達標後項目成功，募得款依項目預算分期撥付給創作者，期數與各期條件見財務術語與收入事件。

依據：5.1.2.1 §5.2.1 F19、F22；主規格 §7.3；D345、D346。

尚待確認

  • 共創的開募時間在哪裡設定（共創周期從開募起算）

  • 資金池百分比代表誰得到多少：規格寫「創作者最終得到的百分比」，規格範例（淨額 20 萬、10%、100 個名額、每個名額 200）算出來是支持者分到 10%
  • 共創目標低於最低金額、共創周期超出範圍、單位成本算不出來、預算分配超過 100% 或沒有項目時，畫面怎麼顯示
