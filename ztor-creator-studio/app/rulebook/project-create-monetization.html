營利設定

直接發佈非影片家族的創作者在第 3 步決定粉絲怎麼取得內容、要不要廣告與品牌合作，以及什麼時候發布。四條路徑的全貌見建立項目。

概述

  • 只有直接發佈非影片家族走這一步；影片家族改走作品檔案、詳情與定價
  • 這一步的設定是收入管理與項目淨利的初始收益資料
  • 發布後依存取模式與廣告營利，沒有達標門檻、不送審

操作流程

這一步從展示內容按下一步開始，到進入預覽與發布為止。

2填價格
3廣告與品牌合作選用
4什麼時候發布？

預覽與發布

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號；虛線框可以略過。

  1. 選存取模式：免費、單次付費觀看或混合模式
    • 免費：直接往下
    • 單次付費觀看、混合模式：填價格
  2. 填價格，下方自動算出收入估算
  3. 要的話開啟廣告、新增品牌合作
  4. 選什麼時候發布
    • 立即發布：通過預覽與發布後直接上線
    • 稍後排程：設發布日期與時間
  • 兩種發布時間都可以另設下架日期與時間，見發布時間

依據：5.1.2.1 §5.1.1 F13～F18。

功能與欄位

這一步有四塊：存取模式與價格、廣告、品牌合作與發布時間。

存取模式與價格

決定粉絲怎麼取得內容。

功能或欄位出現條件與必填規則
存取模式（Access model）必填，三選一免費（Free）：副標「Ad-supported」，免費觀看或取得，搭配廣告收入
單次付費觀看（Pay per view）：副標「One-time purchase」，一次性購買
混合模式（Hybrid）：副標「First free, rest paid」，部分免費、後續付費
價格（Price）選單次付費觀看或混合模式才出現，出現時必填金額，提示「9.99」，顯示幣別
收入估算跟著價格出現例如「If 1,000 fans watch at $9.99, you earn approximately $8,491.5」，已扣掉平台費與 Stripe 手續費，見平台費
平台費說明—見平台費

廣告

用廣告位置賺額外收入；免費模式可以把廣告當主要收入。

功能或欄位出現條件與必填規則
廣告（Enable ads）—開關，預設關，副標「Earn additional revenue from ad placements」
廣告位置開啟廣告後選項與規則見頁尾尚待確認

品牌合作

記錄贊助、推廣、分潤或品牌合作的收入。

功能或欄位出現條件與必填規則
新增品牌合作（＋ Add brand）選填可以在這裡先設，也可以在項目上線後補登

發布時間

決定項目什麼時候上線、什麼時候下架。

功能或欄位出現條件與必填規則
發布時間（Publish timing）必填，二選一
預設立即發布		立即發布（Immediately）：通過預覽與發布後直接上線
稍後排程（Schedule for later）：展開發布日期與時間
上線前後的項目階段，見發布時間與項目階段
發布日期與時間選稍後排程時出現，出現時必填到時項目上線
下架日期與時間（Unlist time）選填
兩種發布時間都出現		到時項目頁自動轉為看不到
不填就不自動下架

依據：5.1.2.1 §5.1.1 F13～F18；D239。

平台費

直接發佈對營收抽成，費率與誰負擔見項目的類型。收入估算與預覽與發布都要清楚標示平台費，避免創作者以為顯示的收入就是可提領的錢。

依據：5.1.2.1 §5.1.1 F14、F15；主規格 §7.3、§7.6；D316。

發布時間與項目階段

這一步的發布是項目看得到的起點；直接發佈非影片家族看得到就買得到，不另設販售期間。

  • 立即發布：按下發布就上線，項目轉已上線
  • 稍後排程：排程期間項目在準備中，到發布時間轉已上線
  • 兩段時間的完整規則見項目的時間

依據：5.1.2.1 §5.1.1 F18「兩軸對應」；主規格 §7.2；D239。

營利設定與 IP 租借的分別

廣告與品牌合作是營利設定的延伸收入；IP 租借屬關於項目的權利揭露，不是營利模式，見IP 在項目裡的身分。

依據：5.1.2.1 §5.1.1 F17；D232。
