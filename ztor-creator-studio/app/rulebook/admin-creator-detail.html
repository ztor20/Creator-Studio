Creator 詳情

Admin 在這頁查看單一創作者的資料、修改店鋪網址與電話，並就地停用、啟用或進入他的工作區。

概述

  • 從Creator 列表的「編輯」進入，是這頁唯一的入口
  • 創作者的身分來自他自己註冊的 ztor 帳號，這頁不能改
  • 這位創作者的 bookyay 活動在創作者活動管理處理，這頁只顯示已對應的場數

操作流程

Admin 從名冊進來，確認是哪一位創作者，改完儲存。

1按「編輯」進入從 Creator 列表的那一列
2找得到這位創作者嗎？
3修改店鋪網址或電話
找不到這位創作者提供回到名冊的入口
4店鋪網址跟別人重複嗎？
5儲存修改成立
擋下說明網址已被使用

流程圖：由左往右走，上面一列是正常的路，下面一列是被擋下的情形，圓圈數字對應下方步驟清單。

  1. 在 Creator 列表按「編輯」進入
  2. 找得到這位創作者嗎？
    • 是：顯示身分列、帳號來源與商店聯絡方式
    • 否：顯示找不到這位創作者，見找不到這位創作者
  3. 修改店鋪網址或電話，欄位見商店與聯絡方式
  4. 店鋪網址跟別的創作者重複嗎？
    • 否：可以儲存
    • 是：擋下並說明
  5. 儲存後修改成立；按取消則整份丟棄
  • 停用、啟用與前往工作區在身分列直接做，見身分列

依據：5.1.0.5 F1、F2、頁面狀態、情境；D107、D218。

功能與欄位

畫面由上到下是身分列、帳號來源、商店與聯絡方式。誰在看、能做哪些就地操作，見身分列；哪些資料不能改，見帳號來源；能改的欄位，見商店與聯絡方式；連結失效時，見找不到這位創作者。

身分列

讓 Admin 一眼確認正在看哪一位創作者、他現在的營運狀態，並就地處理，不必退回名冊。

功能或欄位出現條件與必填規則
頭像—唯讀，沿用這位創作者的 ztor 帳號
名稱—唯讀，沿用這位創作者的 ztor 帳號
店鋪網址—唯讀，意思同Creator 列表的清單
創建時間—唯讀，意思同Creator 列表的清單
狀態—唯讀，意思見創作者的狀態
已匯入 M 場活動（Imported Events）—唯讀，M 是 0 也顯示
M＝已對應給這位創作者的活動數
點了前往創作者活動管理，清單只列這位創作者的活動，見篩選與搜尋
停用（Disable）狀態是啟用中跟名冊上的停用是同一個操作、同一個效果，見創作者的狀態
啟用（Enable）狀態是已停用切回啟用中
前往工作區（Enter Workspace）—進入這位創作者的工作區代為操作，見代為操作創作者的工作區

帳號來源

這一組全部唯讀。ztor 帳號是創作者的身分來源，換掉等於換一個人；要換人就建立另一位創作者，不是編輯。

功能或欄位出現條件與必填規則
名稱—唯讀，沿用 ztor 帳號
email—唯讀，沿用 ztor 帳號
創建時間—唯讀，建立創作者時自動記錄
幣別（創作者幣別）—唯讀
建立創作者時由 Admin 選定，之後創作者與 Admin 都不能改，見建立創作者

商店與聯絡方式

Admin 在這頁唯一能改的一組。修改在按儲存之前不成立。

功能或欄位出現條件與必填規則
店鋪網址（Shop URL）—全平台唯一
儲存時檢查重複，不跟自己比
電話（Phone）選填—
儲存—店鋪網址重複時擋下並說明
沒有重複就儲存，修改成立
取消—丟棄這次所有沒儲存的修改

找不到這位創作者

開到一位不存在的創作者時（例如連結失效），整頁只顯示找不到的說明與回到名冊的入口。

  • 不改顯示另一位真實存在的創作者，免得 Admin 以為在改 A、實際上在改 B

依據：5.1.0.5 F1、F2、頁面狀態；5.1.0 F2、F3；D107、D218、D233、D316、D326、D372。
