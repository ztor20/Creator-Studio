平台費率設定

Admin 在這頁設定全平台的平台費率與支付費，並可對個別創作者設不同的平台費率。費率怎麼套進一筆交易的金額、由誰負擔，見優惠規則的平台費與支付費怎麼算。

概述

  • 這頁是平台費率唯一的設定處，只有 Admin 能進入與修改，沒有權限時顯示無權限狀態
  • 創作者在商品細節、訂單與收入頁只看得到套用後的費率，不能改
  • 平台費分兩層：全平台的預設值，以及對個別創作者的覆寫
  • 每次儲存都產生一個新的費率版本，只對之後的交易生效，見改費率只對之後生效

操作流程

Admin 先選要改全平台預設還是某位創作者的覆寫，改完儲存成一個新版本。

1要改哪一層？設定模式
2改預設費率平台費與支付費
選一位創作者沒選不顯示可覆寫的費率
逐項覆寫或清除其餘沿用預設
3儲存產生新的費率版本
4新費率生效只對生效時間之後的交易

流程圖：由左往右走，上面一列改全平台預設，下面一列改某位創作者的覆寫，兩條路在儲存合流；圓圈數字對應下方步驟清單的編號。

  1. 選設定模式
    • 預設：改全平台的預設費率
    • 覆寫：先選一位創作者，再逐項覆寫或清除，見逐創作者覆寫
  2. 改預設費率，欄位見平台費與支付費的預設值
  3. 儲存，產生一個新的費率版本
  4. 新費率只對生效時間之後的交易生效，既有交易不變

依據：5.1.0.3 F2、F3、F4、情境；D041、D141。

平台費與支付費的預設值

頁面上方先選設定模式，預設與覆寫共用這一格：

功能或欄位出現條件與必填規則
設定模式—二選一
預設（General）：設全平台的預設值
覆寫（Override）：對一位創作者設不同的值，見逐創作者覆寫

設定模式選預設時，Admin 在這裡設全平台通用的費率。平台費逐交易類型設定，見平台費；金流商的手續費另設一組，見支付費。

平台費

平台費是平台從每筆成交抽成的比例。費率分四個維度，每個維度展開成幾種交易類型，費率設在交易類型這一層。

功能或欄位出現條件與必填規則
維度—四個：電子商店、活動、項目、IP
可以展開、收合
維度本身不設費率
各交易類型的費率（%）—可以改
每一種交易類型各有一個費率
費率說明—可以替每一種交易類型附說明，例如「拍賣低於一般商品是刻意區分」
維度交易類型
電子商店（E-Shop）直售·實體商品
直售·數位商品
拍賣商品（成交時）
活動（Events）現場活動票券
線上活動票券
項目（Projects）交易類型的歸類尚待確認，見頁尾
IP（IP Bank／IP Market）交易類型的歸類尚待確認，見頁尾
  • 畫面上的費率數字是示意值，不是正式費率
  • 成本價、毛利、淨利不在這頁設定

支付費

支付費是金流商的手續費，跟平台費是兩筆不同的扣項，不分維度。

百分比—可以改
每筆固定額—可以改
以平台基準幣別記錄（平台自己的記帳幣別，預設港幣），不是任何一位創作者的幣別
套用到某位創作者時，依當時匯率換算成他的創作者幣別再算
畫面同時顯示換算後金額與匯率時點
幣別規則見定價幣別

依據：5.1.0.3 頁面定位、F2；主規格 §7.3、§7.6、§7.15；D085、D139、D141、D169、D316、D455。

逐創作者覆寫

覆寫讓 Admin 對個別創作者給跟預設不同的平台費率，處理個別合約或優惠。怎麼設，見選創作者與覆寫；誰設過覆寫，見覆寫清單。

選創作者與覆寫

各交易類型的覆寫值選定創作者後一次改一種交易類型，其餘自動沿用預設

覆寫值與預設值在畫面上要分得出來

費率怎麼生效

一筆交易在成交當下決定套哪個費率，之後改費率不會改到它。套哪一個值，見一筆交易套用哪個費率；改了之後影響哪些交易，見改費率只對之後生效。

一筆交易套用哪個費率

平台費依序找兩層，找到就用：

  1. 這位創作者對這種交易類型的覆寫值（有設的話）
  2. 全平台預設中這種交易類型的值
  • 找到的費率連同費率版本，在成交當下一起記進那筆收入
  • 收入管理、訂單詳情、商品細節與拍賣商品細節顯示的平台費與支付費，都讀這頁的設定、不另外計算；顯示的是那筆交易記下的費率，不是這頁目前的值
  • 平台費與支付費在收入拆解中各是一筆扣項，用詞見財務術語與收入事件；計費基準與負擔方見平台費與支付費怎麼算

改費率只對之後生效

  • 每次儲存（不論預設或覆寫）都凍結成一個不能修改的費率版本
  • 新費率只對生效時間之後產生的收入生效
  • 已經發生的收入與它的沖銷分錄，一律沿用當時記下的版本與費率，日後改預設或覆寫都不會改寫
  • 版本歷史只增不改，更正以新版本表示

依據：5.1.0.3 F3、F4、F5；主規格 §7.3、§7.6；D041、D141、D253、D278、D315、D316。

來源與尚待確認

來源

  • 規格：5.1.0.3-平台費率設定.md（v1.11）、0-設計規格書.md §4.1／§7.3／§7.6／§7.15
  • 決策：D041、D085、D139、D141、D169、D253、D274、D278、D315、D316、D391、D455

尚待確認

  • 各交易類型的正式費率（畫面上顯示的百分比是示意值）
  • 組合商品要不要成為電子商店底下的一種交易類型
  • 活動的報名與免費活動處理費要不要成為一種交易類型（可為 0）
  • 項目的交易類型歸類（目前列共創成功抽成、預購成交抽成、實體回饋履約、數位回饋履約）
  • IP 的交易類型歸類（目前列 IP 授權金抽成、版稅分潤抽成、IP 租用抽成）
  • 原型多出的第五個維度「OTT・Streaming」（例如付費點播）要不要納入
  • 支付費是否逐金流商各設一組百分比與固定額（原型示意 Atom、Stripe 兩家），資料怎麼記
  • 一筆交易記下費率時，怎麼記實際套用的金流商
  • 生效時間怎麼設定（立即生效或指定日期）
  • 頁面載入中、儲存失敗時怎麼顯示
