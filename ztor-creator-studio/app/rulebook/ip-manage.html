管理 IP

擁有者在管理 IP 以擁有者的角度管理一筆 IP：看經營成效與權利歸屬、調整授權定價、查看出租中的租約，並控制接單、計價模式、到期提醒與刪除。

概述

  • 只從我的 IP清單的「Manage」進入；承租方評估一筆 IP 看的是 IP 詳情，兩頁並存、不互相取代
  • 權利人與分潤比例在這頁只看得到唯讀摘要，正式設定在 Admin 的 IP Bank

操作流程

擁有者從我的 IP 進來後，先確認這筆 IP 的狀態與成效，再決定要調整哪一塊。

1我的 IP按「Manage」
2確認狀態與成效身分列、總覽指標、權利歸屬
3要調整什麼？
授權定價按「Save licensing changes」
出租
出租營運設定
刪除確認輸入密碼才能送出
IP 詳情以承租方視角檢視

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 在我的 IP 按該列的「Manage」進入
  2. 確認這筆 IP 的狀態與成效：見身分列、總覽指標、權利歸屬
  3. 要調整什麼？

功能與欄位

畫面由上到下依序是：

  • 身分列
  • 總覽指標
  • 權利歸屬
  • 授權定價
  • 出租
  • 出租營運設定
  • 刪除 IP（與其他設定明顯區隔）

身分列

讓擁有者確認自己在管理哪一筆 IP，以及它目前的上架與驗證狀態。

功能或欄位出現條件與必填規則
麵包屑—顯示「IP Bank / My IP / IP 名稱」
點 My IP 回到我的 IP，保留原本的自有或租入分頁與搜尋
IP 名稱、IP 類型—只顯示；類型見IP 類型
來源—Made on Ztor（在 Ztor 上產出）或 Registered externally（站外登錄）
上架狀態徽章—未上架、暫停接單、已在 IP 市場上架三選一，由市場上架開關與接受新租約兩個開關決定，見上架狀態
驗證狀態—已驗證時顯示徽章；驗證中或站外登錄待驗證時改在頁首顯示橫幅，見上架狀態
以承租方視角檢視（View as renter）未上架時不出現進 IP 詳情，看承租方會看到的樣子

總覽指標

擁有者一進頁先看這筆 IP 的經營成效。

  • IP 收益（IP revenue）：這筆 IP 年初至今的累計收益，口徑與幣別同收入管理，這頁不重算
  • 進行中租約數（Active rentals）：目前生效中的授權份數，見授權的階段
  • 目前費率（Current rate）：照授權定價的設定即時組成，例如「$6,800 + 12% royalty」（數字為假設），組字方式見價格摘要

權利歸屬

這筆 IP 屬於誰、授權可以用到哪裡；排在授權定價之前，因為權利歸屬是定價的前提。權利人只顯示、不能改；授權地區、權屬證明、授權用途目前只顯示，能不能在這頁修改見頁尾尚待確認。

欄位內容
權利人（Rights holders）權利人與分潤比例摘要，例如「Maya Chou · 100%」或「Maya Chou + Lin Yiwen · 60/40」
正式設定、驗證與多位權利人的規則在 Admin 的 IP Bank
授權地區（Territory）例如「Worldwide」「Taiwan · Hong Kong · Macau」
原始設定來自登錄 IP 第 2 步
權屬證明（Proof of ownership）已上傳的檔名；沒上傳顯示「尚未上傳」
授權用途（Permitted usage）允許的使用情境清單；沒設定顯示「尚未設定」

授權定價

擁有者在這裡設定對外授權的價格，是這頁唯一會動到金額的區塊。價格的組成與請洽詢的規則，見授權的定價。

功能或欄位出現條件與必填規則
市場上架開關（List in IP Market）選填
預設關閉		跟我的 IP 清單的 Mktplace 是同一個開關，見市場上架開關
一次性授權費（One-off licence fee）沒勾請洽詢時必填金額，不能是負數
預設空白，代表還沒定價
請洽詢（Price on request，一次性授權費）選填勾選後輸入框收起；各處怎麼顯示見請洽詢與尚未定價
收益分潤（Royalty on revenue）沒勾請洽詢時必填百分比，每次增減 0.5
可填的範圍見頁尾尚待確認
預設空白，代表還沒定價
請洽詢（Price on request，收益分潤）選填規則同一次性授權費的請洽詢
獨家授權費（Exclusive licence fee）選填金額，不能是負數
留空代表不提供獨家授權，不是還沒定價
也可以勾選請洽詢
承租方會看到（Renters will see）—只顯示；即時套用上面三欄與各自的請洽詢，組成一句價格說明
顯示規則見價格摘要
既有租約提示這筆 IP 有進行中的租約時提示這次修改只套用於之後新成立的租約，已生效的租約維持簽署時的條款，見修改已生效的條款
儲存授權設定（Save licensing changes）—送出這一區的變更，送出後要明確回饋已儲存
儲存不等於已生效的正式授權變更

出租

擁有者查看這筆 IP 目前對外的授權租約。

  • 只列已生效或即將到期的租約；別人送來、還在等核准的申請在我的 IP 的授權核准佇列
  • 每一列顯示哪些欄位、狀態怎麼稱呼，見頁尾尚待確認
  • 還沒有任何租約時顯示「尚無租約」，並說明這筆 IP 通過驗證並上架後，租約會出現在這裡

出租營運設定

日常的接單控制。

功能或欄位出現條件與必填規則
接受新租約（Accept new rentals）選填開：接受新的租用申請
關：暫停接單但不下架，既有租約不受影響
跟市場上架開關各自獨立，見接受新租約
計價模式（Bidding mode）選填固定租金（Flat rental）或限時競標（Auction）二選一，決定下一個可承租檔期怎麼出租
徽章顯示目前的模式，按鈕切換，見直接租用或競標
到期提醒（Expiration alerts）選填開：任一租約到期前提醒，並出現在儀表板的今日待處理，見授權的期限與到期提醒

刪除 IP

刪除是不可復原的操作，在畫面上跟其他設定明顯區隔；要在確認畫面看清影響範圍、輸入密碼才能送出。

功能或欄位出現條件與必填規則
刪除 IP（Delete IP）—開啟刪除確認；永久移除這筆 IP，無法復原
將被移除的內容刪除確認裡列出三項：
IP 紀錄、授權條件與定價
收益分配歷史與收益歸屬
IP 市場的上架刊登
進行中租約警告這筆 IP 有進行中的租約時說明承租方在授權期滿前仍有合約效力，要先結清或等到期
目前只是提示，不擋刪除，見頁尾尚待確認
密碼—必填
輸入密碼作二次確認，驗證在伺服器端做
取消—關閉確認，不刪除
永久刪除—密碼欄有內容才能按
送出刪除

尚待確認

  • 驗證還沒完成時，上架與定價的操作是否真的擋下
  • 以承租方視角檢視是否帶入同一筆 IP 的識別碼，確保開到同一筆的 IP 詳情
  • 授權地區、權屬證明、授權用途能不能在這頁修改或重新上傳，還是只能在登錄時設定
  • 金額是否支援多幣別（目前固定顯示 $）
  • 收益分潤的範圍：這頁規格寫 0–100，登錄時限 0–30%
  • 修改定價後，是否強制保證既有租約不受影響、是否開新費率版本
  • 出租清單每一列的欄位與狀態用詞（畫面示意為承租方、檔期、金額，以及「進行中」「即將到期」兩種狀態；是否改對齊授權的五個階段）
  • 這頁要不要也顯示待核准申請的摘要或連到授權核准佇列
  • 接受新租約、計價模式、到期提醒三個設定的預設值
  • 切換計價模式後，承租方在 IP 詳情看到的模式怎麼連動
  • 到期提醒提前幾天送出（畫面示意為 14、7、1 天）
  • 有進行中的租約時是否直接禁止刪除（風險較高，建議優先釐清）
  • 密碼確認失敗時的錯誤畫面與重試次數限制
  • 從租入 IP 的列按 Manage 進來時，這頁能做什麼
  • 這頁與 IP 詳情頁（從我的 IP 進入時）兩邊的擁有者管理資訊怎麼分工
