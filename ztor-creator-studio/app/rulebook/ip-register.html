登錄 IP

創作者用四個步驟把一筆 Ztor 之外既有的 IP 登錄進 IP 資產，記下類型、使用規則與分潤，並決定要上架出租還是保持私有。

概述

  • 只有站外既有的權利走這個流程；在 Ztor 上由項目產出的 IP 會自動建立紀錄，見兩種來源
  • 送出後建立一筆 IP 紀錄，回到我的 IP；選上架出租的，也出現在 IP 市場
  • 選保持私有也算登錄完成，之後可以再上架，見上架出租或保持私有

操作流程

這個流程從我的 IP 按「＋ Add your IP」開始，到送出審閱、回到我的 IP 為止。

1我的 IP按「＋ Add your IP」
2類型與資訊
3使用規則
4要上架出租嗎？先填分潤比例
填定價一次性授權費、獨家授權費
5審閱可回任一步修改
6建立 IP 紀錄回到我的 IP

流程圖：由左往右走，上面一列是上架出租、下面一列是保持私有；圓圈數字對應下方步驟清單的編號。

  1. 從我的 IP 按「＋ Add your IP」進入，畫面頂端有關閉與四步進度
  2. 第 1 步類型與資訊：選 IP 類型，填名稱與描述，可附所有權證明，見第 1 步：類型與資訊
  3. 第 2 步使用規則：選允許用途與授權地區，見第 2 步：使用規則
  4. 第 3 步定價與收益：填分潤比例，再決定要不要上架出租，見第 3 步：定價與收益
    • 上架出租：接著填定價
    • 保持私有：不顯示定價，直接到審閱
  5. 第 4 步審閱：核對三張摘要卡，要改就按 Edit 回到該步，見第 4 步：審閱
  6. 送出：建立 IP 紀錄，回到我的 IP
  • 每一步必填沒填齊，不能進下一步

依據：5.1.4.1 §1、§2、§3、§4；5.1.4 F6；D037。

功能與欄位

四個步驟各一個畫面：第 1 步：類型與資訊、第 2 步：使用規則、第 3 步：定價與收益、第 4 步：審閱；每一步共用的關閉與進度，見每一步都有的操作。

功能或欄位出現條件與必填規則

第 1 步：類型與資訊

記下這筆 IP 是什麼。

功能或欄位出現條件與必填規則
IP 類型（IP Type）必填，單選六張卡：Story World、Music、Person-Based、Brand、Event Format、Other，分類見IP 類型
IP 名稱（IP Name）必填2–100 字元
下方顯示字數計數
描述（Description）必填10–2000 字元
寫這筆 IP 是什麼、價值在哪裡
所有權證明（Proof of Ownership）選填上傳合約、證書或創作證據
接受 PDF、JPG、PNG，單檔上限 10MB
有助於驗證，跟驗證狀態的關係見頁尾尚待確認

第 2 步：使用規則

決定承租方可以拿這筆 IP 做什麼、在哪裡用。

功能或欄位出現條件與必填規則
允許用途（Permitted Usage）必填，多選，至少一項選項：
Streaming（VOD／PPV）：承租方可以做串流影片內容
Adaptation（衍生作品）：以這筆 IP 為基礎的新故事、角色或內容
Promotion only：只做行銷宣傳，不做獨立內容
Merchandise：有這筆 IP 的實體或數位商品
Live events：用這筆 IP 辦演唱會、放映或見面會
授權地區（Territory）必填，多選，至少一項選項：
Worldwide

提示文案寫「Worldwide 涵蓋所有地區，取消 Worldwide 才能選個別地區」；互斥邏輯見頁尾尚待確認

第 3 步：定價與收益

先定分潤比例，再決定要不要上架出租；價格的組成與請洽詢的規則，見授權的定價。

功能或欄位出現條件與必填規則
版稅比例（Royalty Rate）必填：填比例或勾選請洽詢0–30%
畫面文案寫：從每個用到這筆 IP 的項目的毛營收（gross revenue）中分到的比例，業界參考 5–15%
分潤的計算基礎見IP 授權規則頁尾尚待確認
分潤請洽詢（Royalty on request）選填勾選後不公開比例，比例欄收起
要上架出租嗎（List this IP for rental?）必填，兩張卡選一張上架出租（List for rental）：其他創作者可以瀏覽與租用
保持私有（Keep private）：只有自己能用，之後可以再上架
結果見上架出租或保持私有
一次性授權費（One-off licence fee）只在選上架出租時出現
必填：填金額或勾選請洽詢，二選一		金額，前綴 $，要是有效的正值
幣別照收入管理的設定
價格請洽詢（Price on request，一次性授權費）只在選上架出租時出現
選填		勾選後不公開金額
獨家授權（Exclusive licence）只在選上架出租時出現
選填		金額，前綴 $，填了就要是有效的正值
留空代表不提供獨家授權
也可以勾選請洽詢

定價區下方提示上架後的出租照授權的階段走：承租方提出、擁有者核准、條款齊全才生效，見授權的階段。

第 4 步：審閱

送出前核對前三步填的內容。

功能或欄位出現條件與必填規則
類型與資訊摘要卡—名稱、類型、所有權證明（沒上傳顯示「Not uploaded」）
使用規則摘要卡—允許用途標籤、授權地區標籤
定價與收益摘要卡—版稅：例如「12% of gross revenue」；勾選請洽詢時顯示「Royalty on request」
上架：保持私有顯示「No, private」；上架出租顯示「Yes, listed for rental」
上架出租而且填了價格時，另列一次性授權費與獨家授權費，各自是金額或「Price on request」
Edit每張摘要卡各一個回到對應的那一步修改
上架狀態提示選保持私有時提示文案寫「This IP is private. List anytime from IP detail page.」與「Only you can use this IP.」
選上架出租時的提示見頁尾尚待確認
送出—建立 IP 紀錄，回到我的 IP；按鈕文案見頁尾尚待確認

依據：5.1.4.1 §1、§3、§4、§6；主規格 §7.1、§7.3；D079、D169。

上架出租或保持私有

第 3 步的選擇決定這筆 IP 登錄後找不找得到；兩種都算登錄完成，不必當下決定。

選擇登錄後
上架出租其他創作者可以在 IP 市場瀏覽並送出租用申請；市場上架開關是否立刻打開見頁尾尚待確認
我的 IP 清單的 Mktplace 與 Rental Price 欄反映這個選擇
保持私有不出現在 IP 市場，只追蹤收益分配
之後在管理 IP 的授權定價上架，我的 IP 清單的 Mktplace 是同一個開關，見市場上架開關
  • 上架或授權生效時，凍結當下的素材包，見素材包
  • 登錄後的驗證狀態與上架資格的關係，見上架狀態

依據：5.1.4.1 §2、§4③④、§6 第 5 項、§7；5.1.4 F1、F6；主規格 §7.7。

尚待確認

  • 所有權證明跟驗證狀態的關係、驗證門檻與上架資格
  • 授權地區選了 Worldwide 與選個別地區怎麼互斥或取代
  • 選上架出租時，審閱頁的上架狀態提示寫什麼
  • 送出按鈕的文案
  • 「平台記錄不等同正式法律合約」的揭露放在哪一步、哪個位置
  • 選上架出租後，市場上架開關是否立刻打開（開關預設關閉），以及驗證還沒完成時能不能上架
  • 私有 IP 的提示文案寫「從 IP 詳情頁上架」，上架開關的家在管理 IP，IP 詳情（從我的 IP 進入）的市場設定能不能切換
  • 中途關閉時已填的內容怎麼處理，有沒有存成草稿（畫面示意有「Save as draft」）
  • 畫面示意另有的「Rights covered」「Likeness age range」「Asset upload」欄位，規格沒有定義
  • 版稅比例在這裡限 0–30%，管理 IP 改分潤時規格寫 0–100%，兩處範圍是否一致
  • IP 類型的最終分類與需求文件列的 Character、Visual 怎麼對齊
  • IP 授權規則相關的待確認列在IP 授權規則頁尾
