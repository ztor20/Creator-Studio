我的 IP

創作者在我的 IP（IP 資產，IP Assets）管理自己擁有與向他人租入的 IP，處理別人送來的租用申請，並掃一眼 IP 帶來的收入。上架、定價與授權的共通規則，見IP 授權規則。

概述

  • 這頁只管當前這位創作者的 IP；跨創作者的權利分配與分潤在 Admin 的 IP Bank
  • 單筆 IP 的定價與上架開關的家在管理 IP，出租與刪除也在那裡；承租方會看到的完整條件在 IP 詳情

操作流程

創作者進我的 IP 後，先切到自有或租入，再決定登錄新的 IP、處理一筆 IP，或處理租用申請。

1進我的 IP看統計與清單
2切分頁自有 IP 或租入 IP
3要做什麼？
登錄 IP按「＋ Add your IP」
管理 IP按「Manage」
IP 詳情點這筆 IP
切 Mktplace 開關
授權核准佇列核准、議價或拒絕

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 進我的 IP；頁首是統計，下方是 IP 清單
  2. 切自有 IP 或租入 IP 分頁，見IP 清單
  3. 要做什麼？
    • 登錄站外 IP：按「＋ Add your IP」進登錄 IP
    • 管理一筆 IP：按該列的「Manage」進管理 IP
    • 看完整條件：點該筆 IP 進 IP 詳情
    • 上架或下架：切該列的 Mktplace 開關，見自有 IP
    • 處理租用申請：到授權核准佇列
  • 想租別人的 IP，到 IP 市場找

依據：5.1.4 F1、F6、F7、F8、頁面佈局、情境；5.1.4.2 §1；D150。

IP 清單

IP 清單讓創作者掃視自己擁有與租入的所有 IP，以及每一筆的權利、租用與收入。頁首數字見統計；自己擁有的 IP 見自有 IP；向別人租的見租入 IP；頁首的入口與提示見登錄入口與提示條；還沒有 IP 時見沒有資料時。

統計

三個指標讓創作者一眼掌握 IP 的總量、出租與收入。

  • IP 總數（Total IP）：附自有與租入的拆分，例如「自有 8 · 租入 4」
  • 租出數（Total rentals）：目前生效中的授權數，附進行中授權；生效的定義見授權的階段
  • IP 總收入（Total IP revenue）：附「年初至今 · USD」；口徑同收入管理，明細到收入總覽看，這頁不重算

租入 IP

租入 IP 讓創作者集中查看向別人租來的 IP、授權範圍與到期狀態。

  • 清單只列摘要，每一列顯示哪些欄位見頁尾尚待確認
  • 來源、授權範圍、期限與到期提醒在 IP 詳情查看，見 IP 詳情的IP 資產管理資訊
  • 到期提醒也會出現在儀表板的今日待處理，見授權的期限與到期提醒
功能或欄位出現條件與必填規則
自有 IP／租入 IP 分頁—切換清單的資料範圍
Manage—租入 IP 的列也有 Manage 入口，進管理 IP；租入 IP 在管理 IP 能做什麼見頁尾尚待確認

授權核准佇列

授權核准佇列（License Out Queue）讓擁有者處理別人對自有 IP 送出的租用申請，是授權從草稿走到生效的核准入口。佇列放在畫面哪裡由畫面決定。

功能或欄位出現條件與必填規則
待核准清單有別人送出的草稿授權時每筆顯示 IP、申請方與條款摘要
申請來自承租方在 IP 詳情頁送出租用，見送出租用申請
核准（Approve）—核准而且條款齊全，授權才轉生效，見生效前條款要齊全
議價（Counter）—向申請方提出不同條件；怎麼往返見頁尾尚待確認
拒絕（Decline）—拒絕這筆申請
沒有申請時—顯示空狀態，例如「目前沒有待處理的租用申請」，不留白
  • 稽核軌跡見核准、議價與拒絕
  • 收到租用或詢問時，儀表板的今日待處理也會提醒，點擊導向我的 IP 或 IP 詳情

依據：5.1.4 F8；5.1.3.1 §3.4；5.1.1 F4；主規格 §7.7「授權生命週期」；D047。
