平台優惠設定

Admin 在這頁開平台滿額折扣、發平台優惠碼、設例外藝人，並查折抵紀錄。這兩種優惠怎麼判門檻、誰吸收成本、跟其他折扣的套用順序，見優惠規則的平台滿額折扣與平台優惠碼。

概述

  • 兩種平台優惠都一筆一筆獨立設定，各有自己的名稱、期間、啟用開關、備註、例外藝人與修改歷史
  • 只有 Admin 能進入與修改，沒有權限時顯示無權限狀態；創作者不能修改或退出平台優惠，個案的出口是例外藝人
  • 儲存只對之後成立的訂單生效，既有訂單不變

操作流程

Admin 選要開哪一種優惠，填完設定儲存，之後在紀錄查折了多少。

1開哪一種優惠？
2新增一筆填門檻與折抵
新增一組填碼、折扣與使用次數
3設期間與例外開始與結束時間、啟用、本筆例外藝人
4儲存只對之後成立的訂單生效
5查紀錄哪些訂單套了、折了多少

流程圖：由左往右走，上面一列是滿額折扣，下面一列是平台優惠碼，兩條路在設期間與例外合流；圓圈數字對應下方步驟清單的編號。

  1. 選要開哪一種優惠
    • 滿額折扣：訂單達門檻自動折，買家不用輸碼
    • 平台優惠碼：平台發碼，買家結帳時輸入
  2. 新增一筆滿額折扣或一組平台優惠碼，欄位見一筆滿額折扣的設定與一組平台優惠碼的設定
  3. 設開始與結束時間、啟用開關與本筆例外藝人
  4. 儲存，修改歷史追加一筆
  5. 在折抵紀錄查哪些訂單套了、折了多少
  • 要讓某位藝人退出所有平台優惠，在例外藝人加入

依據：5.1.0.7 頁面定位、F2、F3、F4、F5、情境；D273、D277。

滿額折扣

Admin 逐筆建立「訂單達多少、折多少」的活動，可以多筆同時存在。先看到滿額折扣清單；新增或編輯時填一筆滿額折扣的設定。門檻、多筆重疊、例外與撤銷的規則見優惠規則的平台滿額折扣。

滿額折扣清單

每一列是一筆滿額折扣，顯示：

  • 名稱
  • 門檻與折抵
  • 生效期間
  • 狀態：未開始、進行中、已結束、已停用，依期間與啟用開關自動算出
  • 啟用
  • 例外藝人數
功能或欄位出現條件與必填規則
新增—開一筆新的滿額折扣
編輯—改這一筆的設定
複製—複製這一筆
停用—立刻停止套用到之後成立的訂單，不必刪除
刪除—什麼情況能刪除，見頁尾尚待確認
  • 還沒建立任何滿額折扣或平台優惠碼時，顯示空狀態與建立第一筆的引導

平台優惠碼

平台自己發放、買家結帳時輸入的碼，一組一組設定；欄位與買家端行為跟創作者在商店設定發的優惠碼一樣。先看到平台優惠碼清單；新增或編輯時填一組平台優惠碼的設定。成本由平台吸收，規則見優惠規則的平台優惠碼。

平台優惠碼清單

每一列是一組平台優惠碼，顯示：

  • 名稱
  • 碼
  • 折扣
  • 適用範圍
  • 生效期間
  • 狀態：未開始、進行中、已用完、已結束、已停用，意思見優惠規則的優惠碼的狀態
  • 已用／總兌換上限
  • 例外藝人數
功能或欄位出現條件與必填規則
新增—開一組新的平台優惠碼
編輯—改這一組的設定
複製—複製這一組
停用—立刻停止受理這組碼
刪除—什麼情況能刪除，見頁尾尚待確認

例外藝人

全局例外清單：列入的藝人，所有平台優惠（滿額折扣與平台優惠碼）都不套用。全局例外、每筆滿額折扣與每組平台碼各自的例外怎麼合起來，以及例外藝人的品項怎麼算，見優惠規則的平台滿額折扣。

功能或欄位出現條件與必填規則
搜尋—找清單裡的藝人
加入—用 Creator 管理的創作者識別挑選藝人
原因加入時選填—
移除—移出全局例外
  • 清單每一列顯示藝人、加入時間、操作者、原因；每筆滿額折扣與每組平台碼裡的例外清單也一樣

依據：5.1.0.7 F5；D273、D277。

折抵紀錄

折抵紀錄讓 Admin 對帳與解釋爭議：哪些訂單、哪些藝人、套了哪一筆、折了多少。

功能或欄位出現條件與必填規則
篩選—依期間、來源模組、藝人、優惠篩選
依藝人彙總切換檢視以藝人為單位，看期間內累計的折抵金額
  • 每一筆顯示：
    • 成交時間
    • 訂單
    • 來源模組（電子商店、活動、項目）
    • 品項小計
    • 套用的優惠（哪一筆滿額折扣或哪一組平台碼）
    • 折抵金額
    • 分攤到各藝人的金額
  • 撤銷的訂單標示已沖銷
  • 金額取自收入管理，這裡只顯示、不另外計算

依據：5.1.0.7 F6；主規格 §7.3；D273、D277。
