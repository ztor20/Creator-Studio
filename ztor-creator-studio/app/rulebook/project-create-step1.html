步驟 1：關於項目

創作者在建立項目的第一步確認項目類型與內容類型，填名稱、描述與內容類型相關的欄位，用了他人的 IP 時連結 IP 租借。四條路徑的全貌見建立項目。

概述

  • 項目類型與內容類型在進入步驟 1 之前就問完，這一步是回頭改選
  • 名稱與描述是粉絲在卡片與清單第一眼看到的文字，也是作品上架與項目公開資訊共用的同一份資料
  • 直接發佈影片家族的這一步叫「關於作品（About）」，收的東西相同，少掉幾個併入後面步驟的欄位，見影片路徑少掉的欄位

這一步從項目列表按建立項目開始，到進入展示內容為止；影片路徑接下來是作品檔案。

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 從項目列表按「＋ New Project」，先選項目類型與內容類型，再進步驟 1（草稿續填不再問，見從哪裡進入建立項目）
  2. 填項目名稱與項目描述
  3. 依內容類型填相關欄位：單曲與專輯的格式、活動的活動類型必填，其餘選填

IP 租借

項目用了他人的角色、音樂、故事、品牌或其他智慧財產時，在這裡連結授權，向其他人揭露作品借用了哪些 IP。

功能或欄位出現條件與必填規則
連結 IP 租借（Link IP rental）用了他人 IP 時必須連結連到租入的 IP 或授權紀錄
沒連結時發布前檢核不通過，見發布前檢核
IP 在項目裡只有這一種身分，見IP 在項目裡的身分

依據：5.1.2.1 §2、§4.1 F1～F5、§4.3 F12 第 7 項；D182、D227、D232。

內容類型與作品家族

內容類型是作品的類型，十個選項分屬兩個作品家族；家族只影響直接發佈走哪條路，見直接發佈的兩個作品家族。

作品家族內容類型
影片家族電影（Movie）
短片（Short film）
影集（Series）
MV
紀錄片（Documentary）
非影片家族單曲（Song）
專輯（Album）
活動（Event）
周邊（Merch）
自訂（Custom）
  • 每個內容類型落到哪個商品次分類，見商品分類與模組應用
  • 內容類型只管作品的形態，不管題材；題材用分類欄位
  • 紀錄片與數位商品的「文檔（Document）」是兩個不同的次分類：紀錄片有可播放的影片、屬影片家族；文檔是 preset、PDF、ZIP 這類檔案，由電子商店建立，不進建立項目
  • 自訂是通用類型，不提供額外功能

音樂的格式決定商品分類

單曲與專輯的格式決定作品落在哪個主分類。

  • 勾 Digital：落數位商品
  • 勾任一種實體載體（Vinyl、CD、卡帶）：落實體商品
  • 兩邊都勾：產生數位版與實體版兩個商品，各自有價格；實體版有庫存與物流，數位版沒有
  • 載體不是分類，只是實體商品的屬性

活動類型少了共看派對

選活動時要再選活動類型才能決定落到哪個商品分類；活動模組有六種類型，項目只有五種，少了共看派對。

  • 共看派對是既有影片的放映場次，沒有待製作的作品，先收錢後交付的共創與預購對它不成立
  • 要賣共看派對，用建立活動

依據：5.1.2.1 §3、§4.1 F3、F4；主規格 §7.1；D227。

名稱與描述的語言

項目名稱與項目描述在這一步只用設定頁的預設語言填，其他三種語言的自動翻譯在最後一步檢視與修改，見預覽與發布。

  • 四條路徑都一樣
  • 這組值與作品上架的多語言標題與說明、項目公開資訊的簡介是同一份資料，任一處修改三處同步
  • 項目卡片與清單顯示預設語言那一份，過長截斷
  • 翻譯怎麼運作，見語言與在地化

依據：5.1.2.1 §4.1 F2「名稱與描述逐語言」；主規格 §7.4；D182、D220、D223。

影片路徑少掉的欄位

直接發佈影片家族在這一步不收下列欄位，改由後面步驟的作品上架欄位收，同一件事只問一次。

這一步不收的欄位改在哪裡收
導演
演員陣容		詳情與定價的演職人員
片長
時長		詳情與定價的片長
年齡分級詳情與定價的年齡限制
分類詳情與定價的分類
語言作品檔案的原始語音，以及逐語言的標題與說明
  • 欄位的規則見作品檔案、詳情與定價
  • 共創與預購的影片項目仍在這一步收這些欄位，之後走作品上架時預先帶入對應欄位

依據：5.1.2.1 §4.1 F4「影片路徑的欄位退場」「三項值域收斂」；D182。
