活動詳情與編輯

創作者在活動詳情管理一場已發布的活動，從售票、名單、報到、通知到結算；要改活動內容時，在同一頁切換成編輯模式。

1活動詳情

活動詳情管理單一活動從售票、名單、報到、通知到結算的完整過程；活動發布後才有詳情頁。

活動資訊與階段操作

頁首讓創作者認出是哪一場活動，並依活動階段提供發布、取消或再辦一場；下架只有 Admin 能做。

  • 頁首顯示：
    • 主視覺，沒上傳就整塊不顯示
    • 活動名稱與亮點
    • 日期時間與場地
    • 階段徽章與活動類型，階段見活動的階段
    • 已下架的活動另加「已下架」徽章，階段徽章不變
    • 系列序，只在活動屬於系列時顯示
  • 詳情頁沒有刪除入口

2編輯活動

編輯活動是詳情頁的編輯模式，不是另一個頁面；改動要按「儲存」才生效。

儲存與離開

編輯模式不自動儲存，改動只停在畫面上，按「儲存」才生效。

  • 「儲存」永遠可以按，沒有改動時按下等於回到檢視模式
  • 有改動時才能按「捨棄變更」，按下要再確認一次
  • 有未儲存的改動卻要離開時，先問「儲存並離開」「不儲存就離開」或「取消」
  • 必填欄位（活動名稱、描述、場地名稱、活動日期）有空的，擋下儲存並標示
  • 描述至少要有一個文字區塊有字，只有圖片或影片區塊不算

哪些欄位能改

已排程、售票中與進行中的活動可以改內容；已結束與已取消的活動整頁唯讀。

  • 已結束與已取消的活動，活動清單的「編輯」與詳情頁的「編輯活動」都不出現，預覽與在地化同樣唯讀
  • 活動唯讀時，Admin 仍可撤銷票券
  • 活動類型建立後就不能改，不論有沒有開賣
  • 要換活動類型，只能用「再辦一場」另建一場
  • 名稱、亮點、描述可以改，儲存後粉絲端立即反映，不算高影響變更
  • 描述的區塊可以新增、刪除、拖動調整順序，區塊的規則見建立活動步驟 2
  • bookyay 帶入的活動，整份描述鎖定：不能改、刪、排序，也不能新增區塊或插入圖片影片，要改回 bookyay 改
  • bookyay 帶入的活動，名稱同樣可以改
  • 描述之後可以改條款與細則：「直接促銷同意」與「條款及細則」兩個開關各附一段文字，定義同建立活動步驟 2
  • 改條款與細則不算高影響變更
  • bookyay 帶入的活動，「條款及細則」的開關與條款文字鎖定，要改回 bookyay 改；「直接促銷同意」可以改
  • 發布設定（上架、開賣、取票方式、顯示設定）在草稿與已排程時可以改，進入售票中後唯讀
  • 任一張門票或票務商品開始能買（包括早鳥）就算進入售票中
  • bookyay 帶入的活動，取票方式在任何階段都不能改
  • 改上架或開賣時間時，照販售時間的三層同一套檢查
  • 改基準內容，不會覆蓋已填的譯文
  • 改基準票價時，其他幣別的覆寫全部依新換算值重算，不保留
  • 改價只影響之後的購買，已售出的票不追溯

改場地或時間要先確認

活動進入售票中後改了場地或場次時間，儲存前要先確認，確認後通知持票人。

  • 適用於活動在售票中或進行中，並且改了場地名稱、地址，或任一場次的日期與開始時間
  • 確認視窗逐條列出改前與改後，並寫明會通知幾位持票人
  • 確認後才儲存，並寄出活動變更通知
  • 按取消就留在編輯模式
  • 活動還在已排程（沒有成交），或沒改到這些欄位時，不出現確認

編輯票種與票務商品

票種與票務商品各自儲存，不受頁面的編輯模式管。

  • 票種逐筆編輯、各自儲存
  • 已經有人買的票種不能刪除，並說明「已有 n 位買家持有此票種」
  • 票種數量不能低於已售張數
  • 沒人買過的票種可以刪除
  • 單張門票的限時間跟著票種逐筆編輯，同樣要在活動的上架區間內，見販售時間的三層
  • 刪除票種或把門票改成隱藏時，受可賣條件與發布檢核約束
  • 票務商品不在活動詳情頁編輯，點組合包卡進組合商品細節頁修改
  • 票務商品已售出後的鎖定與票價連動，見組合包與票務商品的組合包的下架連動與刪除與組合包的價格

依據：5.1.6.2 §1、F1、F2、F9、F12、F14、F15；5.1.6.3 §2.1；主規格 §7.14、§7.15；D188、D281、D292、D296、D301、D306、D308、D327、D329、D330、D340、D342、D354、D361、D362。

尚待確認

  • 開賣前置條件的正式清單
  • 起飛前檢核清單除了不擋開賣，會不會擋其他動作
  • 結案要不要成為正式階段，以及結案後多久仍可匯出
  • 票種的「Almost sold out」「Near capacity」是正式狀態，還是只是警示文案
  • 逐封寄送明細要不要放進詳情頁，以及重寄的路徑
  • 發布後改譯文要不要審核或留版本紀錄
  • 編輯時能不能移除既有的表演者
  • 編輯時素材要不要至少保留一張
  • 影片預告能不能在編輯模式修改
  • 結束時間、開放入場、結束日期或跨日開關改動時，要不要也算高影響變更並通知購票者
  • 高影響變更的完整欄位清單與通知內容格式
  • 發布後改了條款與細則，已購票的粉絲要不要重新同意
  • 已售出票種改名稱時，對已完成的交易有沒有影響
  • 進入售票中後，發布設定還有哪些項目能改，例如提前停售、下架時間、由顯示改隱藏
  • 已結束或已取消的活動能不能下架
  • 活動下架後能不能重新上架
  • 創作者要請 Admin 撤銷票券或下架活動時，透過什麼管道申請（目前規格沒有畫面）
  • 改了上架或開賣時間後，已設限時間的門票或已另設時間的票務商品落到上架區間外時怎麼處理
  • 票務商品已售出後，購買條件、限購與另設的上架開賣時間能不能改
