收益

創作者在項目詳情的收益分頁，看這個項目賺了多少，共創另在這裡手動觸發淨利池分配。頁首與編輯規則見項目詳情。

概述

  • 金額與口徑一律引用收入管理，這裡不重算，見財務術語與收入事件
  • 三種發行模式都有這個分頁，分配只有共創

操作流程

創作者先看收益拆解；共創要分錢時，看過淨利池與明細再手動觸發。

1看收益摘要與瀑布
2是共創嗎？
3有已結算的收入、淨利池不是負數嗎？
4看過金額、明細與費率版本
手動觸發分配
淨利池全歸創作者不用分配

流程圖：由左往右走，紫色框是要回答的問題，綠框是結束的地方。圓圈數字對應下方步驟清單的編號。沒有已結算的收入或淨利池為負時不能觸發，見淨利池與分配。

  1. 看收益摘要與瀑布
  2. 是共創嗎？

    • 是：往下一步

  4. 看過淨利池金額、逐筆分配明細與所依據的費率版本，手動觸發分配

依據：5.1.2.2 §2.3、§2.4 第 3 項。

功能與欄位

收益分頁有兩塊：收益摘要與瀑布，與淨利池與分配。

收益摘要與瀑布

收益摘要與瀑布把本項目的收益一層層拆開，讓創作者看出錢從哪來、扣了什麼。

  • 呈現本項目的收益拆解（財務階梯，也叫瀑布）
  • 每一筆收入都綁定本項目，可以追到它所用的費率版本
  • 完整的逐筆明細在收入管理

依據：5.1.2.2 §2.3、§2.3.1；主規格 §7.3、§7.6。

淨利池與分配

淨利池是本項目可以分配的淨利，口徑見財務術語與收入事件；共創要把它分給創作者與分潤名額的持有者，其他模式全歸創作者。

功能或欄位出現條件與必填規則
淨利池金額（Net Profit Pool）三種發行模式直接發佈與預購同時寫明「全歸創作者」，不用再分給誰，也不必按任何按鈕
分配比例與明細只有共創創作者與分潤名額持有者的比例，預設創作者 60%、持有者 40%，可以逐項目在範圍內調整
逐一列出每位收款人的明細
觸發分配只有共創
本項目有已結算的收入
淨利池不是負數		只能由創作者手動觸發，平台不會自動撥款
觸發前顯示淨利池金額、逐位收款人明細與所依據的費率版本
  • 淨利池為負時暫停分配，並說明虧損會結轉、已撥的款不回收
  • 分配與結算紀錄只能新增、不能改寫，更正用沖銷分錄
  • 本項目的收益獨立結算，不跨項目挪用
  • 淨利池分配和共創的撥款進度是兩筆不同的錢，不合併呈現
  • 已取消的項目只顯示歷史，不接受新的收入事件

依據：5.1.2.2 §2.3.2、§2.2.4、§2.1.1「撥款進度的口徑」；主規格 §5.2.2、§7.3、§7.6；D192、D345。
