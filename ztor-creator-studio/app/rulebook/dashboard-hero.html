首頁輪播（Hero Banner）

創作者在儀表板最上方的首頁輪播看到平台能做什麼、官方活動與營運機會，按卡上的按鈕直接進對應的建立流程或活動。

概述

  • 輪播固定是儀表板頂部的單一區塊，前三張是引導建立的固定卡，第四張預設是官方活動公告
  • 卡片的素材與文案可以替換，順序規則不變，見輪播卡的順序

操作流程

創作者在儀表板看到輪播，切到想看的那一張，按卡上的按鈕前往。

1進儀表板看到第一張
2切換卡片上一張、下一張
3按卡上的按鈕
4前往對應的頁面建立項目、IP 市場、建立活動或公告內容

流程圖：由左往右走，灰色虛線框是選用的步驟；圓圈數字對應下方步驟清單的編號。

  1. 進儀表板，輪播停在第一張；帳號是新的時，第一張固定是建立項目
  2. 需要時切換到其他張
  3. 按卡上的按鈕
  4. 前往這一張的目的地，見每一張的內容

依據：5.1.1.1 頁面內容、頁面佈局；5.1.1 F1。

功能與欄位

輪播在儀表板最上方，所有帳號都會看到。

功能或欄位出現條件與必填規則
卡片—每張有標題、副標與一個按鈕；內容見每一張的內容
上一張、下一張—切換卡片
目前第幾張—顯示目前停在第幾張
卡上的按鈕每一張都有帶到具體的建立流程、活動、公告詳情或報名流程，不只停在一般資訊頁

依據：5.1.1.1 頁面內容、§2.4；5.1.1 F1。

輪播卡的順序

預設順序：

  1. 建立項目
  2. 探索 IP 市場
  3. 建立活動
  4. 官方活動公告
帳號狀況順序怎麼排
帳號是新的建立項目卡固定第一張，是主要入口；判斷條件見頁尾尚待確認
一般公告不能蓋過建立項目
帳號已經不是新的可以依官方活動公告、平台企劃或營運機會調整排序，建立推廣退為次要

Admin 替換素材與調整排序時，仍要保留上面的規則，每一張也都要有明確的目的地。

依據：5.1.1.1 頁面內容、頁面佈局、使用情境與任務；5.1.1 頁面狀態；D024、D391。

官方活動公告

官方活動公告向已在營運的創作者宣傳平台官方活動、精選企劃、合作機會、功能更新或重要公告。文案要做到：

  • 說明這則活動或公告對創作者營運的價值
  • 按鈕帶到具體的活動、公告詳情、報名流程或相關模組
  • 公告跟收入、活動、IP、粉絲經營或外部資料同步有關時，寫出影響範圍

依據：5.1.1.1 §2.1～§2.4。

載入失敗時

前三張固定卡保底，輪播不會完全空白。

  • 官方公告載入中或載入失敗時，只顯示可用的固定卡，不出現空位或破圖
  • 沒有任何官方公告可排時，只顯示固定卡

依據：5.1.1.1 頁面內容「狀態」；主規格 §6.2、§6.3；D069。
