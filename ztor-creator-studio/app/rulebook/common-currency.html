定價幣別

創作者用自己的幣別填一個價格，其他幣別自動換算；Admin 設定的金額用平台基準幣別記錄，套用到創作者時再換算。粉絲用哪一種幣別看價與付款由粉絲端決定，不在這頁範圍。

創作者幣別

一位創作者只有一個幣別（Creator currency），由 Admin 建立創作者帳號時選定，建立後創作者與 Admin 都不能改。

  • 幣別有五種：
    • 美元（USD）
    • 新台幣（TWD）
    • 港幣（HKD）
    • 新加坡幣（SGD）
    • 日圓（JPY）
  • 全站只有這一份幣別清單，設定頁、商店設定、手動補登收入都用它
  • 唯一的設定入口是 Admin 在 Creator 管理建立創作者時的必填欄位，見Creator 列表
  • 設定頁與商店設定只唯讀顯示創作者幣別，不提供切換
  • 設定頁的金額（最低提款金額、年度提款額度、月結算量）與申請提款的金額，一律用創作者幣別顯示，不寫死美元符號 $
  • 不同創作者可以有不同的創作者幣別；站上沒有「全站幣別」

依據：主規格 §7.15「創作者幣別」；5.1.9 F5、F7；5.1.8.1 §4.5；D316、D326、D466。

平台基準幣別

平台基準幣別（Platform base currency）是平台自己的記帳幣別，預設港幣，跟任何一位創作者的幣別無關。

  • Admin 設定的金額以平台基準幣別記錄：
    • 支付費的每筆固定額，見平台費率設定
    • 平台滿額折扣的門檻金額，見平台優惠設定的滿額折扣
  • 套用到某位創作者或某張訂單時，依當時的匯率換算成該創作者的幣別再判定與計算；畫面同時顯示換算後的金額與匯率時點
  • Admin 跨創作者的報表：每一列顯示那一筆自己的原幣別金額；合計換算成平台基準幣別並標出匯率時點；不同幣別的數字不直接相加
  • 忠誠點數的購買類計分，先把消費金額換成平台基準幣別再算分，見粉絲分級的購買怎麼換算成點數

依據：主規格 §7.15「平台基準幣別」；D316、D347。

基準幣別與換算價

每個可販售的對象（活動票種、組合包、商品）有一個基準幣別（Base currency），就是建立當下的創作者幣別；金額欄只填基準幣別一個值，其他四種幣別的價格（換算價，Converted price）依匯率自動算出。

  • 基準幣別建立後固定
  • 各頁的金額欄只收基準幣別一個值，不另開逐幣別輸入的欄位
  • Creator Studio 內的清單、摘要、KPI、收入一律用基準幣別顯示，不混用幣別
  • 例外：從 bookyay 帶入、創作者幣別不是港幣的活動，創作者幣別那一欄覆寫過時，清單、摘要、KPI 顯示覆寫值（粉絲實際付的價）；沒覆寫過的照基準價
  • 換算價的小數位照該金額欄自己的規則（例如票價是整數），四捨五入
  • 折扣百分比這類欄位沒有幣別，各幣別套同一個百分比

依據：主規格 §7.15「基準幣別」「換算價」「本輪納入的金額欄」「使用限制」；D306、D316、D331。

重算規則

基準價改了，沒手動改過的幣別價格跟著重新換算，手動改過的保留。

其他幣別：換算值跟著重新換算
手動改過
其他幣別：覆寫值保留不變

繼承圖：實線是跟著基準價換算的格子，虛線是覆寫過、自己一組的格子；數字是假設。

  • 創作者在 ztor 改基準價、bookyay 同步改價都照這條
  • 「重設為換算值」讓某一格回到跟隨，之後基準價再改就跟著重新換算
  • 基準價改了之後，有保留下來的手動改價時，列出有手動改價的幣別，提示創作者重新確認
  • 組合包售價由成員原價合計 ×（1 − 折扣%）算出；成員價或折扣改了，比照第一條：沒手動改過的幣別跟著重新換算，手動改過的保留，並同樣提示重新確認
  • 電子商店的換算價沒有手動改的情形，一律跟著基準價重新換算
  • 活動的譯文也是改過的保留；電子商店的翻譯則在原文改了就重新產生，兩者不是同一套，見自動翻譯與活動的手動翻譯

依據：主規格 §7.15「重算規則」；D306、D312、D415、D455。

bookyay 帶入的活動

bookyay 帶入的金額一律是港幣：換算成創作者幣別當基準價並鎖定，價格表的港幣欄固定是 bookyay 原價，港幣以外的幣別可以覆寫。換算與鎖定的完整規則，見 bookyay 匯入與對照的金額與幣別。

依據：主規格 §7.15「bookyay 帶入的活動」；D328、D330、D331、D429。

粉絲付款與收款

  • 粉絲用哪一種幣別看價與付款，由粉絲端決定
  • 創作者收款的換匯在交易當下進行
  • 收入事件記原幣（粉絲實付的幣別與金額）與換算幣（基準幣別），見財務術語與收入事件的收入事件
  • 粉絲用覆寫價付款時，原幣金額就是覆寫價
  • 覆寫值或基準價變更只影響之後的購買，已售出的票與訂單不追溯

依據：主規格 §7.15「粉絲端與收款」「已售出後改價」；5.1.9 F5；D306。
