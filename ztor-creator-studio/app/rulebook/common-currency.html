定價幣別

創作者用自己的幣別填一個價格，其他幣別依匯率自動換算；粉絲用基準幣別以外的幣別付款時，換匯手續費併進售價，粉絲只看到一個價格。平台設定的金額（支付費固定額、滿額折扣門檻）用平台基準幣別記錄，套用到創作者時再換算。

創作者幣別

一位創作者只有一個幣別（Creator currency），由 Admin 在 Creator 列表建立創作者帳號時選定，建立後創作者與 Admin 都不能改。

  • 預設有五種幣別，Admin 可在平台費率設定新增幣別：
    • 美元（USD）
    • 新台幣（TWD）
    • 港幣（HKD）
    • 新加坡幣（SGD）
    • 日圓（JPY）
  • 全站只有這一份幣別清單，設定頁、商店設定、手動補登收入都用它；新增的幣別同時成為創作者幣別與粉絲付款幣別的選項
  • 唯一的設定入口是由 Admin 在Creator 列表建立創作者時的必填欄位
  • 設定頁與商店設定只唯讀顯示創作者幣別，不提供切換
  • 設定頁的金額（最低提款金額、年度提款額度、月結算量）與申請提款的金額，一律用創作者幣別顯示，不寫死美元符號 $
  • 不同創作者可以有不同的創作者幣別；站上沒有「全站幣別」

依據：主規格 §7.15「創作者幣別」；5.1.9 F5、F7；5.1.8.1 §4.5；D316、D326、D466。

平台基準幣別

平台基準幣別（Platform base currency）是平台自己的記帳幣別，預設港幣，跟任何一位創作者的幣別無關。

  • 平台設定的下列金額，以平台基準幣別記錄：
    • 支付費的每筆固定額，見平台費率設定
    • 平台滿額折扣的門檻金額，見平台優惠設定的滿額折扣
  • 套用到某位創作者或某張訂單時，依匯率換算成該創作者的幣別再判定與計算；畫面同時顯示換算後的金額與匯率時點
  • 跨創作者的報表：每一列顯示那一筆自己的原幣別金額；合計換算成平台基準幣別並標出匯率時點；不同幣別的數字不直接相加
  • 忠誠點數的購買類計分，先把消費金額換成平台基準幣別再算分，見粉絲分級的購買怎麼換算成點數

依據：主規格 §7.15「平台基準幣別」；D316、D347。

基準幣別與換算價

每個可販售的對象有一個基準幣別（Base currency），就是建立當下的創作者幣別，建立後固定；金額欄只填基準幣別一個值，其他幣別的價格（換算價，Converted price）依匯率自動算出，創作者與 Admin 都不能改。幣別之間的關係見下圖。

  • 適用的金額欄：
    • 活動票種的票價
    • 商品定價（單一選項、逐選項、數位商品）
    • 組合包售價：成員原價合計與售價的其他幣別都是換算價
    • 項目的價格
    • 作品定價：作品的基準幣別是作品上架步驟 3 選的幣別
  • 各頁的金額欄只收基準幣別一個值，沒有其他幣別的輸入欄位，也沒有修改換算價的入口
  • 預覽與發布、預覽與在地化畫面沒有幣別區塊與切換，只用創作者幣別顯示價格；其他幣別的換算價在粉絲端才出現，見語言與在地化的畫面的組成
  • Creator Studio 內的清單、摘要、KPI、收入一律用基準幣別顯示，不混用幣別
  • 換算價的小數位照該金額欄自己的規則（例如票價是整數），四捨五入
  • 折扣百分比這類欄位沒有幣別，各幣別套同一個百分比
創作者幣別 = 基準幣別建立創作者時選定，建立後固定；金額欄只填這一個值
自動換算
其他幣別：換算價依當日匯率從基準價算出，不能改

示意圖：實線是跟著基準價換算的幣別；bookyay 帶入的活動同樣照這張圖，見bookyay 帶入的活動；平台基準幣別是平台自己的記帳幣別，與這張圖無關，見平台基準幣別。

依據：主規格 §7.15「基準幣別」「換算價」「適用的金額欄」「使用限制」；§7.4「發布前預覽確認」第 3 點；D306、D316、D514、D517。

匯率

平台每天更新一次匯率；畫面上的換算價用當日匯率，粉絲結帳時鎖定當下匯率並記進訂單。

  • 非基準幣別的價格會隨每日匯率浮動
  • 訂單鎖定匯率之後，匯率再變，這張訂單不受影響
  • 沒有人能手動改匯率；單日匯率波動大於換匯手續費時，平台寄信給 Ztor 團隊
  • Ops 只能到平台費率設定調換匯手續費，不能改匯率
  • 訂單的每個品項記下粉絲幣別與金額、創作者幣別與金額、匯率、換匯手續費；退款用訂單記下的匯率

依據：主規格 §7.15「匯率」；D514、D517。

換匯手續費

換匯手續費（Currency swap fee）是粉絲付款幣別與品項基準幣別不同時，平台併進售價的費用；兩者相同時不收。粉絲只看到一個價格，等於換算價加手續費，下方附創作者幣別原價。

事項規則
誰付粉絲，併在售價裡
粉絲端不單獨列手續費，顯示金額等於實際扣款金額
誰看得到展開創作者與 Admin 在訂單看得到價格展開，逐列顯示換算前金額、匯率、費率與換匯手續費，見訂單詳情的金額拆解
歸誰平台，不是創作者收入，也不從創作者收入扣
怎麼算品項實付（折後）換算成付款幣別後 × 費率
與平台費各自計算，不疊加
費率由 Admin 在平台費率設定依粉絲付款幣別各設一個百分比，預設都填同一個值
同一幣別的粉絲不論買誰的商品，費率都一樣；沒有逐創作者的費率
調費率只影響之後的銷售
粉絲實付品項金額＋運費＋換匯手續費，品項金額指折後的品項實付
適用範圍電子商店商品與活動票券
項目與作品的金額同樣自動換算，但不收換匯手續費

範例（數字皆為假設）：基準幣別是港幣，品項實付 HK$1,000，匯率 1 港幣＝4 新台幣，粉絲用新台幣付款，新台幣的費率 2%。換算後 NT$4,000，換匯手續費 NT$80，粉絲付 NT$4,080（運費另計）。

換匯手續費依付款幣別換樣子，各狀態如下：

狀態什麼時候畫面
收粉絲付款幣別與品項基準幣別不同併進粉絲看到的售價，下方附創作者幣別原價
不收粉絲付款幣別與品項基準幣別相同不收這筆費用
項目與作品粉絲付款幣別與基準幣別不同金額自動換算，不收換匯手續費
退款—用訂單記下的匯率；退款含不含換匯手續費尚待確認

依據：主規格 §7.15「換匯手續費」、§7.3、§7.6；5.1.0.3 F6；5.1.5.3.1 §2.3.2；D514、D517。

重算規則

基準價改了，其他幣別的換算價一律跟著重新換算。

  • 創作者在 ztor 改基準價、bookyay 同步改價都照這條
  • 組合包售價由成員原價合計 ×（1 − 折扣%）算出；成員價或折扣改了，各幣別售價跟著重新換算
  • 匯率每日更新時，換算價跟著當日匯率變動
  • 活動的譯文是改過的保留，電子商店的翻譯則在原文改了就重新產生，見自動翻譯與活動的手動翻譯

各幣別的價格依條件換樣子，各狀態如下：

狀態什麼時候畫面
一般項目
基準幣別—要改回原本的金額欄改
換算價其他幣別創作者與 Admin 都不能改，由粉絲端呈現；基準價改了或匯率更新時跟著變
bookyay 帶入的活動
基準價—鎖定，要調價回 bookyay 改
其他幣別—由基準價自動換算，不能改
匯率
匯率資料來源—尚待確認

依據：主規格 §7.15「重算規則」「匯率」；D306、D312、D514、D517。

bookyay 帶入的活動

bookyay 的票價以創作者幣別輸入，帶入後直接是基準價，不換算並鎖定；其他幣別一律由基準價自動換算，換匯手續費照一般規則。完整規則見 bookyay 匯入與對照的金額與幣別。

依據：主規格 §7.15「bookyay 帶入的活動」；D328、D517。

粉絲付款與收款

  • 粉絲幣別由註冊國家決定，粉絲不能選，也不隨所在地改變：
    • 新加坡用 SGD
    • 香港用 HKD
    • 台灣用 TWD
    • 其他國家用 USD
  • 一位粉絲只有一種幣別，看價、付款、錢包與 POPCORN 儲值都用它
  • 粉絲不能改用創作者幣別付款；購物車只有一種幣別，不會混幣
  • Admin 新增幣別時，一併指定適用的註冊國家
  • 創作者收款以創作者幣別結算
  • 收入事件記原幣（粉絲付款幣別與品項金額，不含換匯手續費）與換算幣（基準幣別），換算用結帳鎖定的匯率，見財務術語與收入事件的收入事件
  • 基準價或匯率變更只影響之後的購買，已售出的票與訂單不追溯

依據：主規格 §7.15「粉絲端與收款」「已售出後改價」；5.1.9 F5；D306、D517。
