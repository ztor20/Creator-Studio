媒體庫規則

創作者照這頁的規則判斷哪些粉絲進得了庫房、進庫後看得到哪幾件內容，以及打得開的人數怎麼算；媒體庫畫面提到這些規則時會連回這裡。

達成任一種進庫方法，或持有鑰匙→進得了庫→完成該件的任務→看得到該件

進庫方法

進庫方法讓創作者決定哪些粉絲進得了這座庫房，這是粉絲看到庫房內容之前的第一道門。一種進庫方法能放哪些條件，見可選的條件；粉絲掉級時進庫方法還算不算達成，見分級條件與掉級。

  • 一座庫房可以列一種或多種進庫方法，粉絲達成其中任一種就進得了庫
  • 一種進庫方法可以放一條或多條條件，條件要全部達成，這種方法才算達成
  • 還沒放任何條件的進庫方法，不算任何人達成
  • 先前設定的庫房，每條既有條件各自成為一種只含該條件的進庫方法，誰進得來不變
  • 各級福利裡的「創作者庫房 VIP 權限」目前只是對粉絲的承諾，不會連動媒體庫的設定；實際誰打得開以媒體庫的設定為準，每件內容的等級任務也與這項福利無關
例：假設一座庫房有兩種進庫方法。方法一要「Super Fans 以上」而且「買過某件限量商品」，兩條都達成才算；方法二只要「出席過某場活動」。粉絲達成方法一或方法二，就進得了庫。

在哪裡新增、移除條件，見媒體庫的進庫方法與條件。

可選的條件

條件粉絲要符合
分級（Tier）在指定分級以上
分級每週重算，名單會跟著變
買過（Bought）買過電子商店的指定商品，含限量品
支持過（Backed）支持過指定項目
出席過（Attended）出席過指定場次
達成過（Earned）達成指定成就，例如名人堂

分級條件與掉級

  • 一種進庫方法含分級條件時，粉絲的分級掉到條件以下，整種方法就不再達成，即使同一種方法裡的其他條件仍符合
  • 掉級的認定依每週重算與降級緩衝
  • 粉絲若沒有其他已達成的進庫方法，也沒有未撤銷的鑰匙，就失去這座庫房的進庫資格

依據：5.1.7.3 F2、F7；5.1.7.2 F2；主規格 §7.5；D150、D347、D376。

鑰匙

鑰匙（進庫憑證）是進庫方法之外的另一條路，讓創作者親手放原本不符合任何進庫方法的粉絲進來；拿到鑰匙的人用掉一次，就能進這座庫房。

鑰匙種類可用次數做完之後
送給一位粉絲1 次拿到可複製的連結
做成 NFC 商品（內建感應晶片的實體商品，例如鑰匙圈）創作者指定數量前往電子商店建立對應商品
  • 鑰匙只管進庫，不免除每件內容的任務
  • 還沒被領取的次數不算人，領取後才算進打得開的人數
  • 鑰匙代碼是唸得出來、能雷雕在實體商品上的短代碼
  • 鑰匙目前只會因兩件事失效：次數用完、被撤銷
  • 撤銷後，靠這把鑰匙進來的粉絲立刻失去存取權
  • 撤銷會保留發放與領取紀錄

在哪裡發鑰匙、怎麼撤銷，見媒體庫的發鑰匙與撤銷。

依據：5.1.7.3 F4；D377。

每件內容的任務

任務讓創作者決定粉絲進庫之後，要做什麼才看得到某一件內容；這是第二道門。三種設法各要粉絲做什麼，見任務的三種設法；行動任務能指定哪些事，見行動任務的種類；等級任務的等級能選的範圍，見等級任務能選哪幾級；解開後什麼情況會再上鎖，見解開之後會不會收回；事後改任務時已解開的粉絲怎麼辦，見修改任務。

任務的三種設法

設法粉絲怎樣才看得到該件
不設任務進得了庫就看得到
行動任務（Action task）完成創作者指定的一件事
等級任務（Tier task）分級達到創作者指定的等級，自動看得到
  • 每件內容各自設任務，一件只能設一個，不能組合多個
  • 新內容預設用哪一種設法還沒定，見媒體庫頁尾尚待確認

行動任務的種類

任務創作者要設定的內容
追蹤創作者（Follow the creator）不用設定，對象就是本創作者
加入社群（Join the community）不用設定
分享庫房頁面給 N 位朋友人數 N
分享指定貼文給 N 人指定貼文、人數 N
邀請 N 位朋友加入社群人數 N
看完指定影片指定影片
參加過一場 Watch Party不用設定
商城消費範圍二選一：任一商品，或指定商品
爆米花打賞累積 N爆米花數量 N
  • 數字 N 由創作者自填正整數
  • 除了商城消費（指定商品）之外，其餘任務怎麼認定粉絲已完成，見頁尾尚待確認

等級任務能選哪幾級

等級任務的等級，要落在進庫方法的分級條件之內。等級名稱與順序見四個分級。

  • 進庫方法有分級條件時，只能選那一級或更高
  • 好幾種進庫方法各有不同的分級條件時，以其中最低的那一級為下限
  • 只要有任何一種進庫方法不含分級條件，或庫房只靠鑰匙進庫，四級都能選
  • 靠鑰匙或不含分級條件的進庫方法進庫、但分級低於任務等級的粉絲，該件維持上鎖

解開之後會不會收回

該件的任務收回規則
不設任務跟著進庫資格走
行動任務完成一次就永久解開
粉絲失去進庫資格時，整座庫房都看不到；重新進得了庫後，已完成的任務仍算完成
等級任務跟著分級走：分級掉到任務等級以下，該件收回
分級回升後，該件自動再解開
掉級的認定依每週重算與降級緩衝

修改任務

  • 創作者事後修改某件的任務，包含：
    • 換成另一種任務
    • 改任務內容
    • 改成不設任務
  • 已經解開該件的粉絲保留
  • 其他粉絲照新任務判定

依據：5.1.7.3 F4、F8；主規格 §7.5；D377。

打得開的人數

打得開的人數讓創作者知道現在有幾位粉絲進得了這座庫房；每件內容各自有幾位看得到，見每件內容的可看人數。

打得開的人數＝達成任一種進庫方法的粉絲，加上持有未撤銷鑰匙的粉絲，重複的人只算一次。這個數字只算進庫，不受各件內容的任務影響。

例：假設達成進庫方法的有 30 人、持有鑰匙的有 5 人，其中 2 人兩者都有，打得開的人數是 33 人。
  • 逐一比對每位粉絲的紀錄，不用估算
  • 分級人數和粉絲總覽一致
  • 限量商品與場次的觸及人數，不會超過實際售出數或報到數
  • 畫面上怎麼顯示總數、各分級與依來源拆開的數字，見媒體庫的總覽

每件內容的可看人數

每件內容另有一個數字，是進得了庫、而且該件已對他解開的粉絲人數。

該件的任務可看人數
不設任務等於打得開的人數
等級任務打得開的人之中，分級達到任務等級的人數
行動任務打得開的人之中，已完成該件任務的人數

依據：5.1.7.3 F3；D377。

尚待確認

  • 「達成過」裡的 Ztor Score 與連續支持月數，是不是忠誠點數、怎麼量
  • 比對所需的粉絲逐筆紀錄何時完整建好
  • 鑰匙代碼的格式、有效期限，要不要加到期機制
  • 連結與內容的加密方式（屬工程範疇）
  • 各級福利的庫房開關，要不要和媒體庫的分級條件連動
  • 同一種進庫方法裡，能不能放兩條分級條件
  • 一座庫房最多幾種進庫方法、一種方法最多幾條條件
  • 進不了庫的粉絲，在粉絲端看不看得到這座庫房
  • 行動任務「追蹤創作者」怎麼認定粉絲已完成
  • 行動任務「加入社群」怎麼認定粉絲已完成
  • 行動任務「分享庫房頁面給 N 位朋友」怎麼認定粉絲已完成
  • 行動任務「分享指定貼文給 N 人」怎麼認定粉絲已完成
  • 行動任務「邀請 N 位朋友加入社群」怎麼認定粉絲已完成
  • 行動任務「看完指定影片」怎麼認定粉絲已完成
  • 行動任務「參加過一場 Watch Party（是否限本創作者的場次、可否指定場次）」怎麼認定粉絲已完成
  • 行動任務「爆米花打賞累積 N」怎麼認定粉絲已完成
  • 商城消費選「任一商品」時的範圍，以及指定商品與任一商品完成的認定時點
  • 數字 N 的可填範圍與上限
  • 指定貼文可以選哪些
  • 指定影片可以選哪些
  • 指定商品可以選哪些
  • 設定任務之前就已做過的行為，算不算完成
  • 進庫方法被修改後，既有等級任務低於新下限時怎麼處理
  • 不設任務改為設任務時，先前看得到的粉絲算不算已解開
  • 原為等級任務、修改後保留的粉絲，之後掉級是否仍收回
  • 逐人逐件的解開紀錄，資料從哪來、怎麼保存
  • 沒有逐人完成資料的行動任務，該件的可看人數怎麼算
