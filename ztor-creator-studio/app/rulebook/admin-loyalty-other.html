全站活動、賽季與衰減設定

Admin 在這頁設定全站活動的給分與上限、多人署名時各職務的計入比例、賽季加倍、衰減與等級保留，並查核平台常數與上線時的歷史訂單規則。

概述

  • 這頁和平台忠誠點數設定是同一個設定畫面的內容，權限、生效時點與修改紀錄都照該頁
  • 全站活動的點數 100% 計入粉絲當下的主要應援對象，選擇與切換主要應援對象的操作在粉絲端
  • 平台常數與歷史訂單的規則只能看，不能改

操作流程

Admin 按編輯改參數或新增一段賽季加倍，儲存後依參數類別生效。

1要改哪一項？
全站活動或職務比例改給分、上限或比例
賽季加倍新增一段期間
衰減或等級保留改天數
2儲存留一筆修改紀錄
3只作用於之後的事件已入帳的點數不改寫
下一次每週重算起生效不改寫點數

    • 賽季加倍：見賽季加倍
    • 衰減或等級保留：見衰減與等級保留

  3. 依參數類別生效，見平台忠誠點數設定的生效時點

全站活動給多少點數、能拿幾次

全站活動是 ztor 平台層級的行為，點數由平台發；Admin 在這裡設定每一種全站活動給多少點數、上限多少。各項的預設值，見四項全站活動；點數怎麼入帳、什麼時候作廢，見點數怎麼入帳；上限怎麼算、點數計入哪位創作者，見能拿幾次與點數算給誰。

每項全站活動各有一組給分與上限，都可以改；下表規則格是預設值。資格條件見粉絲分級的全站活動與主要應援對象，這頁只設定給分與上限。

能拿幾次與點數算給誰

  • 標 90 天的上限從給分當下往回算最近 90 天，在給分當下判定，不追溯
  • 上限以每位用戶全站合計計算，切換主要應援對象不會重置額度
  • 連續簽到中斷只是重新數，不扣分，也不顯示愧疚計數（提醒粉絲「斷了幾天」「少拿多少」的計數）
  • 新朋友在 7 天內同時追蹤某位創作者時，兩份分數都給：加入 Ztor 的 1,000 分計入邀請人的主要應援對象，追蹤的 400 分計入被追蹤的那位創作者
  • 創作者設定的各類行為份量不影響全站活動

賽季加倍

賽季加倍讓 Admin 指定哪些期間、哪些範圍的計分要加倍、加幾倍。

每一段指定加倍的起訖時間
行為發生在任何一段期間內，就適用加倍
新增一段期間—多加一段加倍期間，儲存後記入平台忠誠點數設定的修改紀錄
範圍（Scope）—每一段選一個：全平台，或特定創作者
加倍幾倍（畫面上的「倍率」Multiplier）—每一段各設一個

狀態什麼時候畫面

進行中現在落在期間內尚待確認
已結束期間已過尚待確認

衰減與等級保留

這一區讓 Admin 設定點數隨時間淡出的速度，以及粉絲多久沒有行為就往下掉一階，下表都可以改；掉級前的緩衝天數見平台忠誠點數設定的分級門檻、名稱與降級。

功能或欄位出現條件與必填規則
點數減半要多久（畫面上的「衰減半衰期」）—預設 45 天
點數每過這段天數剩一半：
第 45 天剩 50%
第 90 天剩 25%
第 180 天約剩 6%
多久沒有行為就往下掉一階（Inactive days before dropping a tier）—預設 90 天
粉絲每連續這麼多天沒有任何行為，等級上限往下掉一階：
第 90 天最多留在原等級的下一階
第 180 天再往下一階
第 270 天掉到一般粉絲，不再往下
點數保留並照曲線繼續衰減，仍佔該級名額
回來做任何一件事就解除
這筆點數剩多少點數減半要多久 · 45 天
→ 50%→ 25%→ 約 6%
等級上限往下掉一階 · 90 天
核心圈超級粉絲上榜粉絲一般粉絲
第 0 天第 45 天第 90 天第 180 天第 270 天

時間軸圖：假設一位核心圈粉絲在第 0 天做了最後一次行為、入帳一筆點數，之後都沒有行為，天數都用預設值。上面一列每一段的數字是這段結束那天剩下的比例；下面一列是這段時間最多能留在哪一級。實際等級取這個上限與依排名算出的等級中較低的那一個，見粉絲分級的衰減與沉睡。

  • 購買類的衰減作用在金額價值上，其他類直接作用在點數上；線下掃碼領點不衰減
  • 往下掉一階造成的降級，同樣適用降級緩衝

上線時把歷史訂單算進點數

忠誠點數上線時，平台把上線前的歷史訂單回算成點數（畫面上的「回填」），粉絲一上線就有分；Admin 在這裡查核規則，創作者不需要操作。
