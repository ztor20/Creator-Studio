活動匯入管理

Admin（平台營運）在這頁監看每位 creator 從 bookyay 自動匯入的活動，並把還沒設完套組的活動補齊。

1bookyay 活動的監看與補完

創作者活動管理是 Admin 跨 creator 的工作台，也是處理 bookyay 活動的唯一入口；匯入由系統自動完成，Admin 負責監看與補完。

  • 活動票券的撤銷也由 Admin 執行，見活動總覽的刪除草稿與取消活動

Creator 清單

Creator 清單讓 Admin 一眼看出每位 creator 的活動狀況，決定先處理哪一位。

  • 每列一定顯示 creator 名稱與 bookyay 帳號綁定狀態（已綁定／未綁定）
  • 已綁定時，另顯示已匯入場次數與待設定套組場次數
  • 未綁定時不顯示任何場次數字，避免 0 被讀成「查過了、結果是零」
  • 網址可以帶 creator 識別，直接開到這位 creator
  • 網址帶的 creator 不存在時顯示錯誤，不換成另一位

篩選與搜尋

  • 篩選三選一：全部、有待設定、未綁定
  • 搜尋 creator 名稱或店鋪識別

已匯入活動清單

已匯入活動清單讓 Admin 看見這位 creator 有哪些活動已在 ztor 裡、各自設到哪一步。

  • 唯讀清單，列出這位 creator 已匯入 ztor 的全部活動
  • 每筆至少顯示活動名稱、日期與場地
  • 每筆狀態二選一：待設定套組（已匯入、票務套組還沒設完）或 已完成
  • 已完成的活動沒有任何操作

繼續設定

  • 「繼續設定」是清單唯一的動作，只出現在待設定套組的活動
  • 按下後帶著這場的 bookyay 資料進建立活動流程，不經第一步的帶入詢問
  • 欄位怎麼帶、哪些鎖定，照從 bookyay 帶入活動

自動匯入與更新檢查

這一區讓 Admin 知道活動怎麼來、清單有多新，必要時要系統立刻再問一次 bookyay。

  • creator 綁定 bookyay 帳號後，該創作者在 bookyay 上的活動由系統自動匯入，Admin 不需要執行匯入
  • 系統持續檢查 bookyay 有沒有更新
  • 畫面顯示「最後檢查時間」，不論這次有沒有搬進新活動都會更新
  • Admin 可以按「重新檢查」，要系統立刻再問一次 bookyay，完成後清單依結果重整
  • bookyay 端刪除或隱藏活動時，ztor 端的活動轉為下架、資料保留
  • 已綁定但一場活動都沒有時，清單顯示空狀態，最後檢查時間與重新檢查仍然顯示

還沒綁定 bookyay 的 creator

選到還沒綁定 bookyay 帳號的 creator 時，右側顯示空狀態，說明為什麼看不到活動與下一步。

  • 空狀態說明這位 creator 還沒綁定 bookyay 帳號，所以沒有活動
  • 空狀態說明綁定之後活動會自動搬進來，Admin 不必再回來匯入
  • 空狀態提供前往綁定的入口
