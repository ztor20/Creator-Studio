活動匯入管理

1Admin 活動匯入管理

「創作者活動管理」是 Admin 端跨 creator 的工作台，也是 bookyay 創作者活動唯一的處理入口。自動匯入之後，Admin 的工作是監看與補完，不是搬運。

Creator 清單

  • 每列一定顯示：creator 名稱、bookyay 帳號綁定狀態（已綁定／未綁定）。
  • 已綁定時另顯示：已匯入場次數、待設定套組場次數。
  • 未綁定時不顯示任何場次數字——沒綁定就不會有匯入，顯示 0 會被讀成「查過了、結果是零」。
  • 篩選三選一：全部、有待設定、未綁定；搜尋 creator 名稱或店鋪識別。
  • 網址可帶 creator 識別直接開到該 creator；查無此 creator 時顯示錯誤，不靜默換成另一位。

已匯入活動清單

  • 唯讀清單，列出該 creator 已匯入 ztor 的全部活動；每筆至少顯示活動名稱、日期與場地。
  • 每筆狀態二選一：待設定套組（已匯入、票務套組還沒設完）或 已完成。
  • 唯一的動作是「繼續設定」，只出現在待設定套組的活動：帶著該場 bookyay 資料進建立活動流程，不經第一步的帶入詢問；欄位怎麼帶、哪些鎖定照「從 bookyay 匯入」。已完成的活動沒有任何操作。

自動匯入與更新檢查

  • creator 綁定 bookyay 帳號後，她在 bookyay 上的活動由系統自動匯入，Admin 不需要執行匯入動作。
  • 系統持續檢查 bookyay 是否有更新；畫面顯示「最後檢查時間」——不論這次有沒有搬進新活動都會更新。
  • Admin 可以按「重新檢查」要系統立刻再問一次 bookyay，完成後清單依結果重整。
  • bookyay 端刪除或隱藏活動時，ztor 端該活動轉為下架、資料保留。
  • 已綁定但一場活動都沒有時，清單顯示空狀態，但最後檢查時間與重新檢查仍然顯示。

未綁定的 creator

選到還沒綁定 bookyay 帳號的 creator 時，右側顯示空狀態，說明為什麼沒有活動、以及綁定之後活動會自動搬進來、Admin 不必再回來匯入，並提供前往綁定的入口。

活動票券的撤銷同樣由 Admin 執行（「活動流程總覽」）。依據：5.1.0.6 F1～F6；D233、D236、D238、D253、D282、D283。
