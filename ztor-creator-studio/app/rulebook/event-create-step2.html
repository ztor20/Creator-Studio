步驟 2：基本資料

創作者在這一步填粉絲認識這場活動要看的基本資料，並決定結帳時要不要請粉絲同意條款。8 個步驟的全貌見建立活動。

這一步的規則

基本資料的規則集中在描述、素材與條款三件事。描述怎麼用文字、圖片、影片區塊組成，見描述；文字區塊能用哪些格式，見描述的文字格式；插在描述裡的圖片與影片套用什麼規格，見描述裡的圖片與影片；主視覺、橫式橫幅、圖庫與影片預告各有什麼規格，見圖片與影片；粉絲結帳時要不要勾選同意條款，見條款與細則；從 bookyay 帶入的活動哪些欄位鎖定，見從 bookyay 帶入時。

  • 每個區塊都沒有標題；需要小標時，用粗體自己寫一行
  • 第一個文字區塊在建立活動時就有
  • 按「新增描述（Add description）」多加一個文字區塊，可以重複加
  • 在文字區塊插入圖片或影片時，圖片或影片自成一個區塊，排在插入點之後
  • 每個區塊都可以拖動調整順序，也可以刪除

  • 描述必填：至少要有一個文字區塊有字
  • 只有圖片或影片區塊、沒有文字時，描述不算已填
  • 粉絲活動頁的「關於活動」照區塊排定的順序呈現文字、圖片與影片
  • 描述只做活動層級，整場共用，不綁定特定門票
  • 描述是給粉絲閱讀的資訊，不進結帳，粉絲不需要勾選同意；結帳時的同意項目是條款與細則，兩者互不取代
  • 每個文字區塊各是一個可翻譯欄位，譯文在步驟 8 手動填，見預覽與發布的翻譯
  • 描述不屬於高影響變更，見改場地或時間要先確認

描述的文字格式

文字區塊有六種格式工具，其他格式（例如標題字級、顏色）不做。

描述裡的圖片與影片

描述裡的圖片區塊與影片區塊是描述的一部分，規格跟素材格不同。

  • 圖片：格式與單檔大小沿用展示素材的圖片規則
  • 描述裡的圖片與影片尺寸、比例不限，素材格的 2:3 與最小尺寸不套用
  • 影片：MP4、MOV、WEBM，單檔 1.8GB
  • 圖片與影片不翻譯，各語系共用
  • 譯文顯示時，圖片與影片的位置跟原文相同

條款與細則

條款與細則決定粉絲結帳時要不要看到並勾選同意兩項條款。

  • 兩個開關各附一段文字：「直接促銷同意」附行銷訊息文字，「條款及細則」附條款文字
  • 開關控制的是粉絲結帳時看不看得到、要不要勾選同意，不是創作者自己勾同意
  • 自建的活動：兩個開關預設關，兩段文字由運營每場自己填
  • 從 bookyay 帶入的活動：「條款及細則」的開關與條款文字由 bookyay 帶入並鎖定，「直接促銷同意」仍由運營自己填，見條款及細則怎麼帶入
  • 描述是給粉絲閱讀的資訊，條款與細則是結帳時的同意項目，兩者互不取代

操作流程

這一步由上往下填完，再按下一步進步驟 3。

  1. 填活動名稱；需要時填亮點
  2. 選活動國家與活動語言
  3. 在第一個文字區塊寫描述
    • 要分段時，按「新增描述（Add description）」多加文字區塊
    • 要放圖片或影片時，從文字區塊插入，圖片或影片成為獨立區塊
    • 拖動區塊調整粉絲看到的順序，不要的區塊可以刪除
  4. 需要時加表演陣容：搜尋 ztor 用戶，或直接輸入外部表演者名稱
  5. 上傳主視覺、橫式橫幅與圖庫；需要時上傳影片預告
  6. 決定結帳時要不要請粉絲同意：打開需要的開關並填文字
  7. 按下一步，進步驟 3：場次
  • 必填欄位在這一步即時檢查，沒填完也能切到其他步驟
  • 按發布時，沒填的必填欄位一起列出並擋下，見發布前檢核
  • 要換活動類型時，從這一步回到選活動類型，見換活動類型
  • 從 bookyay 帶入的活動，這一步的鎖定欄位只能看、不能改，見從 bookyay 帶入時

依據：5.1.6.1 §4.2、§4.8 F11、§4.9；D060、D340、D354。

尚待確認

  • 活動名稱與描述的字數上下限、亮點的字數上限
  • 活動國家的用途，以及是否必填
  • 活動語言是否影響粉絲端的篩選或推薦
  • bookyay 帶入時沒有任何語言值怎麼處理
  • 表演陣容每一位的欄位（頭像、角色、連結）、人數上限與外部名稱的檢查
  • 連結是否只接受 http 或 https 網址，粉絲端是否以新分頁開啟
  • 描述的圖片與影片數量上限：是否為整份描述合計最多 10 個
  • 原本已存在的說明區塊轉成文字區塊時，原標題是否併入內文第一行並設為粗體
  • 描述裡的圖片與影片是否不佔素材格額度、也不當縮圖
  • 展示素材的圖片格式與單檔上限（描述裡的圖片沿用同一套）
  • 上傳的素材比例不是 2:3 時怎麼處理：拒收、自動裁切，或只在顯示時裁切
  • 譯文能不能也套文字格式
  • 影片預告（MP4／MOV、2GB）與素材格、描述裡的影片（MP4／MOV／WEBM、1.8GB）兩套規格，日後要不要收斂成一套
  • 粉絲同意條款的紀錄怎麼保存、要符合哪些法規
