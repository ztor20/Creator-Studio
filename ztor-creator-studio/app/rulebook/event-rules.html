活動規則

創作者與 Admin 照這頁的規則判斷一場活動走到哪個階段、什麼時候買得到、能做哪些動作，以及票務商品怎麼跟著變，其他活動頁提到這些規則時會連回這裡。從匯入或建立到結案的整條旅程，見活動用戶旅程圖。

活動的階段

一場活動從草稿單向走到結束，同時只落在一個階段。每個階段下創作者與 Admin 能做什麼，見各階段誰能做什麼；一場活動算在哪個階段，見階段怎麼判定。

草稿→已排程→售票中→進行中→已結束 已排程或售票中被取消 → 已取消

階段怎麼判定

  • 一場活動取已經走到最遠的那一個階段，例如活動當天現場仍在售票，算進行中
  • 已發布、等待定時上架的活動算已排程
  • 一場活動可以有多個場次，所有場次共用一份場地；每一站換場地的巡迴，改成每站各建一場活動，見步驟 3 場次

依據：5.1.6 F1、F3、F5；5.1.6.1 F12b；5.1.6.2 §2、F14；5.1.6.3 §2.1、頁面狀態；主規格 §4.1 第 5 項、§7.2、§7.14「活動販售的時間層級」「活動取消或下架時連動組合包」「封存與刪除」；D188、D253、D282、D292、D294、D342、D352、D361、D371、D375、D391。

什麼時候買得到

單張門票與票務商品預設用活動的售票期間販售，也可以各自設時間。

  • 單張門票加了限時購買條件時，照限時購買的期間販售
  • 票務商品的上架、下架、開賣、停售四個時間預設跟隨活動；跟隨開賣時就是活動的售票期間，另設時用另設的值，見組合包與票務商品
  • 每個時間欄位在儲存時就地檢查，超出範圍就擋下儲存

活動設定是門票與票務商品的上限

建立活動時一起建立的單張門票與票務商品，上架、開賣、顯示都以活動的設定為上限，只能比活動窄，不能比活動寬。

設定活動怎麼限制單張門票與票務商品
上架活動未上架、已下架、已取消或已結束時，票務商品不能上架
活動下架時票務商品怎麼跟著變，見票務商品怎麼跟著活動變動
開賣單張門票的限時購買、票務商品的開賣與停售，都不能晚於活動停售
活動停售後就不能再買
單張門票的兩種限時折扣不在此限，期間可以晚於活動停售
顯示活動隱藏時，含本活動門票的組合包在電子商店的清單與搜尋都找不到，見組合包的上架、顯示、開賣開關
單張門票的顯示開關不受影響：經活動連結進入的活動頁，照常列出顯示中的門票
活動隱藏期間，含本活動門票的組合包可以經組合包自己的非公開連結購買
  • 唯一的例外是提前販售（早鳥）：單張門票的限時購買、票務商品另設的開賣，可以早於活動的正式開賣，但仍要在活動上架區間內
  • 單張門票與票務商品自己收窄（例如先停售、隱藏或下架），不回寫活動

早鳥與預售

早於正式開賣就能買的時間叫其他售票時間，也就是預售；預售一開始，活動就進入售票中。

  • 其他售票時間有兩種：
    • 單張門票的限時購買早於正式開賣，就是早鳥的一種
    • 票務商品另設的開賣早於正式開賣
  • 每張門票可以各自設不同的早鳥時間
  • 預售屬於售票中，所以已排程的活動不會有成交
  • 活動選立即開賣時，售票期間從上架那一刻開始

活動的動作與效果

每個動作各寫能用的階段、條件與效果，依序是：

  • 售票後還能改什麼：售票後的編輯限制
  • 草稿怎麼刪：刪除草稿
  • 場次與門票能不能刪：移除場次與門票
  • 活動找不找得到：上架與下架
  • 活動在不在公開清單：顯示、隱藏與非公開連結
  • 暫時不賣或賣完：暫停售票與完售
  • 三種停止販售做法的差別：停止販售的三種做法
  • 票券怎麼作廢：撤銷票券

售票後的編輯限制

進入售票中後，發布設定與會影響持票人的欄位受限制，其餘內容照常可改；逐欄規則見活動詳情的哪些欄位能改。

  • 發布設定在售票中與進行中只能改這幾項：
    • 顯示設定：隨時切換
    • 停售時間：可以提前或延後
    • 定時下架的下架時間：只能延後
  • 開賣時間與取票方式不能改，發布設定的其他項目唯讀
  • 改時間造成門票的限時購買或票務商品另設的時間落到上架區間外，或晚於活動停售時，擋下這次修改並列出衝突項目
  • 場次與門票（含未售出的）都不能刪除，只能暫停售票或隱藏，見移除場次與門票
  • 改場地名稱、完整地址、活動國家、場次日期與開始時間、跨日的結束日期，儲存前要確認，並通知持票人，見改場地或時間要先確認
  • ztor 自建的活動，發布後可以改活動預設購票規則與單張門票的購買條件：
    • 可以新增、修改、移除條件
    • 只影響之後的購買，已售出的票與訂單不變
    • 限購改小時，已買超過新上限的粉絲不追回，只是不能再買
    • 限時條件的期間照建立活動同一套檢查，超出就擋下儲存
    • 不算高影響變更，儲存時不出現確認，也不通知持票人
  • bookyay 匯入的活動，購買條件唯讀，要改回 bookyay 改

刪除草稿

草稿可以刪除；發布過的活動不能刪除，只能取消。

  • 刪除草稿系列的母列，整個系列連同底下的場次一起刪除
  • 草稿系列的子場也可以單獨刪除，同樣要確認
  • 活動沒有封存，發布後的終點是已結束或已取消
  • 一起刪除的組合包，見下方票務商品怎麼跟著活動變動

移除場次與門票

開賣前可以移除場次與門票；活動進入售票中之後，場次和門票都不能刪除。

  • 草稿與已排程的活動可以移除場次，至少留一場
  • 該場已有門票時，移除前跳出確認，列出會一併刪除的門票；確認後場次與這些門票一起刪除
    • 該場的門票包括票種在這一場組合出的門票，以及指定這一場的獨立票
  • 該場沒有任何門票時直接移除，不跳確認
  • 一併刪除門票後，已排程的活動會沒有可賣的東西時，擋下這次移除，見可賣條件與發布檢核
  • 被刪的門票列在組合包的允許門票清單時，組合包保留；那些門票在粉絲端的組合包選項裡隱藏、不能選，在 Creator Studio 的組合包畫面顯示為停用
  • 某一個門票成員允許的門票全部被刪時，組合包不能賣，狀態標「無法販售（Unavailable）」，取代原本的「即將開賣」或「販售中」，見票務商品
  • 活動進入售票中之後（售票中、進行中），場次和門票（含未售出的）都不能刪除，只能暫停售票或隱藏
  • bookyay 匯入的活動不能增刪場次，帶入的門票也不能刪除

上架與下架

上架是階段以外的另一回事。

  • 草稿以外的五個階段，創作者與 Admin 都能下架與重新上架活動；下架與重新上架都不改變階段
  • 下架一律先確認；已有成交時，確認視窗說明已售出的票照常有效
  • 定時下架打開時，到了下架時間自動下架；定時下架關閉時不會自動下架
  • 已下架的活動留在原本的階段，另加「已下架」徽章
  • 下架後，公開與非公開連結都失效，指向這場活動的入口（活動頁連結、清單、搜尋結果）隨活動消失；創作者的優惠碼本身不動
  • 已結束或已取消的活動重新上架前會先提示：上架後粉絲找得到活動頁，但不能購買
  • 含這場活動門票的組合包怎麼跟著下架，見下方票務商品怎麼跟著活動變動

顯示、隱藏與非公開連結

顯示設定（畫面上的「顯示於商店」）管活動在不在 ztor 的活動列表與搜尋結果，跟上架是兩回事。

  • 顯示：活動出現在活動列表與搜尋結果
  • 隱藏：活動不在公開清單，只能經活動的非公開連結進入
  • 切成隱藏時產生一條非公開連結與 QR，發布後才生效；創作者可以隨時重置，重置後舊連結失效、產生新連結
  • 由隱藏改回顯示時，原本的非公開連結失效；之後再改隱藏，產生新連結，不沿用舊連結
  • 下架時，公開與非公開連結都失效
  • 已排程、售票中與進行中都能切換；已結束與已取消整頁唯讀
  • 活動隱藏期間，經非公開連結進入的活動頁照常列出顯示中的門票；含本活動門票的組合包怎麼跟著變，見活動設定是門票與票務商品的上限
  • bookyay 匯入的活動照 bookyay 的活動性質帶入：公開活動→顯示，私人活動→隱藏；帶入後可以自己切換，bookyay 端事後改活動性質不覆蓋

暫停售票與完售

暫停售票與完售都不是階段，活動照時間走，另加徽章。

  • 售票中與進行中，創作者與 Admin 都可以暫停整場活動的販售，也能恢復；暫停時另加「暫停售票」徽章
  • 暫停時活動頁照常看得到，所有門票與含其門票的票務商品都不能購買
  • 暫停前已售出的票照常有效
  • 暫停期間，粉絲端活動頁顯示「暫停售票中」，購買鈕停用
  • bookyay 匯入的活動同樣可以暫停
  • 單張門票的暫停售票照樣保留，跟整場暫停並存；單張門票暫停與隱藏的差別，見隱藏與暫停售票的差別
  • 所有門票與票務商品都賣完時，活動另加「完售」徽章，仍照時間落在售票中，販售照時程結束
  • 有票回補、不再全部賣完時，「完售」徽章移除
  • 完售後粉絲端只顯示「完售」，先不提供候補等其他引導

停止販售的三種做法

三種做法效果各不相同。

  • 暫停售票：活動頁看得到，但不能購買
  • 下架：活動頁找不到，也不能購買
  • 取消：結束這場活動

撤銷票券

  • 平台不提供退款動作，票券的取消一律用撤銷；撤銷在哪裡執行，依活動來源而不同，見下方ztor 自建與 bookyay 匯入的差別
  • 創作者看得到撤銷入口與撤銷紀錄，但不能操作；需要撤銷時，創作者在平台外聯繫 Admin

依據：5.1.6 F3、F5；5.1.6.1 F7、F12b、F22、F25；5.1.6.2 F7、F9、F12、F14；5.1.6.3 §2.1、§2.9.2；主規格 §4.1 第 5 項、§7.2、§7.14「活動層級暫停售票與完售」「非公開連結」「下架確認與組合包連動」「封存與刪除」；D188、D253、D282、D294、D341、D361、D363、D364、D371、D375、D388、D389、D390、D391。

票務商品怎麼跟著活動變動

門票相當於一種商品，可以被包進組合包，含門票的組合包就是票務商品，規則在組合包與票務商品。票務商品的設定怎麼受活動限制，見票務商品的設定與活動；活動不賣了票務商品怎麼辦，見活動下架、取消或結束時；刪除草稿時一起刪什麼，見刪除草稿時。

票務商品的設定與活動

  • 票務商品另設的時間要在活動的上架區間內，可以早於活動開賣，見組合包與票務商品的上架與開賣
  • 票務商品的上架、開賣、顯示不能比活動寬，見活動設定是門票與票務商品的上限
  • 票務商品自己的三個開關不回寫活動：關掉組合包，不影響活動本身與單張門票的販售

活動下架、取消或結束時

  • 下架時，含這場活動門票的上架中組合包一起下架
  • 活動重新上架時，組合包不會自動上架
  • 取消活動的確認內容，列出會一起下架的組合包名稱
  • 活動取消、下架或結束造成的連動下架，不算可賣條件與發布檢核要擋下的動作

刪除草稿時

  • 草稿活動被刪除時，一起刪除的組合包有兩種：
    • bookyay 套票自動建立的組合包（這類組合包本身沒有刪除入口，見從 bookyay 帶入活動）
    • 創作者自己建立、成員含這場活動門票的草稿組合包
  • 刪除確認時列出哪些組合包會一起刪除

依據：5.1.6.1 F12b；5.1.6.3 §2.1；主規格 §7.14「活動取消或下架時連動組合包」「封存與刪除」；D292、D293、D294、D331、D340、D342、D352、D363、D371。
