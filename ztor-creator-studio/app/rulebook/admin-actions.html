Admin 專屬操作總表

Admin 在這張表查全站有哪幾項操作只有 Admin 能做，以及創作者介面對創作者怎麼呈現；各頁只寫自己那一項，這裡列全。

概述

  • Admin 專屬操作是創作者介面裡，只在 Admin 代管創作者時能執行的操作；Admin 介面本身的頁面不在這張表裡，見第 9 章各頁
  • 對創作者的呈現只有兩種：「看得到、不能按」與「看不到」
  • 手冊第 1～8 章提到這些操作時，用同一套寫法並加上 Admin 標籤，讓讀者分得出哪些是創作者能做、哪些是 Admin 才能做

Admin 專屬操作

下表每一項都連到手冊裡寫細節的那一節。

  • 「看得到、不能按」的操作，創作者看得到入口，但不能按
  • 「看不到」的操作，只在 Admin 代管創作者時才出現在畫面上，創作者本人的畫面沒有這個入口
  • 撤銷品項與撤銷票券的前置，是 Admin 已在平台外完成退款，見撤銷的步驟
  • 撤銷（商品、整單、活動門票）一律不寄 email 給買家或持票人，撤銷原因只記在訂單紀錄與撤銷紀錄給 Admin 查

Admin 代管不能做的事

Admin 代管創作者時，創作者能做的事原則上都能做；下面三件事是例外，Admin 代管時不能替創作者做。

  • 提款
  • 改密碼
  • 改收款帳戶

另有一條界線：代管身分不能順手把自己送的件審過，審核一律回到影片上架審核，以 Admin 身分執行。

這條界線來自金流與帳號安全要保守的原則。提款、改密碼、改收款帳戶一律由創作者本人做。

依據：主規格 §4.1、§4.4；D352、D510。
