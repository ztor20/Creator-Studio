分級設定

創作者在分級設定（Tier settings）設定各分級的兩道門檻與計分設定，並查核目前生效的是哪一版。門檻與點數的規則見粉絲分級。

概述

  • 分級設定和各級福利放在粉絲總覽的同一個「粉絲分級設定」分頁，從分級分布的「分級設定（Tier settings）」進入
  • 門檻與計分設定改了，下一次每週重算才生效；各級福利則是儲存後立即生效
  • 全站活動、賽季加倍週、衰減、多久沒有行為就往下掉一階、降級緩衝由 Admin 設定，不在這頁，見誰能調整什麼

操作流程

創作者調好門檻與計分設定後儲存，通過檢查就存成新的設定版本，等下一次每週重算生效。

1進分級設定從粉絲總覽或粉絲詳情的「分級設定」
2調門檻與計分設定看「將重新分級 N 位粉絲」預覽
3按儲存
4門檻的高低順序對嗎？
存成新的設定版本下一次每週重算才生效
擋下儲存改好再存

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 從粉絲總覽分級分布或粉絲詳情的「分級設定」進來
  2. 在門檻與計分設定調整數值，並看「將重新分級 N 位粉絲」的預覽
  3. 按儲存，見儲存與放棄
  4. 門檻的高低順序對嗎？見儲存前檢查

    • 不對：擋下儲存
  • 不想保留這次的修改：按放棄，回到上次儲存的版本

依據：5.1.7.6 F1、F2、F4、使用情境；5.1.7 F3、F8。

功能與欄位

每一級的兩道門檻，見門檻；各類行為與購買品項的份量、互動與推薦的上限，見計分設定；查核目前生效的是哪一版，見設定版本；儲存或放棄這次的修改，見儲存與放棄。

設定版本

設定版本保存每一次儲存的門檻與計分設定，讓創作者查核目前生效的是哪一版。

  • 每次儲存門檻或計分設定，都會存成一個不能修改的設定版本
  • 已發生的收入、粉絲當時的分級，不會因為後來的調整被改寫
  • 版本歷史是唯讀清單，列出每個版本與生效時間

儲存與放棄

儲存與放棄管的是門檻與計分設定這次的修改，畫面上顯示這次修改的儲存狀態。

尚待確認

  • 創作者能調整的份量與上限，各自可調的範圍
  • 付費首映對應哪一種品項
  • 同一次儲存時，門檻（下次重算才生效）與福利（立即生效）怎麼分別套用
  • 門檻順序檢查：相鄰兩級能不能設成一樣、要不要和一般粉絲比、輸入時還是儲存時檢查
  • 「將重新分級 N 位粉絲」何時計算、算進哪些粉絲
  • 各級目前人數多久更新一次
  • 設定版本保留多久、能不能看差異、匯出或還原舊版
  • 門檻、人數與份量的畫面數值是原型示意，正式資料來源還沒定
  • 分級設定載入中時畫面怎麼顯示
  • 門檻與點數規則的待確認列在粉絲分級頁尾
