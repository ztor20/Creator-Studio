IP Bank Reporting

Admin 在 IP Bank Reporting 選一部影片與一段期間，看這部影片的收入分給各權利人與平台各多少。這頁只能看，要改分配回 Admin IP Bank。

概述

  • 報表的數字是從 Admin IP Bank 的權利人與分潤比例，加上收入管理（Earnings）與 Profile 既有的提款（payout）結果推算出來的衍生數字（derived figures），目前是示意（illustrative），畫面上要標明這兩點
  • 收入與提款的正式資料只在收入管理；這頁不另記一份，也不能新增、編輯、移除、調整分潤比例或設定提款
  • Admin 不用先選定創作者就能進這頁

操作流程

Admin 先選影片與期間，有分配資料就讀摘要與分潤列表，沒有就回 Admin IP Bank 建立。

1進 IP Bank Reporting
2選影片與期間摘要與列表跟著更新
3這部影片有分配資料嗎？
讀摘要與分潤列表只能看
沒有分配資料引導到 Admin IP Bank 建立

  • 發現 IP、權利人或分潤比例不對時，回 Admin IP Bank 修正；這頁不能改

統計摘要

四個指標讓 Admin 先掌握一部影片的收入、分給權利人的部分與平台剩餘之間的關係。

指標內容
影片淨收入（Film net revenue）這部影片在選定期間的報表基準收入；正式定義見頁尾尚待確認
已分配給權利人（Allocated to owners）分潤列表各權利人應計金額的加總
平台剩餘（Platform remainder）分潤列表平台列的比例與金額
更新節奏（Refresh cadence）顯示資料多久更新一次；實際節奏見頁尾尚待確認

分潤列表

分潤列表讓 Admin 對照每一筆 IP 與權利人的分潤比例，以及對應的金額。一列是一筆 IP 權利分配，最後一列是平台；各金額怎麼算見分潤金額怎麼算。

欄位內容
IP 名稱（IP title）對應 Admin IP Bank 裡的那一筆 IP
權利人（Owner）對應那一筆的權利人；平台列不屬於任何權利人
狀態（Status）已連結（Linked）或已邀請，已邀請在報表上簡寫為 Pending，見權利人的連結狀態
分潤比例（Share）這位權利人在這部影片的比例
平台列顯示沒分配出去的比例
應計金額（Owed）這位權利人在這部影片應得的金額
已提款（Withdrawn）這位權利人在這部影片已經提走的金額
可用金額（Available）這位權利人在這部影片還能提的金額

情況畫面

分潤金額怎麼算

每位權利人的金額都只看同一部影片：應計金額照分潤比例算，扣掉這部影片已提款的部分就是可用金額。

金額怎麼算
應計金額（Owed）影片淨收入 × 分潤比例
已提款（Withdrawn）讀取收入管理（Earnings）與 Profile 既有的提款（payout）結果，只算同一位權利人在同一部影片的部分
不能拿這位權利人在所有影片的提款總額來扣
可用金額（Available）應計金額 − 已提款
平台列只顯示沒分配出去的比例與對應的應計金額
不顯示已提款與可用金額

權利人還在已邀請時，應計金額照常累積，提款鎖住直到認領帳號、轉為已連結：

  • 已提款：不顯示數值
  • 可用金額：顯示「locked until claim」

範例（數字皆為假設）：影片 A 在選定期間的淨收入 100,000；權利人甲 30%、已連結、已提款 10,000；權利人乙 20%、已邀請。

  • 甲：應計 30,000，可用 20,000
  • 乙：應計 20,000，已提款不顯示，可用金額顯示「locked until claim」
  • 平台列：50%，應計 50,000

依據：5.1.0.2 F3、F4；主規格 §7.3「IP Bank Owed」「IP Bank Available」、§7.6；D004、D129。
