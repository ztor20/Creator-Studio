Creator 列表

Admin 在 Creator 管理（Creator Management）查看平台上所有創作者、建立新的創作者，並選一位進入他的工作區代為操作。

概述

  • Creator 管理是 Admin 登入後落地的第一頁，也是進入任何一位創作者工作區的入口
  • 創作者本人先在 ztor 前台自己註冊帳號，Admin 再以這個帳號建立創作者；建好後創作者也能自己登入 Creator Studio
  • 修改單一創作者的店鋪網址或電話，在Creator 詳情

操作流程

創作者從註冊帳號到被 Admin 代為操作，走下面五步。

1註冊 ztor 帳號創作者本人在 ztor 前台註冊
2建立創作者Admin 以這個帳號建立
3自動產生電子商店創作者狀態為啟用中
4前往工作區Admin 代為操作
5返回 Creator 管理或改進入另一位創作者

流程圖：由左往右走，圓圈數字對應下方步驟清單的編號。

  1. 創作者本人在 ztor 前台（買家端）自己註冊 ztor 帳號，這一步不在 Creator Studio
  2. Admin 按「建立創作者」，填寫的欄位見建立創作者
  3. 建立成功後，自動產生這位創作者的電子商店；創作者狀態為啟用中
  4. Admin 在名冊按「前往工作區」，進入後能做什麼見代為操作創作者的工作區
  5. 做完後返回 Creator 管理，或改進入另一位創作者
  • 停用或重新啟用一位創作者，見創作者的狀態

依據：5.1.0 頁面定位、F2、F4、情境；D086、D107、D170。

創作者名冊

名冊讓 Admin 掌握平台上所有創作者的狀態，決定要進入哪一位。怎麼縮小範圍，見篩選與搜尋；每一列顯示什麼、能做什麼，見清單；新增一位，見建立創作者。

篩選與搜尋

篩選與搜尋都只影響檢視，不改名冊的資料。

功能或欄位出現條件與必填規則
狀態篩選（Status）—單選，選項：
全部
啟用中
已停用
每個選項附數量，隨名冊即時重算
狀態的意思見創作者的狀態
搜尋（Search）—用創作者名稱或店鋪識別縮小名冊
清除搜尋或篩選沒有結果時名冊改顯示查無符合，並提供清除的入口
跟還沒有任何創作者的空狀態分開顯示

清單

一列一位創作者，每一列顯示：

  • 頭像
  • 名稱：顯示名稱或藝名
  • 店鋪識別：這位創作者電子商店的網址識別，例如 ztor.com/shop/denise
  • 創建時間：帳號建立的時間，自動記錄
  • 狀態：啟用中或已停用
功能或欄位出現條件與必填規則
前往工作區（Enter Workspace）—進入這位創作者的工作區代為操作，見代為操作創作者的工作區
編輯（Edit）—打開這位創作者的Creator 詳情
能改店鋪網址與電話，ztor 帳號不能改
停用（Disable）狀態是啟用中切為已停用，效果見創作者的狀態
啟用（Enable）狀態是已停用切回啟用中
  • 狀態變更後，清單那一列立刻反映
  • 平台還沒有任何創作者時，名冊改顯示空狀態與建立創作者的引導

建立創作者

按「建立創作者（Create）」時出現。對象是創作者本人已在 ztor 前台註冊的帳號，不是憑空開一個新帳號。

功能或欄位出現條件與必填規則
名稱（Creator Name）必填創作者的顯示名稱或藝名
頭像（Avatar）—創作者的頭像圖片
email必填對應創作者已註冊的 ztor 帳號，也用來聯絡
電話（Phone）選填—
店鋪網址（Shop URL）必填格式 ztor.com/shop/xxx
全平台唯一，建立時就擋下重複
幣別（Currency）必填，五選一選項：
美元（USD）
新台幣（TWD）
港幣（HKD）
新加坡幣（SGD）
日圓（JPY）
選的就是這位創作者的創作者幣別，定義見定價幣別
建立後創作者與 Admin 都不能改，送出前要讓 Admin 知道這一格不能再改
建立—建立成功後：
自動產生這位創作者的電子商店
創作者狀態為啟用中
創建時間自動記錄
  • 建立的成功、失敗與欄位錯誤，照全站共用的狀態規則顯示

依據：5.1.0 F2、F3、頁面狀態；主規格 §7.15；D097、D107、D218、D316、D326、D374。

創作者的狀態

創作者的營運狀態只有兩個，停用可以隨時復原。

啟用中⇄已停用
狀態什麼時候進入效果
啟用中（Active）新建立的創作者預設
已停用的創作者被重新啟用後		正常營運
Admin 可以進入工作區代為操作
已停用（Disabled）Admin 停用後電子商店對外停止存取
資料不刪除
名冊仍看得到，可以重新啟用
  • 停用與啟用在名冊和 Creator 詳情都能做，效果相同

依據：5.1.0 F3；5.1.0.5 F1；D097、D374。

代為操作創作者的工作區

Admin 從名冊進入一位創作者的工作區後，看到的畫面跟創作者本人一樣，另外多了只有 Admin 能做的操作。

  • 還沒選定創作者前，創作者工作區的模組不出現在導航；Admin 的其他頁（例如創作者活動管理、影片上架審核、平台費率設定）照常可用
  • 進入後，導航提供「返回 Creator 管理」，並標示目前正在操作哪一位創作者
  • 要換一位創作者，回到名冊再進入另一位
  • 代為操作只發生在選定的那一位創作者範圍內，不跨創作者混用資料
  • 每一筆操作都記錄執行身分：Admin 代為操作，或創作者本人
  • 代為操作時可以做只有 Admin 能做的操作，例如訂單詳情的撤銷品項；這類操作同樣記錄執行身分

依據：5.1.0 F4、情境 3、情境 4；主規格 §4.1；D086、D107、D128、D252。
