IP 授權規則

創作者照這頁的規則判斷一筆 IP 怎麼上架、怎麼定價、一筆授權走到哪個階段，以及版本與素材包怎麼留存。

IP 的來源與類型

創作者這一側只管當前這位創作者（Artist）範圍內的 IP；一筆 IP 可以有其他創作者的權利人，跨創作者的權利分配與分潤比例在 Admin 的 IP Bank 設定，創作者這一側只看得到唯讀摘要。IP 有兩種來源，見兩種來源；類型怎麼分，見IP 類型。

上架 IP 市場與接受租約

一筆 IP 能不能被別人找到、租用，由兩個各自獨立的開關決定：市場上架開關管「找不找得到」，接受新租約管「收不收新申請」；兩個開關合起來就是這筆 IP 的上架狀態。可租用的 IP 怎麼取得授權，見直接租用或競標。

市場上架開關

  • 預設關閉
  • 開啟：其他創作者可以在 IP 市場搜尋到這筆 IP，並送出租用申請
  • 關閉：不出現在 IP 市場搜尋、不能被租用，但照樣追蹤收益分配（waterfall，這筆 IP 產生的收益依權利人分配的紀錄）
  • 開關只決定能不能被搜尋與發起申請；一筆授權要生效，仍要走完授權的階段
  • 開關的家在管理 IP 的授權定價（List in IP Market）；我的 IP 清單的「Mktplace」欄是同一個開關，兩處變更互相反映
  • 登錄 IP 第 3 步選「上架出租（List for rental）」後開關是否立刻打開，以及 IP 詳情（從我的 IP 進入）的市場設定能不能切換，見頁尾尚待確認

接受新租約

  • 在管理 IP 的出租營運設定切換，見出租營運設定
  • 關閉時暫停接受新的租用申請，但不下架；既有租約不受影響

上架狀態

上架狀態市場上架開關接受新租約結果
未上架關—不出現在 IP 市場；管理 IP 不顯示「以承租方視角檢視」
暫停接單開關出現在 IP 市場，但不接受新的租用申請
已在 IP 市場上架開開可以被搜尋，也可以發起新的租用申請
  • IP 的驗證還沒完成（驗證中、站外登錄待驗證）時，管理 IP 頁首的橫幅寫明「完成驗證前不能上架、也不會產生收益」；上架與定價的操作是否真的擋下，見頁尾尚待確認
  • 登錄時上傳的所有權證明有助於驗證，驗證門檻與上架資格的關係見頁尾尚待確認

直接租用或競標

  • 擁有者在管理 IP 選下一個可承租檔期的計價模式：固定租金（Flat rental）或限時競標（Auction），見出租營運設定
  • 固定租金：承租方在 IP 詳情頁看到定價並送出租用申請，見 IP 詳情的租用
  • 限時競標：承租方在 IP 詳情頁出價，見 IP 詳情的競標
  • 擁有者切換後，承租方看到的是否就是同一個模式，見頁尾尚待確認

依據：5.1.4 F1、F6「Mktplace」、頁尾圖例；5.1.4.1 §4③；5.1.4.2 §2.1、§2.4、§2.6、§4 頁面狀態；5.1.3.1 §2.5；主規格 §7.7；D037、D150。

授權的定價

一筆 IP 的授權價格由一次性授權費加上分潤組成，另可加開獨家授權費；價格跟租期脫鉤，租期不是計價單位。三種價格各管什麼，見價格的組成；不公開金額時怎麼顯示，見請洽詢與尚未定價；各頁怎麼顯示同一句價格，見價格摘要。

  • 定價的家在管理 IP 的授權定價；登錄 IP 第 3 步可以先填第一次的價格
  • 幣別照創作者在收入管理的設定，見收入總覽
  • 一次性授權費是否已含平台抽成、與平台費率的關係，見頁尾尚待確認

請洽詢與尚未定價

  • 一次性授權費、分潤、獨家授權費都可以各自勾選「請洽詢（on request）」，改成不公開數字
  • 勾選請洽詢後，各頁顯示「請洽詢」，不顯示數字；承租方的主要動作改成向權利人洽詢，同樣建立一筆草稿授權，見送出租用申請
  • 一次性授權費與分潤都沒定價時顯示「尚未定價」，不顯示成 $0 或 0%，免得被讀成免費授權

授權的階段

一筆授權（License）從草稿開始，雙方核准且條款齊全才生效，生效後以到期、撤銷或爭議其中一種結束。每個階段下誰能做什麼，見各階段誰能做什麼；生效前條款要填齊哪些，見生效前條款要齊全；平台紀錄的效力，見平台紀錄與正式合約。

草稿→生效→到期／撤銷／爭議

授權的動作與效果

一筆授權從申請到結束有五種動作：送出租用申請、核准、議價與拒絕、撤銷、續約、修改已生效的條款。

送出租用申請

  • 承租方在 IP 詳情頁按送出，建立一筆草稿授權，進入擁有者的授權核准佇列
  • 價格是請洽詢時，送出就是向權利人洽詢，不是直接送出報價
  • 送出之後、雙方核准之前，不構成正式授權；需要審核或付款時，畫面不能讓承租方以為已完成授權
  • 送出前要不要二次確認、申請方能不能撤回、承租方在哪裡追蹤自己的申請，見頁尾尚待確認

核准、議價與拒絕

  • 擁有者在我的 IP 的授權核准佇列處理，可以核准（Approve）、議價（Counter）或拒絕（Decline）
  • 核准而且條款齊全，授權才轉生效
  • 每次核准、拒絕都寫進稽核軌跡

撤銷

  • 生效中的授權可以撤銷，撤銷時要附書面理由，理由寫進稽核軌跡
  • 誰可以發起撤銷，見頁尾尚待確認

續約

  • 續約是把舊條款複製成一筆新草稿，雙方重新核准
  • 原授權保留它的歷史狀態，不被新草稿覆蓋

修改已生效的條款

  • 授權生效後要改條款，一律開新版本，不在原授權上直接改
  • 已生效的授權沿用簽署時的版本
  • 擁有者在管理 IP 改定價時，畫面提示只套用於之後新成立的租約；這條是否有強制保證、是否開新費率版本，見頁尾尚待確認

依據：5.1.4 F8；5.1.4.2 §2.4；5.1.3.1 §2.5、§3.1、§3.4；主規格 §7.6、§7.7「授權生命週期」；D047、D169。

版本歷史與素材包

IP 本身與一筆授權用到的素材都會留下可回溯的紀錄：IP 的權利狀態見IP 的版本歷史，授權時交付的素材見素材包，收入怎麼對到版本見收入。

IP 的版本歷史

  • 每筆 IP 有一個不會變的識別碼（IP ID），版本只能往後加
  • 站外登錄的 IP 從 v1 開始，第一次編輯後成為 v2
  • 可以還原任一時間點的權利狀態
  • 版本歷史與稽核軌跡在 IP 詳情頁（從我的 IP 進入時）查看

素材包

素材包（Media Pack）是一筆 IP 提供給承租方使用的素材組合。

  • 每種 IP 類型有自己的素材欄位，並自動算出完整度
  • 上架或授權生效時，凍結當下的素材包版本，供日後爭議時對照
  • IP 市場的卡片顯示這筆 IP「目前」的完整度，不是某一筆授權凍結的值；兩者不混用

收入

  • 每筆收入綁定發生當時的 IP 版本；IP 之後改版，不改寫已發生收入的綁定
  • 授權費、競標付款與分潤的實際收入與明細都在收入管理，IP 相關頁面只引用、不重算，見收入總覽

依據：5.1.4 F5；5.1.3 F3「素材包完整度」；5.1.3.1 §2.5、§4.3；主規格 §7.3、§7.6、§7.7「IP 版本歷史」「素材包」；D047。
