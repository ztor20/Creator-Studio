平台忠誠點數設定

Admin（平台營運）在這頁設定全平台通用的忠誠點數參數：全站活動的給分與上限、賽季加倍週、衰減與等級保留。創作者可調的參數在粉絲分級。

1 設定範圍與權限2 全站活動給分與上限3 賽季加倍週4 衰減與等級保留5 生效時點與修改紀錄

1設定範圍與權限

這頁只管全平台通用的忠誠點數參數，作用於所有創作者的計分。

範圍與邊界

範圍與邊界讓 Admin 分清楚哪些參數在這頁調，哪些在別處。

  • 這頁設定五項參數：
    • 全站活動的給分與上限
    • 賽季加倍週
    • 衰減半衰期
    • 多久沒有行為就往下掉一階（天數）
    • 降級緩衝天數
  • 創作者可調的參數在粉絲分級，這頁不提供編輯，也不覆寫創作者的設定
  • 誠信規則由平台強制，任何人都不能關，這頁不提供開關，規則內容見粉絲分級的誠信規則
  • 這頁只設定「參數是多少、何時生效」，每位粉絲的忠誠點數與分級由每週重算產生，這頁不重算個別粉絲
  • 全站活動的點數 100% 計入粉絲當下的主要應援對象，這頁不設定分配規則；選擇與切換主要應援對象的操作在粉絲端
  • 購買類先把金額換成平台基準幣別（預設港幣）再乘基準費率，幣別與匯率規則不在這頁設定
  • 基準費率（Base rate）每 HK$1 = 40 分，是平台常數，這頁只顯示、不能改

權限

權限決定誰能進入這頁。

  • 只有 Admin 可以進入與編輯
  • 創作者工作區不含這頁
  • 沒有權限時，畫面顯示無權限狀態並說明原因

依據：5.1.0.8 頁面定位、F1、F5、頁面狀態；主規格 §4.1、§7.5、§7.15；D316、D347、D348。

2全站活動給分與上限

全站活動是 ztor 平台層級的行為，點數由平台發；Admin 在這裡設定每一種全站活動給多少點數、上限多少。

四項全站活動

下表是各項的預設值，資格條件照粉絲分級的全站活動與主要應援對象，這頁只設定給分與上限。

全站活動預設給分預設上限
每日簽到每天 50 分每天一次
連續簽到每連續第 7 天加 200 分90 天 12 次
全站發文互動每則 30 分
該則發文須有至少一則非本人的互動才給分		每天 3 則
邀請朋友加入 Ztor每位合格啟用 1,000 分90 天 10 位

上限與分配

  • 標 90 天的上限以滾動 90 天計，在給分當下判定，不追溯
  • 連續簽到中斷只是重新數，不扣分，也不顯示愧疚計數
  • 新朋友在 7 天內同時追蹤某位創作者時，兩份分數都給：追蹤的 400 分計入被追蹤的那位創作者
  • 創作者設定的各類行為份量不影響全站活動

依據：5.1.0.8 F2；主規格 §7.5；D347。

3賽季加倍週

賽季加倍週讓 Admin 指定哪些期間的計分加倍。

  • Admin 指定加倍的起訖時間，可以設定多段
  • 行為發生在任何一段期間內，就適用加倍
  • 期間內所有行為的分數一律 ×2，包含全站活動
  • 適用範圍是全平台所有創作者的計分

依據：5.1.0.8 F3；主規格 §7.5；D347。

4衰減與等級保留

這一區讓 Admin 設定點數隨時間淡出的速度、粉絲多久沒有行為就往下掉一階，以及掉級前的緩衝天數。

參數預設值說明
衰減半衰期45 天點數每過這段天數剩一半：第 45 天剩 50%、第 90 天剩 25%、第 180 天約剩 6%
降級緩衝14 天粉絲掉出原等級之前的緩衝期，緩衝期內仍保留原等級
多久沒有行為就往下掉一階（Inactive days before dropping a tier）90 天粉絲每連續這麼多天沒有任何行為，等級上限往下掉一階：第 90 天最多留在原等級的下一階，第 180 天再往下一階，第 270 天掉到一般粉絲
點數保留並照曲線繼續衰減，仍佔該級名額
  • 沉睡與衰減的完整規則見粉絲分級的衰減與沉睡

依據：5.1.0.8 F4；主規格 §7.5；D347、D348、D351。

5生效時點與修改紀錄

這一區讓 Admin 知道改了參數何時生效，並能追查歷次修改。

生效時點

  • 儲存後，參數在下一次每週重算生效，不即時
  • 已儲存、尚未重算的變更，畫面要看得出「已儲存，將於下一次每週重算生效」
  • 待生效期間，各創作者的忠誠點數與分級仍是上一次重算的結果

修改紀錄

  • 每次儲存留一筆修改紀錄
  • 每筆記錄時間、執行者、改了哪些參數，以及改前與改後的值

依據：5.1.0.8 F6、頁面狀態；主規格 §7.5；D347。
