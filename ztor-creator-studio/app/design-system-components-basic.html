4.2 Button

🟢 atom

Purpose

用途

Primary action control. Five emphasis levels — pick by how important the action is and how dense the surface is. One orange primary per block (card / dialog / toolbar); never use the orange primary for destructive actions.

主要動作控制項。五種強度——依「動作多重要」與「版面多密」挑。每一塊（卡片／彈窗／工具列）只留一個橘 primary;刪除類動作絕不用橘色 primary。

When to use which

什麼時候用哪個

“One block” = a self-contained area on screen (a card, a dialog / form, a toolbar, a list row) — not the whole page.

「一塊」＝畫面上各自獨立的一塊區域（一張卡片、一個彈窗／表單、工具列、列表的一列），不是整頁。

On which background (white vs grey)

配哪種底色（白底 vs 灰底）

A button is seen by the contrast of its fill/border against the surface — a fill the same colour as the background disappears. So pick by the surface layer it sits on (ramp: white --card → grey --muted/--surface-shell/--sidebar).

按鈕靠「填色／邊框跟背景的對比」被看見——填色和背景同色就會消失。所以要看它坐在哪一層 surface（階梯：白 --card → 灰 --muted/--surface-shell/--sidebar）。

In short: soft is white-surface only; on grey use outline. Outline has a real border, so it holds on both — the safest cross-layer secondary.

一句話：soft 只活在白底；要放灰底就改 outline。 outline 有實線框，白灰底都成立，是跨層最安全的次要。

Collapsing groups by milestone, one row per post (2026-08-20, D209) — general posts between two milestones collapse and expand together, regardless of date. Collapsed, the --day row states how many there are; expanded, that row stays as the control and each post becomes its own --post row: its own date gutter, its own --ghost dot. The axis promises one dot = one thing that happened, and three posts from three different days sharing a single dot read as one event. Consequence: expanding and collapsing must re-render — those rows are siblings, not a block tucked inside .ptl__fold, so toggling a class can neither hide nor create them.

收合的單位是「兩顆里程碑之間」，展開後一則一列（2026-08-20，D209）——里程碑與里程碑之間的一般貼文一起收合、一起展開，不限日期。收合時 --day 那一列說出這一段有幾則；展開時那一列留下來當控制項，每一則各自成為 --post：自己的日期欄、自己的一顆 --ghost 點。這條軸的承諾是「一顆點＝一件事」，三則發生在不同日子的貼文擠在同一顆點底下，會讀成「這裡發生了一件事」。連帶影響：展開與收合必須重繪，那幾列是兄弟節點、不是收在 .ptl__fold 裡的一塊，切 class 藏不掉也長不出來。

該做與別做

Do該做
  • Keep one orange primary per view as the clear CTA.
  • 每個畫面只保留一個橘色 primary 當明確的 CTA。
  • Use outline / ghost for secondary and inline actions.
  • 次要與行內動作用 outline／ghost。
Don't別做
  • Put more than one primary in a region, or use orange for destructive actions.

  • Use a transparent-fill outline on the white canvas — it reads as "nothing there."
  • 在白底上用透明填色的 outline — 看起來像「什麼都沒有」。
