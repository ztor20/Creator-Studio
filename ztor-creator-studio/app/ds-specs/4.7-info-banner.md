### 4.7 Info banner

**`_layer`** · atom — Neutral contextual information banner with a leading `info` icon. It explains a rule, timing, limitation, or next step without giving it warning priority.

**Anatomy**

The banner contains a Tabler `info` icon (`.info-banner__icon`) followed by the explanatory text. Use `<strong>` only for the clause people need to scan first.

**Variants** — Default single-line banner, plus a titled form (Q159, 2026-11-09): `.info-banner__text` wraps `.info-banner__title` (key line, `--foreground`, `--fw-medium`) and `.info-banner__desc` (13px description); an optional `.info-banner__action` (one `.btn--outline.btn--sm`, pushed right) needs the `.info-banner--action` modifier so the row wraps on narrow widths.

> **Q159（2026-11-09）**：說明規則的訊息一律用 info-banner；`.alert--row` 只給要處理或失敗的事。原本借 `.alert--row.alert--info` 的說明（活動與組合包「已上架只能改庫存」、活動「跟著系列設定」、活動通知「已上架不能改」、媒體庫檢視身分、已送出貼文的編輯說明）已改成本元件的標題＋說明形式。

**Sizes** — Desktop uses 10 × 12px padding with 14px text; mobile keeps the compact padding and contracts to 13px text.

**States**

| State | Selector | Change |
|---|---|---|
| default | — | neutral glass surface (`--ztu-glass-bg` + blur + 1px `--border` + top-edge rim), `--foreground-muted` text, `--radius-xl` corners and a 10px icon gap; the leading icon carries `--ztu-orange-hi` + a single soft glow so the "pay attention" cue lives in the icon, not the surface |

Static callout — no interactive states.

**Class API** (CSS classes — Props/API = N/A, this is a static CSS prototype)

| Class / modifier | Effect |
|---|---|
| `.info-banner` | Neutral glass information banner (flex, centered vertically) |
| `.info-banner__icon` | Leading Tabler `info` icon, 20px desktop / 18px mobile |
| `.info-banner__text` ＞ `__title` + `__desc` | Titled form (Q159): key line + description column |
| `.info-banner__action` + `.info-banner--action` | One outline button on the right; modifier allows wrapping |

**Token usage** (→ Pillar 2 Role)

- bg `--ztu-glass-bg` + `backdrop-filter: blur(var(--ztu-blur-glass))` · border `--border` · top rim `--shadow-edge-top` · text `--foreground-muted` · icon `--ztu-orange-hi` + `drop-shadow` glow from `--ztu-orange` · radius `--radius-xl` · type `--font-ui`

**Usage** — Use when context helps a person understand a rule, timing, limitation, or next step. Use `alert` for warnings, failures, or urgent action; use `.card__hint` for a short field-level hint.

**2026-08-28 換裝**（Wave 3 C-1 使用者裁決）：面從實色 `--accent` 改中性玻璃，跟卡片家族同語言（Q77）；「這是說明、要留意」不再靠實色橘底表達，改由 leading icon 的橘色與柔光承擔，量級比 filter-tabs 選中字光更收斂（單層、半徑更小）——banner 是被動說明，不是使用者選中的互動態。

**Do & Don't**

- ✅ Do keep it to 1–3 sentences and use `<strong>` for the key clause.
- ✅ Do use the same `info` icon for every instance so this role remains recognisable.
- ❌ Don't use it for urgent warnings or destructive consequences.
- ❌ Don't use it as a substitute for field-level help.


**Code example**

```html
<div class="info-banner">
  <i data-lucide="info" class="ztor-icon info-banner__icon"></i>
  <span><strong>Pending ≠ Available.</strong> Pending settlement holds funds for the T+7 dispute window.</span>
</div>
```
