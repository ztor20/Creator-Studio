### 4.234 Limit set（限購）

**Purpose** — 商品、組合包與活動門票共用同一種上限：每人總限購數量。一句輔助說明，句型一致、只換單位——商品「件」、組合包「組」、活動門票「張」（D398，2026-10-12；主規格 §7.2、§7.14「組合包的限購」、5.1.6.1 F22）。**D427（2026-10-16）**：原本的三種上限只留每人總限購，「每次交易限購數量」「限購次數」兩欄整組退場（含 `KEYS_BKY` 與 `keys` 選項；舊資料帶這兩項一律忽略）。**D456（2026-10-20）**：組合包的限購不繼承成員——預設不限、獨立計算（買組合包不扣成員商品或單張門票的額度），「跟隨成員預設」開關與「取自誰」事實句退場；原本預設跟隨成員（各成員上限 ÷ 每組用量取整後的最小值）、可覆寫、可改回，隨 D456 失效。2026-10-12 建立組合包改版（使用者裁示）：組合包變體由「徽章＋覆寫按鈕」改成「限購」標題，欄位排成一個細框裡的列，與 [Price ladder](./4.235-price-ladder.md) 同一種列。

**`_layer`** · molecule ｜ **source tier** · App ｜ **surface 層** · 白卡與灰底皆可；檢視態輸入框是 disabled（Q128）

**Anatomy**
- `.limit-set__fields` — 欄位容器（grid、`gap: --sp-16`，Q103；D427 起只有一欄）；商品直接放在限購開關的 `.control-group__body` 裡
- `.limit-set__field` — 一欄＝`.field`：`.field__label`（`pl.<unit>.<欄位>`）＋ `.input.limit-set__input`（`type=number`、`min=1`、寬度上限 `--w-220`、空＝placeholder「不限」）＋ `.field__hint`（`pl.<unit>.<欄位>.hint`）＋ `.field__error[data-pl-err]`
- `.limit-set.limit-set--bundle` — 組合包變體（整個區塊一個細框 `--border-soft`／`--radius-md`，標題列、說明、欄位列之間細線，同 price-ladder；2026-10-12 使用者裁示）
  - `.limit-set__head` — 不換行：左邊 `.limit-set__title`「限購」標題（選配，`blockHTML` 的 `title` 選項）。墓碑 2026-10-20（D456）：`.limit-set__follow`＋ `button.switch.limit-set__switch`（跟隨成員預設開關，`data-pl-act`）與 `data-state` 隨不繼承成員退場；墓碑 2026-10-16（D429）：bookyay 鎖定（`locked`）狀態與 `.limit-set__state` 徽章隨自動組合包退場
  - `.limit-set__sub` — 標題列下方一句額度說明（`--fs-13`、`--muted-foreground`、`--lh-relaxed`）：獨立計算，買組合包不扣成員商品或單張門票的限購額度（D456）
  - `.limit-set__fields` — 列外框：1px `--border-soft` 細框、`--radius-md`、`gap:0`；每列 `.limit-set__field` 為兩欄 grid（`1fr｜160px`），左＝`.field__label`（`--fs-14`）＋ `.field__hint`、右＝輸入框，列與列之間細線；檢視態輸入框 `disabled`（Q128）
  - 墓碑 2026-10-20（D456）：`.limit-set__src`（取自誰）隨不繼承成員退場

**Behavior** — `js/purchase-limits.js`（`window.ztorPurchaseLimits`）：`fieldsHTML()` 畫欄位（D427 起只有每人總限購）；`blockHTML(lim, T, { disabled, title })`（D429 起拿掉 `locked`／`lockNote`；D456 起拿掉 `der`）畫組合包區塊（`title:true` 畫「限購」標題）；`onInput()`、`errors(lim, T)`／`syncErrors(root, holder, T)`（填了但不是 1 以上整數 → 擋存；空白＝不限）。墓碑 2026-10-20（D456）：`derive(members)`（成員交集與門票天花板）、`followVals()`、`onClick()`（跟隨／覆寫）與「跟隨時任一成員不足 1 組」「覆寫超過門票上限」兩種擋存隨不繼承成員退場；`hintHTML(field, unit)` 給 `js/purchase-conds.js` 的「限購」條件卡借用。

**Token usage** — `--sp-2`／`--sp-8`／`--sp-10`／`--sp-12`／`--sp-14`／`--sp-16`、`--fs-13`／`--fs-14`、`--lh-relaxed`、`--foreground`／`--foreground-muted`／`--muted-foreground`、`--border-soft`、`--radius-md`、`--w-220`；其餘外觀來自 `.field`、`.input`、`.badge`。

**Consumers** — `create-product.html`、`product-detail.html`（商品限購欄）；`create-bundle.html`、`bundle-detail.html`（組合包區塊，含標題）；`create-event.html`、`event-detail.html`（經 `purchase-conds.js` 只用輔助說明）。

**2026-10-21**：組合包的三個消費點改用 `blockHTML(…, { group:true })`，畫成 Rules group（§4.240）裡的一列（`.rules-group__row[data-pl-block]`：左＝`pl.set.person`＋兩句說明、右＝輸入框），不再自帶標題與外框；`title`／預設變體保留給舊用法與 DS demo。新增 `sumText()`／`syncSum()` 寫群組底部彙總句。
