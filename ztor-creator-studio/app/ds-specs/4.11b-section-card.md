### 4.11b Section card

**`_layer`** · molecule — The product-page section wrapper: a titled outline with an optional head-row action link, used for every card-shaped section across the app (dashboard tiles, earnings panels, detail-page blocks). Boundary vs. **4.11 Card**: `.card` = section wrapper (this entry), `.ztor-card` = generic standalone content card (docs-only reference, unused on product pages).

**Anatomy**

```
.card  (or .card--muted)
 ├ .card__head
 │   ├ .card__title
 │   ├ .card__hint        (non-actionable)
 │   └ .card__link →      (chevron after, in head)
 ├ ...section body...
 ├ .card__note            (footnote)
 └ .card__foot            (action area, pinned to the card's bottom edge)
```

**Variants** — `.card--muted` (muted section wrapper, for nested sub-sections).

**Sizes** — Single size (padding `20px`).

**States**

| State | Selector | Change |
|---|---|---|
| default | — | **ztorUI 換裝（2026-08-28 Wave 2a）**：`--ztu-glass-bg` 半透明玻璃底（原 `--card` 實色）＋ `backdrop-filter: blur(var(--ztu-blur-glass))` ＋ **邊框回歸**`border: 1px solid var(--border)`（原 2026-07-26 Q23 決 C 去邊框、純陰影浮起；玻璃需要 1px 邊把厚度畫出來）＋ `--shadow-card` + `--shadow-edge-top`（token 值本身已在 Wave 1 對齊沙盒深投影）, `--radius-xl` |
| link hover | `.card__head .card__link:hover` | Link color → `--foreground` (chevron tracks via currentColor) |
| `.card--muted`（卡中卡） | `.card--muted` | **ztorUI 換裝**：`--ztu-film` 薄膜底（原 `--nest-surface` 4%）, `backdrop-filter: none`, `border: 1px solid var(--nest-line)`, `border-radius: var(--radius-lg)`, `box-shadow: none`——巢狀層刻意不上模糊、不疊陰影，避免讀成「浮在卡上的第二張卡」 |
| 浮層內的 `.card`（如 `.payout-dialog .card`） | `:is(.payout-dialog, .payout-modal, .dropdown__menu, .zselect__panel, .preview-panel__sheet, .detail-sheet, .overlay-surface) .card`＋`html[data-embed] .card` | **ztorUI 換裝**：退回 `--ztu-film` 薄膜＋關模糊＋`border: 1px solid var(--nest-line)`＋無陰影——浮層本身已是實色（見 §3.2），裡面再放一張會透的玻璃卡就是看穿兩層玻璃；祖先清單本波從原本只有 `.payout-dialog` 擴編成本站所有實色浮層容器。**2026-08-31 補 `html[data-embed]`**：detail-sheet 用 iframe 開詳情頁，祖先選擇器過不了 iframe 邊界，浮層裡那一頁的卡片永遠選不到這條規則，就帶著給實色檯面用的重投影坐在玻璃上（使用者「陰影太重了」）。同輪一併補進 `kpi.css`／`alert.css`／`preview-card.css` 的對應規則 |

**Class API** (CSS classes — Props/API = N/A, static CSS prototype)

| Class / modifier | Effect |
|---|---|
| `.card` | Product section wrapper, 20px pad |
| `.card--muted` | Muted section bg (nested sub-sections) |
| `.card__head` | Baseline-aligned space-between head row, 14px bottom margin |
| `.card__head--wrap` | 卡頭放「一句說明 `<p>`＋右側按鈕群或篩選列」時用（2026-11-02，平台忠誠點數設定 promote）：`flex-wrap: wrap`、改垂直置中；說明句 `flex: 1 1 var(--w-300)`，窄螢幕時按鈕群換到下一行，不撐破卡寬。消費頁：`admin-platform-loyalty.html` |
| `.card__title` | 15px / 500 section title |
| `.card__hint` | 12px subtle non-actionable hint |
| `.card__note` | 12px subtle footnote below the card body — the sentence that states the figures' basis, denominator or limitation (2026-08-06 promoted from fan-analytics' page-local `.aud-note`). Boundary vs `.card__hint`: hint is one short inline phrase in the head; note is a paragraph after the body, so it carries `--sp-12` top margin and `--lh-normal` |
| `.card__foot` | 卡底動作區（2026-08-18 promote）——`margin-top:auto` ＋ 16px 上內距，把動作釘在卡的下緣。`.card` 本身是 flex column，多出來的高度全留給內容。用它的理由：同一排的卡內容長短不一，動作若貼著內容走，兩張卡的按鈕會一高一低；釘底之後對齊成同一條線。要排兩顆以上時在裡面再包 `.stack` 或 `.flex-row`，本區只管落點。消費頁：project-detail 總覽的進度摘要／方案摘要 |
| `.card__link` | 12px action link — underline by default; in `.card__head` becomes underline-less with trailing chevron icon |

**Token usage** (→ Pillar 2 Role)

- bg `--ztu-glass-bg`（2026-08-28 換裝，原 `--card`）／`.card--muted` 用 `--ztu-film` · backdrop-filter `--ztu-blur-glass` · `--foreground`, `--foreground-muted`, `--muted-foreground` (title / hint) · `--border`（**2026-08-28 起重新是卡緣**，玻璃需要 1px 邊；換裝前 2026-07-26 Q23 曾去邊只留陰影，現已回歸） · `--shadow-card`, `--shadow-edge-top` (edge) · `--radius-xl` · `--font-ui`, `--font-body`（Poppins）

**Usage** — Use for every product-page section that needs a titled wrapper with an optional action link. Avoid when content is a flat row list — reach for Data list / Table instead.

**Do & Don't**

- ✅ Do put the section action in `.card__head .card__link` so it auto-renders the trailing chevron.
- ✅ Do use `.card--muted` for nested sub-sections to differentiate depth.
- ✅ Do rely on the玻璃四件套（`--ztu-glass-bg` ＋ blur ＋ 1px `--border` ＋ `--shadow-card`/`--shadow-edge-top`）for the section edge（2026-08-28 換裝現況；`.funding-panel--card`／`.fc-bundle` 等 `.card` 系變體同步）。歷史：2026-07-13 Q3 純邊框無陰影 → 2026-07-26 Q23 決 C 去邊框改純陰影浮起 → 2026-08-28 換裝邊框回歸、與陰影並存。
- ❌ Don't use this for a standalone info block outside a page section — use `.ztor-card` instead.


**Code example**

```html
<section class="card">
  <div class="card__head">
    <h3 class="card__title">Recent earnings</h3>
    <a class="card__link" href="earnings.html">View all</a>
  </div>
  <!-- section body: data-list, kpi row, etc. -->
  <p class="card__note">Counted in people, not plays.</p>
</section>
```
