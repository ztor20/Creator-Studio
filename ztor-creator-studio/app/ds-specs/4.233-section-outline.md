### 4.233 Section outline（長表單的本頁大綱）

**Purpose** — 建立商品「內容」頁一路排下來有十幾張卡，使用者最常需要的是「我現在在哪、還有哪些必填沒填」。使用者 2026-10-12 指示在頁面左側（左側欄與表單卡片之間的空白欄）加每個 section 的導覽，看完 `lab-section-nav.html` 六種擺法後選定 C（狀態清單）。本支是把 C 做成正式元件：導覽兼就緒檢查，一眼看出哪些必填還沒填。

**`_layer`** · molecule ｜ **source tier** · App ｜ **surface 層** · 無底色、無卡面，直接坐在頁面底（`--surface-page`）上；不是玻璃卡。

**2026-10-12 改版（使用者在 `docs/section-outline-redesign-demo-2026-10-12.html` 選 D）** — 長相改用站上的側欄分節導覽（Section nav）：一節一列、列與列 1px `--border-soft` 分隔線（分類最後一列與整份最後一列不畫），目前節只換 `--selected-ink`＋`--fw-medium`（不再有左側亮線）；群組標照清單群組標（`--fs-12`、字距 .05em、`--column-head-ink`）；狀態改成列尾的進度記號（`.section-outline__mk` 同時掛 `.pmark`，16px：todo＝空心圈＋淡勾、done＝`.pmark--done`、opt＝不畫）。`__head` 與 `__sum` 不再顯示（元素仍由 JS 產生）。以下 Anatomy 中左側細線、亮線、12px 狀態圓、摘要列的描述為改版前，保留作沿革。同日補：**整組置中**——視窗 ≥1400px 且大綱掛在左側空白欄時，`.wizard__body` 以 `position: relative; left` 往右推「大綱寬＋`--sp-16`＋`--sp-12`」的一半，讓「大綱＋表單＋預覽」整組左右留白相等（不用 transform，避免內層 fixed 彈窗換基準）；內容欄最大寬度同時改讀 `--section-outline-body`（頁面改掛在 `.wizard__body`：建立商品 1040、建立組合包／拍賣 1000）。

**Anatomy**
- `nav.section-outline` — 根；`aria-label`＝標題「本頁大綱」（JS 填）；`[hidden]`＝目前沒有可見的節時整個收起
- `.section-outline__inner` — sticky 內層，`top` 讀 `--section-outline-top`（預設 96px，與 `.preview-col` 同一條線）；高度超過視窗時自己可捲（隱藏捲軸）
- `.section-outline__head` — 標題「本頁大綱」
- `.section-outline__sum` ＞ `__count`（「必填 `<b>N</b>`／M」）＋ `__bar`（3px 進度條，寬度讀 `--section-outline-progress`）— 沒有任何必填節時整列 `[hidden]`
- `.section-outline__list` — 左側一條 1px `--border-soft` 細線
- `.section-outline__group` — 選配群組標題列（2026-10-12）：兩節相鄰且群組不同時插在中間的一行小字（`--fs-11`、`--foreground-muted`、字距 .04em）；不是按鈕、不進必填 N／M、群組內的節全被藏起來時跟著消失；`:not(:first-child)` 上方留一段間距。
- `.section-outline__item(.is-active)` — `<button>`，一節一列；目前節 `--foreground`＋`--fw-medium`＋左側 2px `--primary` 亮線，並帶 `aria-current="location"`
- `.section-outline__mk[data-st="todo|done|opt"]` — 12px 狀態圓：todo＝1.5px `--primary` 空心圈；done＝`--status-success` 實心＋白勾（`.ztor-icon`）；opt＝5px `--faint-ink` 灰點
- `.section-outline__text` — 節名，最多兩行（`line-clamp: 2`），完整名稱在 `title`；另有 `.u-visually-hidden` 的狀態文字給讀屏
- `.section-outline--gutter` — 修飾：放進頁面左側空白欄，相對 `.section-outline-host` 絕對定位（`top:0; bottom:0; right: calc(100% + --sp-16)`），不佔 grid、不推擠表單；寬度＝(視窗 − `--section-outline-body`（預設 1140）) / 2 − 12px，夾在 120–184px；視窗 <1400px 時 `display: none`
- `.section-outline-host` — 掛 `--gutter` 的那一欄，只負責 `position: relative`（建立商品＝`.preview-split__form`）

**Behaviour（`partials/section-outline.js`）** — `window.ztorSectionOutline.mount({ host, sections, status, labels, title?, group?, offset?, observe?, gutter? })`。輸入＝節容器清單（`sections()`）＋必填判斷函式（`status(els)` 回同長度的 `'todo'|'done'|'opt'`）＋文案（`labels()`）；輸出＝導覽。`group`（選配）：`el => '群組標題'`，預設讀節的 `data-outline-group`、回空字串＝不分組；群組標題改變時視為清單簽章變動、會重畫（換語言標題跟著更新）；同一群組的節在 DOM 裡必須相鄰，否則標題會重複出現。元件自己濾掉不可見的節（`hidden` 或 `getClientRects` 為空）、節標題讀 `.form-section__title` 現況文字；節增減靠 MutationObserver 監看 `hidden`／`class`（只對節本身與其祖先的變動反應，自己的 class 變動不算），另聽 `input`／`change`／`click`／`upload:change`／`i18n:applied`／`ztor:lang-changed`，全部節流 80ms，不輪詢。scroll-spy：capture 階段聽任一捲動容器，目前節＝最後一個頂端越過「頁首高度＋16」的節，捲到底固定亮最後一節。點擊用 `scrollIntoView`＋`scroll-margin-top`；`prefers-reduced-motion` 時不平滑。回傳 `{ refresh(), destroy() }`。

**States** — 每節三態（todo／done／opt）、目前節亮起、hover 文字轉 `--foreground`、`:focus-visible` 內縮 2px `--ring` 框線；摘要「必填 N／M」的 M＝目前顯示的節裡有必填欄位的節數、N＝其中已完成者；沒有可見節時整個元件收起。

**Token usage** — `--sp-4`／`--sp-6`／`--sp-8`／`--sp-12`／`--sp-16`／`--sp-24`、`--fs-11`／`--fs-12`、`--fw-medium`、`--lh-snug`、`--duration`、`--primary`、`--status-success`、`--background`、`--foreground`／`--foreground-muted`／`--muted-foreground`、`--faint-ink`、`--border-soft`、`--ring`。覆寫 hook（自訂屬性，頁面可設）：`--section-outline-top`、`--section-outline-body`；`--section-outline-progress` 由 JS 寫。

**Dependencies** — Progress mark（`progress-mark.css`，2026-10-12 起列尾記號；消費頁要連入）、Icon（`.ztor-icon` 打勾）、`.u-visually-hidden`（shared.css）、Form section（節標題 `.form-section__title` 是預設的標題來源）。

**Consumers** — `create-product.html`（內容頁；內容欄 1140）、`create-bundle.html`（八張分卡，以 `data-outline-group` 分成「組合包介紹／選擇組合物／販售設定」三個群組（分類只出現在大綱群組標題，分卡上方的 `.form-cat` 分類小標已於 2026-10-12 撤除）；內容欄 `.wizard__body--narrow` 1000、頁面設 `--section-outline-body: 1000px`；必填讀發布前檢核 `stageChecks()`）、`create-auction.html`（左欄各節；同 1000；必填讀就緒檢查 `buildChecks()`，節標題缺的第一節用 `title` 選項補）。「必填」判斷沿用該頁既有的就緒檢查 `buildChecks()`：每個就緒項用 `cpSectionOf(step)` 對到所在節，節內有就緒項＝必填節、項目全過＝已完成、沒有就緒項＝選填，不另訂規則（缺口與降級記在 `ASSUMPTIONS.md`、`BUILD-SPEC.md`）。可延伸頁：`product-detail.html` 編輯態（尚未接）。

**CSS** — [`section-outline.css`](../ds-components/section-outline.css)
