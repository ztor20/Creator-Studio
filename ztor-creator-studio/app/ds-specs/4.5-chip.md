### 4.5 Chip

**`_layer`** · atom — Clickable filter pill with an active (inverted) state and optional count; distinct from Badge (display-only).

**States（2026-09-21 補）** — `.chip--active` 已選、`.chip--static` 唯讀、`.chip:disabled`／`[aria-disabled="true"]` 選不到（淡化＋劃線＋`not-allowed`，hover 不變色；首用組合包預覽卡 §4.213）。

**Surface role token（2026-10-15，STYLE-DECISIONS Q76 裁決 B）** — 未選 `.chip`（含 `--static` hover、`:disabled` hover、`--value`）的底改吃 role token `--chip-surface`：暗色＝`var(--ztu-film)`（外觀不變）、淺色＝`color-mix(in srgb, var(--foreground) 6%, var(--card))`（比卡深一階，不再與 `--card` 同色融成一片）。淺色模式目前關閉（Q135），值先定義好備用。

**Anatomy**

```
.chip-group ─────────────────────────────
┌──────────────┐ ┌──────────────┐
│ All  | 214   │ │ E-Shop | 96  │
└──────────────┘ └──────────────┘
 .chip--active     .chip
        └ .chip__count (│ + faded number)
```

**Variants** — Base `.chip`, `.chip--active` (selected), `.chip--static` (read-only, no hover), `.chip--value` (quiet fill for a creator-entered value, 2026-07-21), `.chip--add` (dashed border, Q71 2026-08-25). Container `.chip-group`; row wrapper `.filter-row` + `.filter-row__actions`.

**Sizes** — Single size (6 × 12px padding, 12px / 500).

**Q71 borderless pass (2026-08-25)** — the whole family lost its 1px `--border`: unselected fill is now `--input-surface` (same interactive-fill answer as every other control, Q19), hover is `--accent`. The family reads as a row of "tags" rather than a row of buttons. `.chip--add` is the deliberate exception that keeps a border (dashed) — see States. **ztorUI 換裝（2026-08-28 Wave 2b）疊在 Q71 之上、未推翻它**：無框化的結論不變，只是底色與已選態的材質換了一批新值，見下方 States。

**States**

| hover | `:hover` | **ztorUI 換裝**：bg `--ztu-glass-strong`（12% 白玻璃，原 `--accent` 實色）, text `--foreground` |

**Token usage** (→ Pillar 2 Role)

- bg `--ztu-film`（預設／`--static`／`--value`，2026-08-28 換裝，原 `--input-surface`） · hover bg `--ztu-glass-strong`（原 `--accent`） · active bg `--ztu-glass-strong` ＋ `backdrop-filter: var(--ztu-blur-glass)` ＋ `inset 0 1px 0 var(--ztu-rim-soft)`, text `--ztu-orange-hi`（2026-08-28 換裝，原 `--selected-surface`／`--selected-ink` 橘 tint） · text `--foreground-muted` → `--foreground` · count `--muted-foreground` · border `--border`（僅 `--add`，虛線，Q71——其餘變體皆無框） · radius `--radius-pill` · motion `--duration` / `--easing` · font `--font-ui`（Poppins）

**Usage** — Use for filterable taxonomies (Earnings transaction filters, Tax-docs year filter). Avoid for read-only status — use Badge (§4.3).

**Do & Don't**

- ✅ Do keep exactly one `.chip--active` per group at a time.
- ✅ Do use `.chip--static` when a chip is informational, not a filter.
- ✅ Do use `.chip--value` for values the creator just typed in; keep them quieter than the surrounding controls.
- ❌ Don't use a chip to display non-filterable status.
- ❌ Don't use `.chip--active` (orange tint) for a creator-entered value — the orange selected state is reserved for a chosen filter.
- ❌ Don't put more than one active chip in a single-select group.
- ❌ Don't render an action (Export / Print / Download) as a chip — those are Buttons (§4.2). In a `.filter-row`, chips filter and the right-aligned action (e.g. Export CSV `.btn--outline`) is a Button.


**Code example**

```html
<div class="filter-row">
  <div class="chip-group" role="group">
    <button class="chip chip--active">All <span class="chip__count">214</span></button>
    <button class="chip">E-Shop <span class="chip__count">96</span></button>
  </div>
  <div class="filter-row__actions">
    <button class="btn btn--outline btn--sm">Export CSV</button>
  </div>
</div>
```
