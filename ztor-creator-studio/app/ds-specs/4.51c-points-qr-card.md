### 4.51c Points QR card

**`_layer`** · molecule — A centred card for scan-to-collect loyalty points: one scannable QR, the QR name, "+N pts per scan", an optional claimed / total usage bar and a "Download QR" button. The creator prints or posts the QR on site; fans scan it to collect points. Used by the scan-to-collect session detail page (`pickup-detail.html`, QR popup) only — since D503 (2026-11-02) point QR codes live inside scan-to-collect sessions, and the loyalty-points product pages that also used this card were removed.

**Anatomy**

```
.points-qr[--compact][--full]      column, centred, no surface of its own
 ├ .points-qr__code                QR frame (--card fill, --border, --radius-md; same as .qr-box) ＞ svg from window.ztorFauxQr(seed)
 ├ .points-qr__name                QR name (--fs-14, medium)
 ├ .points-qr__points              "+N pts per scan" (--fs-13, --primary)
 ├ .points-qr__usage               optional (claimed + total given)
 │   ├ .points-qr__usage-text      "{a} of {b} claimed" / "Fully claimed"
 │   └ .stock-bar ＞ .stock-bar__fill   usage bar (stock-bar.css)
 └ .points-qr__download            .btn.btn--outline.btn--sm, hook data-pqr-download
```

**Variants** — `--compact` (QR frame `--sp-96`, for rails); `--full` (claimed ≥ total: QR dimmed to .55, usage text and fill turn `--destructive`; added by JS, not by the consumer).

**Sizes** — Default QR frame 168px (`--points-qr-size`, built from `--sp-*`); compact 96px.

**States**

| State | Selector | Change |
|---|---|---|
| default | `.points-qr` | QR + name + points + download |
| with usage | `.points-qr__usage` present | claimed / total text plus stock bar |
| fully claimed | `.points-qr--full` | QR dimmed, usage turns `--destructive`; download stays enabled |
| download | `.points-qr__download` | button hover/focus from `button.css`; click saves `<QR name>.png` (falls back to `.svg` if canvas fails) |

**Tokens** — `--card`, `--border`, `--radius-md`, `--foreground`, `--primary`, `--destructive`, `--muted-foreground`, `--fs-12/13/14`, `--fw-medium`, `--lh-snug`, `--sp-4/6/8/24/96`. No raw hex / rgb / font-size.

**JS API** (`js/points-qr.js`, needs `js/faux-qr.js`; text from i18n `pqr.*` with a built-in fallback for pages without i18n.js)

```
ztorPointsQr.render(opts)      → HTML string
ztorPointsQr.mount(el, opts)   draws the card into el; re-renders on i18n:applied and on <html data-lang> change
ztorPointsQr.download(el)      saves the QR inside el as PNG (black on white, 512px); filename = QR name
opts = { name, points, seed?, claimed?, total?, compact? }   // usage bar shows only when claimed and total are both given
```

i18n keys: `pqr.download` · `pqr.perScan` ({n}) · `pqr.claimed` ({a}, {b}) · `pqr.full`. `js/faux-qr.js` defines `window.ztorFauxQr` once (does not overwrite an existing definition).

**Consumers** — product-detail.html (loyalty-points product detail), pickup-detail.html (scan-to-earn session QR cards), create-product.html (step 3 preview).
