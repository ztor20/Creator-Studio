### 4.219 Fan bundle page（粉絲視角組合包頁，前台 shop-item 兩個組合分支鏡像）

**Purpose** — 建立組合「下一步：預覽」後全頁「預覽與發布」（§4.216 Publish stage）用於組合包的預覽檢視（D321，2026-09-23，比照 D317 建立商品改兩步驟）：Fan event page（§4.215）／Fan product page（§4.218）的組合版，同一套「前台 1:1 鏡像」做法——內容等同粉絲端組合包頁會呈現的全部設定，依成員組成分兩種視圖：純商品套組（`kind:'goods'`，前台 `renderBundle`）與含活動票券組合（`kind:'eventset'`，前台 `renderEventSet`，多一段「座位區域」與活動資訊框）。`js/fan-bundle-page.js` 讀前台原始碼（`assets/shop-detail-render.js` 的 `renderBundle()`／`bundleBuyHtml()`／`bundlePickerHtml()`／`bundleContentsHtml()`／`renderEventSet()`／`setCrumbsHtml()`／`setBuyHtml()`／`setTiersHtml()`／`setContentsHtml()`／`setPerksHtml()`）輸出對應的 DOM 結構與 class 名；CSS 是 `ds-components/fan-shop.css` 第 5 段「組合包頁元件」，延續第 1–4 段（Fan event page／Fan product page）已建好的 `.fep-shop` 前台 token，不新增裸值例外。只有資料換成我們的——名稱、素材、成員（票券成員的允許票種 × 每組張數、商品成員的規格）、售價、原價合計、組合折扣、可售套數、組合專屬權益全部來自建立組合表單；購買類互動一律不動作；元件支援相關推薦四張佔位卡（前台 markup），但 2026-09-23 起 `create-bundle.html` 不傳 `related`、該段不畫（B 反饋「你可能也喜歡都移除」，與 Fan event page／Fan product page 同輪裁決）。

**`_layer`** · organism ｜ **source tier** · SiteSpecific ｜ **surface 層** · 與 Fan event page／Fan product page 同一份 `.fep-shop` 前台近黑底。

**⚠ Token 紀律例外（同 §4.215／§4.218 的既有註記）** — `fan-shop.css` 是前台鏡像、不是本 design system 的元件；第 5 段沿用第 1–4 段已註記的例外（裸 `rgb()`／px 字級，不與 `_tokens.css` 混用），不得在 Creator Studio 其他頁引用（唯一消費者是 `js/fan-bundle-page.js`）。裸色數量已併入 `fan-shop.css` 既有的 `ds-baseline.json` 登記，未新增例外項目。

**Anatomy（＝前台 shop-item 兩個組合分支的 `<main>`）** — `.fep-shop[data-fbp-view=bundle|eventset]` &gt; `main` &gt; `.section.section-bg-page.section--flush-top` &gt; `.pdp[data-type=bundle|eventset]` &gt; `.pdp-topbar`（手機頂欄，不可點）＋ `.pdp__page` &gt; `.container` &gt; `.page-head__crumbs`（純商品套組＝商店 › 名稱；含票券組合＝活動 › 活動型態 › 活動名 › 組合名）＋ `.pdp__grid` &gt; `.pdp-gallery[data-fbp-gallery]`（組合自己的素材，結構同商品頁縮圖條＋主圖）＋ `.pdp-buy` &gt; `.pdp-buy__meta`（狀態／類型徽章）＋ `h1.pdp-buy__title`（可翻譯）＋ 店家列（`goods`，`.pdp-host--shop`）或活動 kicker＋主辦列（`eventset`，`.pdp-set__host`）＋（`eventset` 才有）`.pdp-event-meta[data-fbp-meta]`（內容／日期／時間／場館／專屬權益逐列）＋ `.pdp-price[data-fbp-price]`（`__now`／`__was`／`__save`，價格節點帶 `data-fbp-price-key`）＋ `.pdp-stock[data-fbp-stock]`（限量且剩 ≤10 組才有，「僅剩 N 組」）＋（`goods` 才有）`.pdp-bundle-picker[data-bundle-picker][data-fbp-picker]`（多選項商品成員的規格 chip，不預選）＋ `.pdp-buy__actions`（`eventset`＝「購買組合」單鈕；`goods`＝有選項＝「選擇你的組合」、無選項＝「加入套組」，皆帶數量步進器與收藏鈕；售完＝已售完並停用）；（`eventset` 才有）`section.pdp-bundle--tiers[data-fbp-tiers]`「座位區域 · 任選一種」（票券成員允許票種 >1 才畫，每列＝該票種的組合價＋購買鈕）；`section.pdp-bundle[data-fbp-members]`「套組內容 · 共 N 件」&gt; `.pdp-bundle__grid` &gt; `.pdp-bundle-item` ×N（一個成員一張卡：媒體格＋名稱＋規格說明＋查看單品／查看活動連結）；`section.pdp-perks[data-fbp-perks]`「組合專屬權益 · 共 N 項」&gt; `ul.pdp-perks__list` &gt; `li.pdp-perks__item`（星形圖示＋可翻譯文字）；`section.pdp-details[data-fbp-desc]`「組合介紹」&gt; `p.pdp-details__lead`（組合自己的說明，可翻譯；`model.desc` 留空整段不畫）；`section.pdp-recs` 相關推薦 &gt; `a.pdp-rec-card` ×4（`related` 有值才畫，全部標「非本商品／非本活動」）；`.shop-buybar`（手機底部購買列）。兩種 `kind` 的區塊順序不同：`goods` 是套組內容→權益→詳情；`eventset` 是說明→座位區域→套組內容→權益（前台 `renderBundle`／`renderEventSet` 的原始順序）。

**Behavior** — 宿主（`create-bundle.html`）把表單資料整理成 `model`（結構見 `js/fan-bundle-page.js` 檔頭：`kind`／`gallery`／`name`／`desc`／`shop`／`event`／`members`／`price`／`stock`／`perks`）交給本檔渲染，本檔只知道「粉絲組合包頁長什麼樣」、不知道資料來源。可翻譯欄位（`name`／`desc`／逐項 `perks`）由宿主給 `{ key }`，本檔以 `api.getValue(key)` 取當前語系值並掛 `api.bindEditable`。`members` 每筆 `{ kind:'ticket', qty, tiers }` 或 `{ kind:'product', name, qty, priceObj, options }`；票券成員允許票種 >1 時視為「粉絲任選一種」（購買欄與套組內容卡都標「任選」）。價格：`price.priceObj`／`price.priceKey` 是組合售價（最低組合），`price.wasObj` 是原價合計（單買加總，只換算不可覆寫），`price.from` 為真時加「起」；座位區域每列的價格＝組合售價＋該票種與最低票種的價差 × 每組張數 × (1 − 組合折扣 %)，差額依匯率換算（同表單「粉絲看到的」卡的算法）。庫存 `stock` 為 `null` 或空即不限量不顯示，≤10 組才顯示「僅剩 N 組」，0＝售完（CTA 停用）。價格只看不改（D514）。`related` 為真值時畫相關推薦固定四張佔位卡；`create-bundle.html` 目前不傳（未定義／`false`）時整段不畫。

**Token usage** — 與 Fan event page／Fan product page 同一批前台 token（定義在 `fan-shop.css` 最前面的 `.fep-shop { … }`），第 5 段新增的類別沿用同一批、無新 token。

**Consumers** — `create-bundle.html`（「下一步：預覽」驗證通過後的全頁「預覽與發布」，`previewRender` 呼叫 `buildFanBundleModel()`）；`design-system.html` §4.219 就地渲染 demo（替身 api，`kind:'goods'`／`kind:'eventset'` 各一份）。

**CSS** — [`fan-shop.css`](../ds-components/fan-shop.css)（第 5 段）｜ **JS** — `js/fan-bundle-page.js`
