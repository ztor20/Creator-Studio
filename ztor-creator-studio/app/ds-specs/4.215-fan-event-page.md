### 4.215 Fan event page（粉絲視角活動頁，前台 shop-item 鏡像）

**Purpose** — 發布前預覽確認（主規格 §7.4）用於活動的預覽檢視，D305（2026-09-22）把它從一張活動卡改成「粉絲視角完整頁」：內容等同粉絲端活動頁會呈現的全部設定，活動有票券頁與票務商品頁兩個視圖（沒有組合包時只有票券頁）。**2026-09-22 使用者裁決：「預覽 UI 必須做得和這兩個一模一樣，只是資料和機制套用我們的流程與功能」**（票券頁 `https://ztor.vercel.app/shop-item.html?id=ev-score-live`、票務商品頁 `…?id=ev-themesong-night&sets=1#bundles`）。所以本元件自同日起不再是用站上 token 重刻的結構鏡像，而是**前台的真實 markup 與 CSS**：`js/fan-event-page.js` 輸出前台兩頁 `<main>` 的 DOM 結構與 class 名（證據 `docs/fe-mirror-2026-09-22/ticket.main.html`／`bundles.main.html`），`ds-components/fan-shop.css` 是那兩頁實際命中的全部 CSS 規則（Playwright 抽出，加 `.fep-shop` 前綴、`:root`／`html`／`body` 改 `.fep-shop`、@font-face 移除改用站上自架字型）。只有資料換成我們的：名稱、亮點、描述、卡司、須知、取票方式、票種、組合包（允許票種 × 張數、商品、權益、售價／原價）全部來自建立活動流程或 events-store。兩個宿主——`create-event.html` 發布前、`event-detail.html` 的「預覽與在地化」——共用同一支渲染函式。

**與前台的差別（刻意）** — 前台專有互動拿掉：`pdp-topbar` 保留 markup 但不可點、「情境展示」浮鈕與 `pdp-sheet` 抽屜不畫、購買類按鈕（購票／購買／購買組合／收藏／購物車）`data-pp-inert` 不動作；相關活動三張卡標「非本活動」（`relatedFromStore()` 從 events-store 撈別的活動，宿主呼叫）；亮點（D300）前台沒有位置，放名稱下方一行 `.pdp-buy__highlight`；退換票表單沒有此欄，前台那句當平台固定文案（`fep.refund.fixed`）；描述是一個可翻譯欄位，整段放前台的 lead 段（一個 contenteditable 拆不成 lead＋para）；金額補成前台的「NT$ 1,200」（符號後空格）。細節見 ASSUMPTIONS UIA-167。

**`_layer`** · organism ｜ **source tier** · Project（前台鏡像） ｜ **surface 層** · 自帶前台的近黑檯面 `--bg-primary`（#0a0a0a），坐在 `.payout-dialog__body` 上；殼用 `shell:'fan'` 放寬到 1376px（`.pp-dialog--fan`，見 §4.130）。

**⚠ Token 紀律例外（已註記）** — `fan-shop.css` 是前台鏡像、不是本 design system 的元件：它刻意保留前台的裸 `rgb()`／`rgba()` 與 px 字級（`--fs-*`、`.status-tag` 的 12px…），token 定義在檔頭 `.fep-shop { … }`、不與 `_tokens.css` 混用；**不得在 Creator Studio 其他頁引用**（唯一消費者是 `js/fan-event-page.js`）。check_ds_sync 檢查 5／10 的裸色數已手動登記進 `ds-baseline.json`（`component_css.fan-shop.css`）；前台改了就重抓覆蓋整檔，不手改視覺。

**Behavior** — 兩個宿主把各自資料整理成同一份 `model`（結構見 `js/fan-event-page.js` 檔頭：`gallery`／`video`／`organizerAvatar`／`bundles[].tickets{names,qty}`／`bundles[].goods[]`／`related[]`）交給本檔渲染，本檔只知道「粉絲頁長什麼樣」、不知道資料來源。可翻譯欄位由宿主給 `{ key }`，本檔以 `api.getValue(key)` 取當前語系值並掛 `api.bindEditable`（非預設語系時 contenteditable，空值 `.is-empty:empty::before` 畫佔位）；價格由 `api.money(priceObj, priceKey)` 依所選幣別格式化（覆寫優先、否則換算，`js/events-store.js` 的 `priceIn`）再補成「NT$ 1,200」；區間「NT$ 1,200 – 2,800」。前台固定文案（票價／日期／場館／購票／組合方案／退換票…）走 i18n `fep.*`（en／zh）、跟介面語言；內容欄跟預覽語系；預覽語系英文時 `.fep-shop[lang=en]` 換 Satoshi／Inter（前台 `html[lang=en]` 同規則）。有組合包時票券頁／票務商品頁可切（`.pp-fan-viewbar` 與頁內「只買票 ›」），購買區與票種節聯動換成組合價與組合方案。
