調參器 · 詳情浮層與主按鈕

右邊是活的：浮層裡跑的是真的 project-detail.html?embed=1，糊的是它底下那一頁。 調到滿意就按「複製 CSS」，把值貼給我，我搬進正式層。滑桿的預設值＝目前線上的值，↺ 就是回到那裡（2026-08-31 定案後已同步）。
標「全站」的參數會影響整個站（不只浮層）；若只想改浮層，跟我說一聲，我幫你收成浮層專用的變數。

A · 浮層外框

  1. ④ 浮層內容　詳情頁本人（iframe），最上層
  2. ③ 面板玻璃　白膜＋模糊＋頂緣內光，另有一圈投影落在面板外
  3. ② 暗紗　蓋滿整個視窗，面板底下也有——所以它同時決定「面板透出來多暗」
  4. ① 底下那一頁　你點進來之前看的畫面（本頁用一份有亮圖大字的替身）

「面板看起來偏暗」是 ②暗紗 與 ③玻璃 一起造成的，面板外那圈黑則多半是投影——三個都在下面，可以分開調。看不出暗紗在做什麼時，勾第一個開關把面板移開。

B · 浮層裡的區塊（卡片與 KPI）

浮層裡的卡片走「薄膜＋細邊、不投影」，因為玻璃上再壓一層有影子的卡就是兩層玻璃。

C · 主按鈕（橘）

這組就是 2026-08-28 換裝時沒收的那一題。側欄的「已選中」跟主按鈕共用同一組 token，改了會一起變——這是當初刻意的，不是漏改。
