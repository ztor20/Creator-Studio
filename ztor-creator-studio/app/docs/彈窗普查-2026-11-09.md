# ztor Creator Studio 浮層普查（2026-11-09）

範圍：`site/app` 根目錄產品頁（排除 `design-*`、`lab-*`、`demo-*`）＋ `js/*.js`、`partials/*.js`。只讀，未改任何專案檔。

讀法：

- 「外殼」欄縮寫：`PD`＝`.payout-modal`＋`.payout-dialog`（後面接修飾類，沒寫＝預設 620px）；`leave-dialog`、`embed-modal`、`drawer`、`explain`（`.explain`＋`.explain__dialog`，`js/explainer.js`）、`detail-sheet`、`scanner-sheet`、`wizard--overlay` 照原名；`原生 confirm`／`原生 alert`＝瀏覽器內建對話框。
- 標題取 `js/i18n.js` 的中文；畫面標題由 JS 動態填的，寫成實際會出現的句子（`{n}` 是品名或數字）。
- 一個外殼在同一頁服務多種任務時（活動詳情 `openConfirm()`、媒體庫確認殼），拆成子列（編號帶字母），因為任務類型不同。
- 不收：頂欄搜尋／通知下拉、`fan-analytics` 平台連線小面板（都是 popover，不蓋頁面）、`index.html` 的 `.canvas-sheet`（首頁卡片，不是浮層）、`js/devtools.js` 作弊碼面板、`js/lab-media-vault.js`（lab 檔）。
