## 2. 建議的類型（依「使用者在做什麼決定」分）

### T0 起手分流（閘門）

- 使用者在做：建立流程一開始決定「要做哪一種東西」，選了直接進下一步，後面整頁跟著分岔。
- 控件：`radio-cards--gate`（2–6 個，附一句說明）；選項超過 7 個且只有名稱時用 `selection-card--icon` 磚（Q69 待裁決）。
- 說明：要附（每張一句「這是什麼」）。
- 生效：點了就走，不保留選取態（Q28）。

### T1 開或關一件事

- 使用者在做：某個功能或屬性要不要，常常打開才揭示更多欄位。
- 控件：`switch`；要揭示欄位時包在 `control-row`／`control-group` 裡。
- 選項數：固定 2（開／關），問題要能用「要不要 X」問。
- 說明：附一句後果（關掉會怎樣）。
- 生效：規格 4.6 寫「立即生效，需要儲存時改用 checkbox」，但現況表單內約 60 處 switch 都要跟著儲存（見 3.3），需要裁決改寫判準：建議改成「開關＝要不要一件事，不論立即或儲存；checkbox 只留給多選與不可逆確認」。

### T2 從 2–4 個互斥做法選一個

- 使用者在做：同一件事有幾種做法，選了會改變後面的欄位或結果。
- 控件分兩級：
  - 每個選項需要一句說明 → `radio-cards`（2 張並排、3 張用 `--3`）；空間窄或第二層設定 → `radio-list`（直列，可收合）。
  - 選項名稱自己就說得清楚（%／$、cm／inch、公開／私人）→ `segmented`（記作 T2-短）。
- 選項數門檻：2–4；5 個以上改 select（表單）或 selection-card 格（主選擇且要看全貌時）。
- 生效：要儲存。

### T3 切換檢視

- 使用者在做：同一份資料換個看法（區間、圖表型式、列表／卡片、排序、單位欄），不改資料、不減少筆數。
- 控件：`segmented`；純圖示時 `segmented__btn--icon`。
- 選項數：2–4。
- 說明：不附。
- 生效：立即換畫面。

### T4 篩選清單

- 使用者在做：縮小清單或表格裡出現的筆數。
- 控件：
  - 一個互斥軸、要看每項筆數 → `filter-tabs`（清單頁狀態用 `--brand`，收入來源用 `--source`）。
  - 可複選的軸（標籤、狀態旗標）或年度這類短值 → `chip-group`。
  - 單一條件「只看 X」 → 待定（現況 ip-market 用 zcheck）。
- 選項數：filter-tabs 3–9；超過 9 改下拉。
- 生效：立即換畫面。

### T5 從多個選項勾幾個

- 使用者在做：一組固定選項裡勾出所有適用的。
- 控件：
  - 只有名稱、數量多（作品類型 21 個、地區）→ `chip-group`。
  - 選項需要說明或成組列 → `radio-list--check`（Q126：列一樣、記號是方框）。
  - 一般清單或樹 → `zcheck`；表格選列 → 列首 `zcheck`。
- 生效：要儲存。

邊界（不建類型、只寫轉介）：
- 長清單的 1-of-N（國家、語言、分級門檻在表單裡）→ `select`／`zselect`。
- 要搜尋才挑得到的 → combobox、tag-input、code-picker。
- 不可逆確認勾 → 屬 5.1.8 彈窗類型的破壞性確認，不屬選擇控件。

## 3. 不一致清單

### 3.1 「限量／收費」這類有無題，同一個決定四種控件

- 商品限量：建立頁是 switch（create-product.html:586 `cp-edition`），詳情頁卻是鎖定的 radio-cards「Unlimited／Limited edition」（product-detail.html:792）。同一個值在兩個畫面長兩種樣子。
- 組合包數量：同一支 js/bundle-editor.js 裡，分段版型用 radio-cards（:1708 `secQtyHTML`），卡片版型用 segmented（:2879）。
- 觀影派對人數「不限／設上限」用 segmented（create-event.html:640）；商品的限購、限量是 switch。
- 收費與否：觀影派對「免費／設定價格」用 segmented（create-event.html:800）；發布作品「收費作品」用 switch（partials/work-fields.js:602）。

### 3.2 同一類決定用了不同控件（違反或擴張 Q17）

- 上架時機，四種控件：
  - 建立商品、組合包、活動：radio-cards--3（create-product.html:959、create-bundle.html:397、create-event.html:1016）。
  - 建立拍賣：收合式 radio-list（create-auction.html:398）。
  - 建立專案「發布時間」：selection-card（create-project.html:442）。
  - 詳情頁：上架總開關 switch＋定時下架 switch（product-detail.html:1132、auction-detail.html:308、bundle-detail.html:586）。
- 開賣時機，三種控件：
  - 建立頁、活動詳情：radio-cards（create-product.html:1015、event-detail.html:1214）。
  - 組合包詳情：radio-cards--3（bundle-detail.html:666）。
  - 商品詳情：收合式 radio-list（product-detail.html:1199）。三個詳情頁問同一題、選項也一樣，卻是三種樣子。
- 3 個帶說明的互斥選項：
  - create-auction.html:253 競標天數、create-project.html:354 觀看權限用 selection-card。
  - create-event.html:972 取票方式、create-product.html:959 上架用 radio-cards--3。
  - Q17 只用版面（大格／並排／直列）分，選項數與說明量相同時沒有判準。
- 分級門檻「誰買得到」，三種控件：
  - create-auction.html:275 用 segmented。
  - create-event 票種條件用 select（Q51）。
  - e-shop.html 清單列用階梯下拉。
  - Q51 只裁了後兩者，segmented 這第三種沒被提到。
- 篩選外觀被當成表單值：「門票建法：從票種／獨立」用 filter-tabs（event-detail.html:2035、create-event.html:2931），這是要儲存的單選，照 T2 應是 radio-cards 或 segmented。
- 起手分流：建立拍賣的種類（create-auction.html:76）用表單內的 selection-card，其他建立流程都是 radio-cards--gate 閘門（create-product.html:122、create-event.html:238、create-project.html:73）。

### 3.3 開關與互斥選擇混用

- 用單選做開關：
  - js/ticket-bundle.js:420、:435 用 radio-list「任何人／限定」「不限／設上限」。
  - 同一件事（限購）在 create-product.html:707 是 switch。
- 用卡片做開關：register-ip.html:261「上架出租／保持私人」用 selection-card 兩張，實際是「要不要上架到市集」，同題在 manage-ip.html:150、ip-detail.html:334 是 switch。
- 用 checkbox 做開關：
  - register-ip.html:251、:280「洽詢」與 manage-ip.html:172–203「授權費種類」用單顆 zcheck 揭示欄位。
  - 其他頁「打開才揭示欄位」一律是 switch＋control-group。
- 規格與現況相反：switch 規格（ds-specs/4.6-switch.md）寫「需要儲存時不要用 switch」，但建立頁與詳情頁約 60 處 switch 都要跟著儲存或發布。這不是個別頁的錯，要改的是規格判準。

### 3.4 切換檢視與篩選各有兩到三種外觀

  - 這直接違反 projects 那條收斂紀錄。
- 清單篩選，四種外觀：
  - filter-tabs：大多數清單頁。
  - tabs 底線：fan-detail.html:264、:330，pickup-detail.html:230、:650，projects.html:64，ip-market.html:56。tabs 規格是頁區導覽。

### 3.5 元件規格自己的禁止事項被違反

- selection-card 規格寫「不要用於多選」：register-ip.html:211 授權用途是多選 selection-card（:761 toggle），已選與未選看起來都像 1-of-N。
- chip 規格寫「不要把 `.chip--active`（橘）用在創作者輸入的值」：已加入的標籤都掛 `chip chip--active chip--removable`（create-product.html:2776、product-detail.html:2590、project-detail.html:5202、fan-detail.html:636、partials/film-picker.js:43）。

- 自訂控件繞過元件：
  - fan-detail.html:557 加／扣點自己做了一對 aria-pressed 按鈕。
  - restock-modal.js:44 的 radio-cards 掛 role=tablist（語意是分頁，行為是選值）。
