# 示範資料索引

本頁列出原型目前涵蓋的全部示範商品、組合、優惠碼、活動與訂單，方便直接點進細節頁核對各種狀態的呈現。商品與組合的資料本體在 `js/products-store.js`（`P_DEFAULT`／`P_NICK`／`BUNDLE_SEED`），活動在 `js/events-store.js`，訂單在 `js/orders-store.js`；本頁只做索引與導覽，不重複維護欄位定義。

2026-10-16 依 `note/release2.4 假資料覆蓋稽核.md` 補齊 release2.4 的示範缺口，新增「優惠碼」「活動（release2.4）」「訂單與匯出紀錄」三節，並更新受影響的商品與組合列。

## 怎麼切換 persona

E-Shop 目前示範兩個賣家身分（persona），同一批商品／組合 id 在兩邊會顯示不同內容：

- **預設 persona（九龍夜行）**：在 cheat code 面板切換 User，或主控台執行 `localStorage.setItem('ztor.persona','default')` 後重新整理。注意：本機 demo 沒設定時預設是 nick（`js/theme.js` 的 FALLBACK）。
- **nick persona（周湯豪）**：透過 devtools 的 cheat code 面板切換 User，或在瀏覽器主控台執行 `localStorage.setItem('ztor.persona','nick')` 後重新整理頁面。
- 清掉 `ztor.persona` 會回到 nick；要看九龍夜行一定要設成 `default`。

以下每張表的「網址」欄都是相對於 `site/app/` 的路徑；要看 release2.4 的範圍就在網址加 `version=release2.4`，直接接在 dev server 網域後面即可開啟（例如 `http://localhost:4326/product-detail.html?id=zine`）。

## 詳細規格／取貨與退貨說明（2026-09-23 · D319 補）

`js/products-store.js` 的商品記錄原本沒有 `specs`（詳細規格逐列 `{ name, value }`）與 `deliveryReturns`（取貨與退貨說明，短文字）兩欄——這兩欄只有建立商品表單才有，導致 `product-localization.html` 的翻譯表少了這兩組可翻譯列（ASSUMPTIONS UIA-175 記過的產品缺口）。本輪為預設 persona 四筆實體商品（`zine`／`tee`／`hoodie`／`acetate`）補上這兩欄真實感示範值，`product-detail.html` 的商品設定分頁與 `product-localization.html` 的翻譯表／預覽都已接上同一份資料；其餘商品沿用原狀（留空，不影響既有頁面）。
