## 結論

機械檢查沒有發現版面崩壞：沒有零高度、水平溢出或沒畫出來的 icon。有問題的是下面三類，共約 10 個小節。

## 用了已經沒有樣式的舊 class

這些 class 在 CSS 裡找不到定義，產品頁和 JS 也沒有使用，demo 很可能和實際元件長得不一樣。

| 小節 | 舊 class |
|---|---|
| `store-settings` | `ss-band__cover`、`ss-band__head`、`ss-band__avatar` 等 |
| `pickup` | `scanner-hand`、`scanner-access__actions`、`scanner-access__pw` |
| `progress-timeline` | `ptl__node--doing`、`ptl__node--todo` |
| `media-vault` | `vault-viewer__icon` |
| `vault-task` | `vault-task__status--ready` |
| `media-preview` | `mpreview--audio` |

建議處理：照產品頁現在的 markup 重寫這幾張 demo。`store-settings` 與 `pickup` 優先，舊 class 最多。

## 空的圖片

有 14 個 `<img>` 的 `src` 是空的，畫面上不會出現圖片。

- `upload-tile`：12 個
- `vip-card`：1 個
- `source-upload-modal`：1 個

建議處理：放示意圖，或確認這些 demo 本來就要呈現未上傳狀態。

## 橘底白字

對比度約 2.0，比一般可讀門檻低。Q99 處理過主按鈕，這幾處是否一併調整待使用者裁決。

- `pager`：目前頁碼
- `funding-panel`：百分比
- `empty`、`pattern-lifecycle`：`.empty-stub__mark`
- `fan-store`：Join community、New
- `upload-tile`：Hero 標記與提示

## 排除的誤報

- 亮色主題的大量低對比：亮色已依 Q135 關閉，不是使用者會看到的畫面。
- 徽章對比 1.0：腳本讀不懂 `color(srgb …)` 格式，實際色值正常。
- `switch` 的空 demo：switch 本來就沒有文字。
- 13 個小節的 `sub__spec-body`：文件排版外框，沒有樣式不影響元件。
- 在 JS 或產品頁有使用但 CSS 沒定義的 class：多半是給 JS 用的掛鉤。

## 沒驗到的範圍

- 瀏覽器面板隱藏，沒有截圖，「看起來怪」這類視覺問題抓不到。
- 互動狀態（hover、展開、彈窗開啟後）沒有逐一操作。
- 手機寬度與 iPhone 實機。
- 半透明或漸層底上的文字對比。
