Creator-economy operations dashboard.創作者經濟營運儀表板

The back-office where independent creators turn IP, projects, and fans into income — transparently. Clean white canvas with neutral light-gray surfaces, highlighter-orange primary, Satoshi typography (Geist fallback), flat 1px borders on default cards and controls (Q3/Q4 2026-07-13), multi-layer rim+drop shadows reserved for popovers/overlays and clickable-card hover.

讓獨立創作者把 IP、項目與粉絲透明地轉化為收入的後台。純白畫布配中性淺灰表面、highlighter 橘為主色、Satoshi 字體（Geist 備援），預設卡片與控件用扁平 1px 邊框（Q3/Q4 2026-07-13），多層 rim+drop 陰影只保留給浮層／對話框與可點卡片的 hover。

Category — Creator-economy operations dashboard: IP licensing, projects, events, products, fans (CRM), and earnings, with finance / royalties / verification states kept legible. Theme: light / dark / system.

類別 — 創作者經濟營運儀表板：IP 授權、項目、活動、商品、粉絲（CRM）與收益，並讓 finance / royalties / verification 狀態保持清楚易讀。主題：light / dark / system。

Locales — en (primary) · zh-Hant (secondary), toggled in the topbar and persisted. CJK glyphs are split across two self-hosted subset typefaces — LINE Seed TW for headings (--font-cjk-display) and Chiron Hei HK (昭源黑體) for body/UI (--font-cjk) — with Noto Sans TC appended as the final fallback in both stacks (2026-07-28 裁示).

語系 — en (primary) · zh-Hant (secondary)，在 topbar 切換並保存設定。中文字由兩支自架 subset 字型分工——標題用 LINE Seed TW（--font-cjk-display），內文／UI 用「昭源黑體」Chiron Hei HK（--font-cjk）——兩個 stack 末端都接 Noto Sans TC 當最終備援（2026-07-28 裁示）。

Discipline

Top-level Do / Don't.最高原則 該做 / 別做

Do該做

  • Reserve #ffa33f for one structural accent per viewport (CTA, active tabs, selection-card selected state, or hero — not several at once; info banners stay neutral gray, nav active states stay neutral gray, Q8).
  • 每個視窗只保留 #ffa33f 給一個結構性重點（CTA、active tabs、selection-card 已選態或 hero，不要同時用好幾個；info banner 與 nav active 一律中性灰，Q8）。
  • Pair --primary with --primary-foreground (#171717) text — never white-on-orange.
  • --primary 一律搭配 --primary-foreground（#171717）文字，絕不用白字配橘底。
  • Define edges with a real 1px --border on default cards and form controls (Q3/Q4 2026-07-13); reserve multi-layer shadows (--shadow-card = rim + drop) for popovers/overlays and clickable-card hover.
  • 預設卡片與表單控件的邊緣一律用真正的 1px --border（Q3/Q4 2026-07-13）；多層陰影（--shadow-card = rim + drop）只保留給浮層／對話框與可點卡片的 hover。
  • Spell out money state inline: "Available $842 · Pending $1,204".
  • 把金額狀態直接寫出來：「Available $842 · Pending $1,204」。

Don't別做

  • Don't use solid orange for nav active fills or status pills — since Q8-A (2026-07-27) nav active is an orange tint (--selected-surface + --selected-ink); hover is still --accent (Q9) and status pills keep their status tokens. --sidebar-active is now a fallback only and is unused (待採用).
  • 別把實色橘用在 nav active 的填色或 status pill——Q8-A（2026-07-27）之後導覽已選是橘色 tint（--selected-surface ＋ --selected-ink）；hover 仍是 --accent（Q9），status pill 用各自的狀態 token。--sidebar-active 已退為回退值、目前無人引用（待採用）。
  • Don't fall back to a shadow-simulated hairline on cards / inputs where the shipped CSS uses a real 1px solid --border (Q3/Q4) — shadow-as-edge is now for popovers / overlays / clickable-card hover only.
  • 別在已改用真 1px solid --border 的 cards / inputs 上退回陰影模擬細邊（Q3/Q4）——陰影當邊框現在只留給浮層／對話框與可點卡片的 hover。
  • Don't show a bare number without its currency + state.
  • 別只顯示沒有幣別與狀態的裸數字。
  • Don't use Title Case on buttons — sentence case ("Create project").
  • 按鈕別用 Title Case，用 sentence case（「Create project」）。
  • Don't put more than one Primary button in a row.
  • 同一列別放超過一個 Primary 按鈕。
Discipline

Style decisions landed (2026-07-13, Q1–Q12).風格裁決落地（2026-07-13，Q1–Q12）

Twelve style calls resolved on 2026-07-13; CSS already ships this — this table is the rule summary for new components going forward.

2026-07-13 落地的 12 條風格裁決；CSS 已經改完，這張表是給後續新元件對齊用的規則摘要。

Q1Shape = interactivity cue — clickable pill (chip, filter-tabs) = full-round --radius-pill; display-only badge (badge, field-pill, metric-pill) = small rounded rect --radius.形狀＝可否互動的線索——可點膠囊（chip、filter-tabs）＝全圓 --radius-pill；純顯示徽章（badge、field-pill、metric-pill）＝小圓角矩形 --radius。
Q2Controls share one radius, --radius (10px now; 6px when decided, raised in the r2.3 reskin) — --radius-md is an alias of it. Exceptions: pill (9999px), shell (30px), --radius-lg (16px), --radius-xl (24px).控制項共用一個圓角 --radius（現值 10px；裁決當時是 6px，r2.3 換裝上調）——--radius-md 是它的別名。例外：pill（9999px）、shell（30px）、--radius-lg（16px）、--radius-xl（24px）。
Q3Default card = 1px flat --border. Only clickable/lift cards (.ztor-card--clickable hover, .selection-card) upgrade to a flat shadow on hover.預設卡＝1px 純邊框。只有可點／浮起的強調卡（.ztor-card--clickable hover、.selection-card）hover 時才升級純陰影。
Q4Inputs use a 1px shadow edge so control sizing stays stable; focus promotes it to --ring plus a 4px soft glow.輸入控件用 1px 陰影邊線，尺寸維持穩定；focus 改為 --ring 加 4px 柔光。
Q5Hover-lift rule — 2026-10-20 update (user): a card whose whole face is one click target lifts --clickable-card-lift (4px) and swaps its fill to --clickable-card-hover-bg (the button hover rung --control-raise-hover); no border change, no shadow change. Previously this row said clickable cards borrow --shadow-float; that shadow hover is retired. List/table rows keep their own row hover (Q34); pure preview/display cards get no hover.hover 浮起規則——2026-10-20 使用者更新：整張卡是一個點擊區的卡片，hover ＝ 上浮 --clickable-card-lift（4px）＋底色換成 --clickable-card-hover-bg（＝按鈕 hover 階 --control-raise-hover）；不換邊框、不換陰影。原本寫「借 --shadow-float 浮起」，該陰影 hover 已退場。清單列與表格列維持各自的列 hover（Q34）；純預覽／展示卡不做 hover。
Q6Form rhythm follows base .field (label↔control 6px, field↔field 16px); .form-section no longer overrides vertical rhythm locally.表單節奏以基礎 .field 為準（描述↔控件 6px、欄位↔欄位 16px）；.form-section 不再局部覆寫垂直節奏。
Q7Card padding stays per-component (not unified): .kpi 16/18 · .card 20 · .ztor-card 24 · .selection-card 14/16 · .empty-card 32/24. New cards should match one of these, not invent a number.卡片內距對照表（維持各自密度，不硬統一）：.kpi 16/18 · .card 20 · .ztor-card 24 · .selection-card 14/16 · .empty-card 32/24。新卡片對號入座，不要隨機挑數字。
Q8Brand orange stays scoped to primary actions/categories (Tabs, selected selection-card). Nav/filter selected states stay neutral gray — .settings-nav--active and .app-sidebar already use --sidebar-active. Reversed by Q8-A on 2026-07-27: selected states now use an orange tint; --sidebar-active is unused (待採用).品牌橘只給主操作／主分類（Tabs、選擇卡已選）。導覽／篩選的已選一律中性灰——.settings-nav--active、.app-sidebar 已對齊用 --sidebar-active。
Q9Interactive hover background is always --accent (#F3F3F3 light / #2A2B2C dark — midnight-v2 2026-07-17); --muted is reserved for zebra stripes/subtle backgrounds. --secondary is retired (zero consumers, removed from _tokens.css). Exception: .filter-tabs__item:hover still uses --muted because its active state is also muted gray — hover can't outweigh selected.互動 hover 底色一律 --accent（亮 #F3F3F3／暗 #2A2B2C，2026-07-17 midnight-v2 壓暗）；--muted 只給斑馬紋／襯底。--secondary 已退役（全站零消費，已自 _tokens.css 移除）。例外：.filter-tabs__item:hover 仍用 --muted，因其 active 也是灰 muted，hover 不可比已選更重。
Q10Close icons are always the base .ztor-icon 16px — the 20px/18px overrides on .alert__close and .leave-dialog__close are removed.關閉鍵 icon 一律基礎 16px——.alert__close、.leave-dialog__close 的 20px/18px 覆寫已移除。
Q11The Paid badge (orders / order-detail) is badge--success (green) sitewide — was badge--neutral.已付款 Paid 徽章（orders／order-detail）全站一律 badge--success（綠色）——原本是 badge--neutral。
Q12Field labels use regular case (.settings-row__label) — the uppercase .gate-field__label on tier-settings.html is retired; don't add new uppercase-label one-offs.欄位標籤用一般大小寫（.settings-row__label）——tier-settings.html 原本的大寫 .gate-field__label 已退役，不再新增大寫孤例。
