## 2.場次與票務設定

1. 選擇入場方式(購票或免票)：選擇購票則有以下流程，選擇免票則無以下流程：
	- 帶入場次
		- 場地, 地址, 集合地點, 交通(fix 無論哪個場次，地點都一樣)
		- 活動日期與開始結束時間, 入場時間(fix)
	- 帶入票種
		- 一般票 : 註記門票名稱 {場次名+票種, (或特殊票名：設定門票種類名稱)} 
			- 價格(fix)
			- 數量(fix)
			- 誰可以買(分票)
			- 折扣(若有則fix)
				- 時間優惠(fix)
				- 粉絲群優惠
			- 加入商品(分票)
			- 限購條件(fix)
			- 手續費(若有則fix)
			- 排序(因為只顯示於ztor前台，因此不帶入，在UI上直接拖動)
			- 標籤（活動主題）
		  
		- VIP : 註記門票名稱 {場次名+票種, (或特殊票名：設定門票種類名稱)} 
			- 價格(fix)
			- 數量(fix)
			- 誰可以買(分票)
			- 折扣(若有則fix)
				- 時間優惠(fix)
				- 粉絲群優惠
			- 加入商品(分票)
			- 限購條件(fix)
			- 手續費(若有則fix)
			- 排序(因為只顯示於ztor前台，因此不帶入，在UI上直接拖動)
			- 標籤（活動主題）
2. 其他活動設定
	- 每人總限購數量
	- 每次交易限購數量
	- 限購次數

## 3發布設定

	- 物流：順風, 到店自取, 電子門票
