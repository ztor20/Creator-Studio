# 示範資料索引

本頁列出 E-Shop 原型目前涵蓋的全部示範商品與組合，方便直接點進細節頁核對各種狀態的呈現。資料本體在 `js/products-store.js`（`P_DEFAULT`／`P_NICK`／`BUNDLE_SEED`），本頁只做索引與導覽，不重複維護欄位定義。

## 怎麼切換 persona

E-Shop 目前示範兩個賣家身分（persona），同一批商品／組合 id 在兩邊會顯示不同內容：

- **預設 persona（九龍夜行）**：不用特別設定，重新整理頁面即回到預設狀態。
- **nick persona（周湯豪）**：透過 devtools 的 cheat code 面板切換 User，或在瀏覽器主控台執行 `localStorage.setItem('ztor.persona','nick')` 後重新整理頁面。
- 要切回預設 persona：`localStorage.removeItem('ztor.persona')` 後重新整理，或 cheat code 面板切回預設 User。

以下每張表的「網址」欄都是相對於 `site/r2.3/` 的路徑，直接接在 dev server 網域後面即可開啟（例如 `http://localhost:4326/product-detail.html?id=zine`）。

## 備註

- 「示範狀態」欄只記這一筆資料主要示範的重點，不是欄位全貌；完整欄位定義見 `js/products-store.js` 檔頭註解。
- E-Shop 清單頁（`e-shop.html`）的「組合」分頁裡，nick persona 專屬的列在預設 persona 下會被隱藏（反之亦然）；切換 persona 後如果列表沒有立即更新，重新整理頁面即可。
- 取貨與核銷區（組合設定分頁「商品」節之後）只在組合含現場 QR 領取成員時出現；本索引在對應組合的示範狀態欄已標明含哪些 QR 成員。
