第三輪，編號換過。第二輪的四個變體（三格數字列／主數字領銜／緊湊列卡／數字優先磚）已全部退場——那一輪的數字是 20px 大字，你的回饋是「太佔空間，改小標籤就好」。本頁的 1–4 是本輪的新四個，方向一律是「欄名與值同一行、字級小」。之後翻到這一頁，編號請以本輪為準。 Round three — the numbering was reset. Round two's four variants (stat row / lead figure / compact row / numbers-first tile) are all retired; that round set the figures at 20px and the note back was "they take up too much room — make them small labels". Variants 1–4 below are this round's, all in the small-label direction: column name and value on one line, set small. Numbers on this page refer to this round only.

「可匯入」這個欄位已經退場（2026-09-02，D238）。本頁做完之後同日又裁示「綁定以後，會自動匯入，實時檢查更新」——自動匯入之後不存在「還沒搬進來」的活動，所以正式頁已經沒有可匯入這個數字、沒有「有待匯入」篩選、表格也沒有勾選匯入。本頁的 2 號（三欄小標籤含可匯入）與 3 號的流水句因此在講一個現在不存在的欄位，留著只當作「三欄塞不塞得下」的量測證據，不要照它復刻。正式頁採用的 1 號不受影響（那兩欄是已匯入／待設定）。 The "to import" figure is gone (2026-09-02, D238). After this page was made, the same day's call was "once linked, events import automatically and keep syncing" — which leaves no such thing as an event still waiting to come across. The live page therefore has no to-import figure, no "To import" filter and no import checkboxes. Variant 2 (three label columns, to-import kept) and the run-on sentence in 3 now describe a field that no longer exists; keep them only as evidence of what three columns cost in 260px, do not copy them. Variant 1, the one that shipped, is unaffected — its two columns are Imported / To set up.

四張卡是同一組資料，含三個極端值：全 0 的已綁定卡（Aya）、未綁定卡（KMT，本輪起卡上不印任何場次數字）、長名字＋兩位數（Sakuragi）。每個變體的第一張卡是已選態（1px 橘 outline ＋中性陰影，站上既有裁決）。 All four variants share one data set with three edge cases: a linked creator whose figures are all zero (Aya), an unlinked one (KMT — as of this round, no event figures at all), and a long name with double-digit figures (Sakuragi). The first card of each variant is in the selected state (1px orange outline + neutral shadow, the site's standing call).

1

兩欄小標籤Two label columns

目前正式頁用這一號Shipped on the live page

強調卡的第二列只回答一件事：「這一位的 bookyay 資料現在是什麼狀態」。已綁定就放已匯入／待設定兩個等寬欄（值落在同一條垂直線，位數變多也不會把後面那一欄往右推）；未綁定就用「未綁定」徽章佔住同一個位置，就地說明這裡為什麼是空的。放棄兩件事：卡上沒有可匯入（那是選人之後才用的量，留在下段摘要與「有待匯入」篩選），也沒有明說的「已綁定」徽章——有數字就代表帳號通了。 Emphasises one job for the second line: what state this creator's bookyay data is in. Linked shows Imported / To set up as two equal columns, so the values sit on one vertical line and a second digit never pushes the next column along; not linked puts the badge in that same slot, explaining on the spot why it is empty. Gives up two things: the to-import figure (it belongs to the step after you pick someone, and stays in the summary line and the "To import" filter), and an explicit "Linked" chip — figures on the card already say the account is connected.

2

三欄小標籤（含可匯入）Three columns, to-import kept

強調把可匯入放回卡上，並保留「已綁定」徽章（移到名稱那一列）。這是唯一在說「這一位還有事要做」的數字——沒有它，一排卡看不出為什麼值得點進去，左上角的「有待匯入」篩選在卡上也找不到對應的視覺。放棄卡寬是固定的：260px 的卡塞三欄，英文欄名（Imported／To set up）會被截成「Import…」，而名稱那一列又被徽章切走一段，「KMT Collective」這種長度就開始掉尾巴。中文塞得下、英文塞不下的版面，等於只對一種語言成立。 Emphasises bringing the to-import figure back onto the card, and keeping the "Linked" chip (moved up to the name line). It is the one number that says this creator still needs work — without it a row of cards gives no reason to click into any of them, and the "To import" filter top-left has nothing to point at. Gives up fit: the card width is fixed. Three columns in 260px clip the English labels to "Import…", and the chip on the name line eats enough room that a name like "KMT Collective" starts losing its tail. A layout that fits Chinese but not English only works in one language.

3

一行流水句One running line

強調三個數字都在，而且不必為它們切欄——一句話讀完「可匯入 3 · 已匯入 2 · 待設定 1」，卡最省版面，密度最高。放棄對齊：句子隨字長流動，卡與卡的數字不在同一條垂直線上，一排掃過去只能一張一張讀；英文更長，兩位數一出現就掉到第二行、卡的高度自己不一致。 Emphasises keeping all three figures without spending a column on each — "3 to import · 2 imported · 1 to set up" reads as one sentence, and the card gets as small as it can. Gives up alignment: the sentence flows with the text, so no two cards put their figures in the same place and the row has to be read card by card. English runs longer, and a double-digit figure tips it onto a second line, so the cards stop being the same height.

4

兩顆數字晶片Two figure chips

強調每個數字是一顆獨立、數得出來的東西——晶片有自己的底，掃一排先看到「這張卡上有幾件事」，全 0 的那張整組退成淡色、幾乎看不見，對比最強。放棄對齊與輕盈：晶片寬度隨字長變動，卡與卡的數字不在同一條垂直線上；兩顆藥丸的視覺重量也比兩段小字重，一排卡看過去先看到的是形狀，不是數字。 Emphasises each figure as a separate, countable thing — a chip has its own ground, so scanning the row first tells you how many things sit on a card, and an all-zero card fades almost out of sight. The contrast between "has work" and "has none" is the strongest of the four. Gives up alignment and lightness: chip widths follow their text, so no two cards line their figures up, and two pills carry more visual weight than two runs of small text — the row reads as shapes before it reads as numbers.
