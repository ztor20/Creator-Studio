01這套階層怎麼運作

現在 DS 的表面是一串固定顏色（畫布、襯底、外殼、卡、hover），要知道某一塊是第幾層，得先記住那五個顏色誰比誰亮。這套改成級數寫在 token 名字裡，並且把「疊上去」做成相對效果。

  • L0 畫布是頁面底，只有一個，不能疊在別的東西上。
  • L1 實色面是卡片與面板，值是絕對色——它必須在任何底色上都長成同一個顏色。
  • L2 疊層是相對的一層：深色用半透明薄膜，疊在誰身上就跟著誰亮一階，同一個 token 疊在畫布上與疊在卡片上得到兩個不同顏色，但「高一層」的感覺一樣；亮色不疊色，留白靠陰影分開（見下一條）。
  • L3 只有框，不再疊填色。填色最多疊到 L2；再疊下去顏色會愈來愈糊、也會把畫布的冷色調洗掉，所以第三層改用一道 hairline 表達。
  • 亮色版走另一條規則（2026-08-11 裁示）：主色是黑夜，白天版除了畫布與 L1 之外，其餘層一律留白，分層改由陰影與線框承擔。白底再疊灰膜只會把卡片染灰、層數愈多愈髒；白色保持乾淨，分離感交給陰影與 hairline。所以同一份 markup 在兩個主題下走的是同一組 token、不同的表達手法。
  • 層級與陰影是兩件事：層級決定底色，陰影（既有的 E0–E4）決定離使用者多遠。深色只有「L2 貼齊母層底緣」會用到 --layer-lift；亮色的 L2 另外吃一道 --layer-2-edge，那是它唯一的分層訊號。
