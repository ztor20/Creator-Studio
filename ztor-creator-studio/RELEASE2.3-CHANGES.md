# RELEASE2.3-CHANGES — release2.3 改版紀錄

這個分支是 Creator Studio 原型的 release2.3。活動交付版。

- 站台檔在 `app/`，版本鎖死在 release2.3（`app/js/devtools.js` 的 `RELEASE_LOCK`），功能範圍依 `tier:release2.2,release2.3`。
- 固定網址：https://ztor-cs-rel23.vercel.app
- 版本標籤：`release2.3-vX.Y`

## 版本

### v1.5 · 2026-11-09

跳過 v1.4：標籤 `release2.3-v1.4` 是 2026-10-27 序號改名前（當時的 release2.3＝現在的 release2.2）打的，保留不動。

- 電子商店新增「修改庫存」：商品清單列選單與商品細節頁庫存管理可直接填新的在庫數，可加可減，最低到已鎖定加已占用的數量，紀錄標「修改庫存」（D525、main PR #441）。

### v1.3.1 · 2026-11-09

- 商品與組合包的購買條件拿掉限時購買，門票保留；組合包的購買條件目前沒有可用條件，區塊不顯示（main PR #437）。

### v1.3 · 2026-11-09

- 商品細節頁新增「貼文」分頁：可發新貼文、編輯、取消排程、重試（D520）。
- 取貨場次、活動票券、掃碼領點場次建立後就能掃或領，開始與結束時間只用來顯示；取消延長結束時間（D521）。
- 活動早到只留「提前入場時間」，掃到太早的票只提示，核銷照常；活動詳情的掃描器入口從已排程起顯示（D521）。

### v1.2 · 2026-11-09

- 購買條件的「新增條件」下拉不再被外框切掉（main PR #431）。

### v1.1 · 2026-11-06
