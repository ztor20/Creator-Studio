# RELEASE2.3-CHANGES — release2.3 改版紀錄

這個分支是 Creator Studio 原型的 release2.3。活動交付版。

- 站台檔在 `app/`，版本鎖死在 release2.3（`app/js/devtools.js` 的 `RELEASE_LOCK`），功能範圍依 `tier:release2.2,release2.3`。
- 固定網址：https://ztor-cs-rel23.vercel.app
- 版本標籤：`release2.3-vX.Y`

## 版本

### v1.8 · 2026-11-20

- 拿掉日圓（JPY）：產品方（Jeff）確認 V2 平台固定四種幣別（USD、TWD、HKD、SGD），release2.3 全站不再出現日圓。補上 v1.7 留下的缺口：日圓示範訂單原本查不到配對費率，換匯手續費顯示 0%。
- 幣別清單與換算：`js/currency.js` 的幣別值域、`js/events-store.js` 的示範匯率與符號、`js/orders-store.js` 的付款幣別符號都只剩四種；只為日圓存在的「不留小數」格式與取整分支拿掉；i18n 刪掉日圓全名。
- 示範資料改幣別：
  - 訂單 #ZT-10469（US$18.50 純數位）改成買家用港幣付款：匯率 1 USD = 7.8 HKD，換算 HK$144.30，換匯手續費 3%（港幣↔美元）HK$4.33，買家實付 HK$148.63。
  - 收入管理（earnings、earnings-ztor）的授權收入列由「JPY 350,000 → $2,401.00」改成「SGD 3,241.35 → $2,401.00」（1 USD = 1.35 SGD）。
  - 手動補登收入彈窗的幣別選項改成 USD、TWD、HKD、SGD（原本的 EUR、JPY 一併拿掉）。
- 影響頁面：訂單清單與訂單詳情、收入管理（earnings、earnings-ztor）、設定頁（註解）、手動補登收入彈窗、建立創作者的幣別下拉。
- 規則手冊同步：定價幣別、Creator 列表、商店設定、手動補登收入、作品發布步驟 3 改成四種幣別；平台費率設定拿掉「沒有日圓費率列」那句。

### v1.7 · 2026-11-19

- 換匯手續費改依幣別配對各設一個費率（D540）：平台費率設定頁的換匯手續費表由 5 列幣別改成 6 個配對（港幣↔美元、港幣↔新台幣、港幣↔新加坡幣、美元↔新台幣、美元↔新加坡幣、新加坡幣↔新台幣），同一配對兩個方向同費率。日圓（JPY）那一列拿掉；起始都是 3%，最終數字待 Susan 決定〔產品待確認〕。
- 訂單的換匯手續費改查配對表：訂單記下幣別配對與當下費率，訂單詳情的換匯手續費列顯示配對與百分比；例外設定的逐創作者覆寫也改成逐配對（release2.3 仍保留這個覆寫）。
- 新增匯率告警（D542，D543–D545 修訂）：
  - 換匯手續費標題列多一顆「警告設定」按鈕，開啟「匯率告警設定」彈窗：開頭一段說明＋收件人名單（可新增、移除；格式不對或重複不加；名單空了會提示）。修改按彈窗的儲存才生效、取消放棄，有未儲存修改時關閉會先確認；名單不走費率版本。
  - 換匯手續費表多第三欄「告警門檻」：每個配對一個數字，預設等於該配對的手續費（示範：新加坡幣↔新台幣 3.5%），改手續費時同列門檻立刻重設成新手續費，儲存前仍可另填；必填且大於 0，不合格時整個儲存擋下。門檻跟頁面的儲存一起存，但不算費率版本：只改門檻時不產生新版本，改在版本歷史寫一行異動（版本欄留「—」）。例外設定彈窗不顯示這一欄。
  - 單日匯率波動大於門檻時寄告警信給收件人，只是提醒、不自動調整價格、手續費或匯率；附告警信範本 `app/emails/rate-alert-zh.html`（每個配對列出告警門檻）。
  - 門檻、收件人、寄信頻率、信件內容與文案仍〔產品待確認〕。
- 規則手冊同步：平台費率設定、定價幣別、財務術語、訂單詳情四頁補上配對費率與匯率告警（來源 main commit bae90fea、8cf0dc2a、01720ebe、76f23dff，在 release2.3 的舊版內容上手工改寫）。
- 這次只搬上述兩項；main 上同期的其他換匯手續費調整（D517 去掉逐創作者覆寫、D539 只給 Admin 看與幣別只剩四種）不在 release2.3，JPY 在其他地方（幣別清單、日圓示範訂單）照舊，日圓訂單查不到配對費率、不收換匯手續費。
